전체 폐루프: 목표 설계
1. 환경과 지역 자원
날씨·낮밤·지형 / 먹이 양·최근 포식 이력
2. 개체의 관측
주변 먹이와 위험, 동료, 에너지, 은신처 거리
3. 정책과 사회적 판단
PPO 행동 + 개인 감각·무리 경보 + 은신처 의도
4. 실제 이동과 상호작용
먹이 탐색·섭식·도주·대피·포식·지역 이동
5. 생태계 상태 갱신
자원 소비·재생 / 생존·사망 / 지역별 개체군 변화
행동 결과를 다시 반영
FoodAmount · Population
PredationHistory
예를 들어, 숲에서 먹이가 줄어든다면
먹이가 줄어듦 → 개체의 관측이 달라짐 → 탐색이나 지역 이동을 선택함 → 지역별 자원과 개체군이
 달라짐 → 다음 판단에 다시 반영됩니다.
이 순환이 실제 실행에서 이어지는 것이 최종 목표입니다.

04 / 학습과 행동 결정

학습은 Python에서, 게임 실행은 Unreal C++에서
Python 학습 → 가중치 Export → C++ Native 추론으로 연결합니다. 게임 실행 중 Python 외부 추론을 기다
리는 구조는 사용하지 않습니다.
학습 환경과 게임의 관측 순서·정규화·행동 의미를 맞추고, 동일한 입력에 대한 출력 비교(Golden Vector)로 
수치를 확인합니다. 현재 감각·포식 조건과 학습 시나리오의 차이는 추가 합의가 필요합니다. [4, 5]

현재 opt-in 동물 통합 경로
• PPO → Social 보정·요청 → 기존 단일 이동 → 도착·실패 Feedback
• 사슴 위협 감각·무리 경보·은신처 이동·점유·반환
• 늑대 먹잇감 감각·기억, 동물 표현·Grass/Dry 발소리
• 기존 기록: 직접 UBT 빌드, 자동화 43/43, PIE 및 서버/Client 재접속 확인
추가 합의·연결·검증 필요
• 감각·포식 조건을 Python 학습 시나리오와 맞추는 작업
• 지역 날씨·식생·물 입력 연결과 시각/논리 낮밤의 동기화
• 장애물 우회, 실제 플레이어 환경, 장시간·지연·대규모 운영 검증
• 자원·섭식·에너지·사망·이주가 이어지는 전체 폐루프의 통합 평가
현재 opt-in 동물 경로의 검증을 기존 M3/JYU 전체 전환이나 모든 목표 기능의 완료로 확대하지 않습니다. 무리
병합·분할, ORCA, 자동 은신처 생성은 후속 검토 범위입니다.
