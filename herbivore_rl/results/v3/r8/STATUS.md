# R8 진행 상황 — 위험을 스스로 배우는 사슴 (설계 `AdaptiveEcosystem/Docs/RL_Policy/RL_R8_LEARN_DANGER_DESIGN.md`)

- 상태: **구현·시험·보정 관문 C0·스모크·학습 전 적대적 검토 끝, 본 학습은 아직 띄우지 않았다.** (11-05 16:55, 이 컴퓨터 시계)
  - 검토로 바뀐 것 하나: 탈진 늑대 속력 0.2 가 짐승에 없는 늑대만의 속력(쉬는 상태의 이름표)이라 `wolves.tired_speed: roam` 으로 고쳤다. C0 다시 통과, 12M 재스모크 정상(5절).

- 정한 학습 크기: **두뇌마다 250M 결정**, 벽시계 상한 10 시간. 넷(본 학습 시드 0·1·2 + 대조 H0)을 함께 띄우면 **약 4.2 시간**(실측 1.65만 결정/초/프로세스)이다.

  - 언리얼 빌드가 같은 때 돌면 느려질 수 있다. 그래도 상한 10 시간 안에서 멈추고 그 자리 모델을 끝 모델로 저장한다.

## 2. 보정 관문 C0 (개발 시드 41400~41449, 50 세계 × 3000 스텝 — `results/v3/r8/calib/`)

설계 값 그대로(`calib/calibrate_design.json`, `leak_design.json`):

| 관문 | 값 | 결과 |
|---|---|---|
| C0-1 `RULE_ORACLE` 잡힘 ≤ 0.5 × `ALWAYS_EAT` | 0.315 / 1.019 = 0.31 | 통과 |
| C0-2 짐승 2 이상 세계 `RULE_BLIND` 먹음 ≤ 0.9 × `RULE_ORACLE` | 3.234 / 3.098 = **1.04** | **못 넘음** |
| C0-3 평상 걸음·크기로 종류 맞히기 AUC ∈ [0.45, 0.55], 바꿔치기 | 0.478, 같음 | 통과 |
| C0-4 `ALWAYS_EAT` 잡힘 0.5~20 /1000 | 1.019 | 통과 |

못 넘은 까닭: 번식 쿨다운 200 스텝이 번식을 묶어, 사슴은 200 스텝 가운데 15~50 스텝만 먹으면 된다. 남는 시간이 많아 도망(짐승까지)이 먹이·번식에 거의 손해가
없다(번식 3.36 대 3.37 /1000). 설계 6절의 '죽음 한 번 ≈ 먹기 15~150 스텝' 저울은 번식이 먹은 양에 묶인다는 가정인데, 쿨다운이 그 가정을 깼다.
이대로면 두뇌가 '다가오는 것은 다 피하기'로도 손해가 없어 구분을 배울 까닭이 없다(P3 를 못 넘을 세계).

개발 시드에서 고칠 값을 찾았다(같은 50 세계, `calib/calibrate_<꼬리>.json`, 값 = 짐승 2 이상 세계 먹음 비 blind/oracle, 0.9 이하가 통과):

|---|---|---|
| cd80 · cd40 · cd20 | 쿨다운 80·40·20 | 1.02 · 0.96 · 0.96 |
| a · b | 쿨다운 40 + 짐승 [2, 8] · [3, 10] | 0.99 · 0.96 |
| c | 쿨다운 40 + 짐승 [2, 8] + 내달리기 몫 0.5 | 1.01 |
| d | 쿨다운 20 + 짐승 [3, 10] | 0.94 |
| e | 쿨다운 10 + 짐승 [3, 10] + 먹이 재생 [1, 3] | 0.92 |
| f · h | 쿨다운 10 + 짐승 [3, 10] (h: + 내달리기 0.5) | 0.94 · 0.94 |

| **i (고름)** | **쿨다운 20 + 짐승 [4, 12]** | **0.896** |

- 고친 설정(`configs/v3_r8_pilot.yaml`) 으로 다시 잰 값(`calib/calibrate.json`, `leak.json`): C0-1 0.329/1.017 = 0.32 통과, **C0-2 7.884/8.800 = 0.896 통과**,
  C0-3 AUC 0.520·바꿔치기 같음 통과, C0-4 1.017 통과. 고침은 이 한 번이다(설계 9-1).
- 솔직한 한계: C0-2 는 문턱을 겨우 넘었고, 같은 개발 시드에서 여러 값을 본 뒤 골랐다. 그래서 보조로 **섞인 무리**(같은 세계에서 짝수 칸 blind·홀수 칸 oracle —
  한 마리가 '짐승까지 피할 때' 치르는 값, 학습의 개체 보상과 같은 눈금)도 쟀다: 고친 세계에서 blind 칸 먹음 0.872 배·번식 0.837 배(설계 값 세계는 1.03·1.01).
  개체 눈금으로는 구분할 까닭이 분명히 생겼다.
- 대조 H0 설정은 짐승 [0, 0] 그대로(쿨다운 20 은 물려받는다).
