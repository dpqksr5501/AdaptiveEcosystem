# 도망길 단서 판단 규칙 (미리 적음 — 2026-10-22, 본 측정 전 · 같은 날 심사 지적으로 고침, 역시 본 측정 전)

도구: `results/v3/route/cues.py` (모듈 docstring 에 같은 규칙이 있다). 설계: `Docs/RL_Policy/RL_V3_FLIGHT_ROUTE_DESIGN.md` 9절.
사용자 결정(10-22): **"고를 단서부터 더 잼 (추천)"** — 학습 전에, 사슴이 그 순간 알 수 있는 단서로 '숲 그늘(COVER) / 은신처(SHELTER) / 그냥 달리기(RUN)'
가운데 어느 길이 나은지 가를 수 있는지부터 잰다.

## 무엇을 정하나

- 가를 수 있으면 → **길 고르기 계약으로 간다** (세 길 + 새 관측 칸).
- 가를 수 없으면 → **두 길(RUN + SHELTER) 안을 권한다.**

## 어디서 재나

- 세계: 스냅숏 `results/v3/live/pilot/eco_v3_snapshot_s20004_t475_e1.json` 의 N 세계(늑대 포만 끔), 지금 끝 규칙(quiet_end 0), 도주 밖 두뇌 obs21zero(기본).
- **판단 조건 = 숲 시야 켬** (잎 r 3.0 단위, block 2.0 단위). 숲 시야 끔은 견줌용(판단에 쓰지 않음).
- **판단 시드 36000~36099 × 지역 3** (숲·메마른 땅·고지). 쓴 적 없는 범위다: 앞선 도망길 측정(규칙 34900~34959, 오라클 34960~34999 — 이 물음의 가설
  'RUN 54·COVER 28·SHELTER 18 %' 를 만든 세계), 관문(35000~35199), R6 예정(33200~33299)과 겹치지 않는다. 연기 시험은 탐색 시드 34900~34902 만 쓴다.
- RUN 판 1800 스텝(4 분)을 끝까지 돌리며 **모든 도주 시작**을 베르누이로 솎는다 — 시작마다 균등 난수 하나:
  - 쫓기며 시작한 것(시작 스텝 끝에 사냥 중인 늑대가 이 사슴을 표적으로 둠 — 도망 기록 `_fl_tgt` 와 같은 셈): 확률 **0.30**
  - 쫓기지 않고 시작한 것: 확률 **0.015**
  - 뽑힐 확률이 알려져 있어 무게 = 1/p. 쫓김 층 안은 같은 무게(시작마다 평균), 모든 시작 = 두 층을 무게로 합친 값.
  - 확률은 연기 시험(runs/cues_smoke, 탐색 시드)으로 정했다: 세계마다 쫓긴 시작 약 100·쫓기지 않은 시작 약 446, 쫓긴 시작의 비기지 않은 몫 35 %
    (84 개, 한쪽 90 % 아래 끝 28 %) → 기대 쫓긴·비기지 않은 시작 약 3,100 (아래 끝 2,500), 쫓기지 않은 시작 약 2,000.
- **쫓김은 사슴이 모르는 값이다.** 층 표시로만 쓰고 고르는 모델에는 넣지 않는다(배포한 고르기는 모든 도주 시작에서 돈다).
- 시작마다 그 순간 세계를 복제해 RUN · COVER(가능하면) · SHELTER(가능하면) · OPEN(측정 전용) 을 난수 흐름 3 개씩 돌리고, 가짜 오라클(COVER·SHELTER
  팔마다 같은 흐름 열쇠의 RUN)도 돈다. 롤아웃 최대 300 스텝.

## 단서 (알 수 있음 P · 알 수 없음 X)

- **P 늑대 단서는 알아챈(wf_pvis — 눈(줄기·잎 가림 포함)·발소리) 사냥 중 늑대만** 쓴다(설계 7절·부록 '알아챔만'): 수, 가장 가까운·둘째 거리, 다가오는
  속력, 속력, 머리 방향과의 cos, 들림, 눈길 가림, 전력 걸음.
- 길 기하(cover_*·shelter_*·관측 22·23 의 재료)만 반사와 같은 늑대 집합 S(안전 거리 40 m 안 사냥 중 늑대의 실거리, hold_awake 면 깨어 있는 늑대 —
  설계 6절의 전제 '쫓는 늑대는 돌아보며 안다')를 쓴다.
- X(진단 전용): 알아챔과 무관한 실제 값(안전 거리 안 사냥 중 늑대 수·못 알아챈 수·무대 전체 수, 가장 가까운·둘째 사냥 중 늑대 거리와 다가오는 속력·
  알아챔), 늑대 종류, 표적(쫓김), 지역.
- 날씨는 지역마다 늘 같고 시야 배수·관측 visibility 로 알 수 있어, 날씨 이동 배수는 따로 단서로 두지 않는다.
- 보고에 'X 칸 가운데 P 칸의 정확한 일차식인 것'을 적는다(있으면 P 가 그 정보를 샌다 — 연기 시험: 없음).

## 잣대

- 값 = 고른 길의 **쫓긴 시간(초)** — 관문 1차 P1 과 같은 셈. 흐름 3 평균. 잡힘·굶음·안 끝남 = 40 초(300 스텝).
- 시드로 묶은 5 겹 교차 검증(GroupKFold — 한 시드의 세 지역은 늘 같은 겹)을 **모든 뽑은 시작에 한 번** 맞추고, 확인 몫의 고른 길로 잰다.
  - 분류기(깊이 3·6 나무, 부스팅 분류, 다항 로지스틱)는 **비기지 않은 시작만**(두 층 모두, 무게 1/p) 맞춘다 — 비긴 시작의 정답은 정의상 아무 길이다.
  - 'regret 직접'(길마다 쫓긴 시간을 부스팅 회귀로 예측해 가장 짧은 길)은 모든 시작(무게 1/p)으로 맞춘다.
  - 가능하지 않은 길은 고르지 않는다(가림).
- 견줄 기준: '늘 RUN', '늘 SHELTER(가능할 때, 아니면 RUN)', 오라클(가능한 두뇌 길 가운데 가장 짧은 것).
- 오라클 잡음 빼기: 오라클 − 가짜 오라클 이득(같은 수의 RUN 흐름 가운데 최솟값 − RUN).
- 신뢰구간: 같은 시작끼리의 차이를 시드로 묶은 95 % 구간(표준오차 = 시드별 무게·(차이 − 평균) 합, t(시드 수 − 1)).
- **가장 좋은 모델** = 알 수 있는 단서만 쓴 모델 가운데 **쫓긴·비기지 않은 시작**의 확인 몫 평균 쫓긴 시간이 가장 짧은 것.

## 판단 (숲 시야 켬, 알 수 있는 단서만)

**네 가지가 모두 맞으면 진행:**

쫓기며 시작했고 비기지 않은 시작(가능한 두뇌 길 사이에 쫓긴 시간이 다른 것)에서

1. 가장 좋은 모델의 평균 쫓긴 시간이 '늘 SHELTER' 보다 **0.3 초 이상** 짧다.
2. 그 차이가 '늘 SHELTER → 오라클(잡음 뺀 값)' 간격의 **30 % 이상**이다. (간격이 0 이하면 맞지 않음)
3. 모델 − 늘 SHELTER 의 시드 묶음 짝 **95 % 신뢰구간 위 끝 < 0**.

그리고 모든 도주 시작(쫓김·안 쫓김을 무게 1/p 로 — 배포 모집단)에서

4. 같은 모델의 모델 − 늘 SHELTER 95 % 신뢰구간 **위 끝 < 0**. (쫓긴 시작에서만 낫고 그보다 네 배 넘게 많은 쫓기지 않은 시작에서 손해를 보면 진행하지 않는다)

→ 길 고르기 계약으로 간다. 그 모델의 **순열 중요도 위 단서**(쫓긴·비기지 않은 시작 안에서 섞으면 평균 쫓긴 시간이 가장 많이 늘어나는 단서)를
새 관측 칸 후보로 적는다. 이미 관측 21 칸에 있는 단서는 따로 표시한다.

**하나라도 아니면:** 두 길(RUN + SHELTER) 안을 권한다.

## 판단하는 측정 (이와 다르면 판단하지 않는다)

- on 측정의 머리가 미리 정한 조건과 같다: 덮기(숲 시야 r 3.0·block 2.0), quiet_end 0, 흐름 3, 롤아웃 300, 판 1800, 고르기 확률 0.30·0.015, 기본 두뇌,
  위 스냅숏, 연기 시험 아님. 측정이 끝났고 셈 길 지문이 있다. 세계 = 시드 × 지역 3 이 다 있다.
- 시드 = 36000~36099 정확히.
- **연장 (미리 정함, 한 번만):** 판단 시드를 다 잰 뒤 쫓긴·비기지 않은 시작이 1,000 밑이면(개수만 보고 정한다) 같은 명령에 `--seeds 36000-36199` 를
  주어 36100~36199 를 이어 돌리고, 그 끝에 **한 번** 판단한다. 판단 시드만으로 1,000 이상인데 늘렸거나 다른 범위면 판단하지 않는다.
- **표본 조건:** 쫓긴·비기지 않은 시작 1,000 개 이상, 시드 30 개 이상. 모자라면 판단하지 않는다. 본 측정 목표는 3,000 개 안팎이다.
- 측정 중 `report` 는 개수만 낸다(모델·기준 표 눈가림 — 판단 시드의 결과를 도중에 보지 않는다).

## 함께 보고 (판단에 쓰지 않음)

- 모든 쫓긴 시작(비긴 것 포함)과 쫓기지 않은 시작의 같은 표.
- 숲 시야 끔 세계의 같은 표(고르기 확률 × 0.5) — 숲 시야가 COVER 를 고를 이유를 만드는지.
- **알 수 있는 단서 + 알 수 없는(특권) 단서**로 같은 모델 — 빠진 정보가 사슴이 알 수 있는 것인지 본다.
  - 특권 단서를 더해도 못 가르면: 결과가 그 순간 뒤의 우연(늑대 움직임 등)에 크게 달린다 — 단서를 더 찾아도 얻을 것이 적다.
  - 특권 단서를 더하면 가르면: 빠진 정보가 사슴이 알 수 없는 것(늑대 종류·표적·못 알아챈 늑대 등)이다.
- '늘 RUN' 대비 이득, 정확도(가장 짧은 길을 고른 몫), 지역별 평균, OPEN 까지 넣은 오라클.

## 알려진 한계

- 가장 좋은 모델을 같은 확인 몫에서 고르므로 조금 낙관적이다. 문턱(0.3 초 · 30 % · 두 신뢰구간)이 그 여유다.
- 정답 표지는 흐름 3 평균이라 잡음이 있다. 오라클 간격은 잡음 뺀 값으로 잰다.
- 판단 1~3 의 '쫓김 · 비기지 않음'은 사슴이 모르는 값과 결과로 고른 부분 집합이다. 그래서 판단 4 가 같은 모델을 모든 시작에서 본다.
- 길 기하 단서는 반사의 S(안전 거리 안 사냥 중 늑대의 실거리)를 쓴다 — 설계 6절의 전제이고, 못 알아챈 늑대의 거리가 경주 여유로 들어갈 수 있다.
- 고르기 확률은 탐색 시드의 연기 시험(쫓긴 시작 84 개)으로 정했다 — 판단 시드의 결과는 보지 않았다.

## 고친 내력 (10-22, 본 측정 전 — 심사 지적)

- **표본:** 쫓기며 시작한 도주만 → 모든 도주 시작(쫓김 층 확률 0.30·아닌 층 0.015, 무게 1/p), 판단 4 를 더했다. 쫓김(표적)은 사슴이 모르는 값이라
  쫓긴 시작만의 '진행'은 배포 판단이 아니다(앞선 m1·m2: 모든 도주 평균에서는 COVER 가 해롭다).
- **고르기:** 고른 시각 뒤 첫 쫓긴 시작(앞 빈틈 길이에 비례해 뽑힘 — 쉬다가 처음 쫓긴 시작이 많이 뽑힘) → 시작마다 알려진 확률. 연기 시험에서 쫓긴
  시작의 비기지 않은 몫이 47 %(옛 방식, 15 개) → 27~35 %(새 방식, 33·84 개)로 바뀌었다.
- **단서:** 알아채지 못한 늑대·안전 거리 밖 늑대가 P 단서로 샜다(wolf2_dist_m 가 40 m 밖 못 알아챈 늑대의 실거리, 못 알아챈 가장 가까운 늑대의 속력·
  방향, X 인 n_unnoticed_safe = P 인 n_hunt_safe − n_noticed) → P 는 알아챈 늑대만, 실제 값은 X(wolf_any_*·n_hunt_safe). 머리 방향은 acos 각 대신
  cos(wolf_bearing_cos — 세계 식 그대로, C++ 로 옮길 때 삼각함수가 없다). 날씨 이동 배수는 P 의 정확한 함수라 뺐다.
- **시드:** 34900~34999(오라클 34960~34999 가 가설을 만든 세계와 겹침) → 36000~36099. 35000~35199 는 관문 시드라 쓰지 않는다.
- **판단 조건 점검:** 덮기·끝 규칙·흐름·롤아웃·판·확률·두뇌·스냅숏·시드가 미리 정한 것과 다르면 판단하지 않는다. 연장은 위 한 번만. 중간 보고 눈가림.
- **분류기:** 비긴 시작(정답이 RUN 으로 떨어짐)을 맞춤에서 뺐다.
- 쓰지 않던 OPEN 가짜 롤아웃을 뺐다(시작당 롤아웃 수 최대 21 → 18).
