# 야생 2단계 — 1 은신처 먹이 부족 + 사냥 성공률, 2 늑대 무리·협동 사냥, 3 세로 장애물, 10-17 고침 (10-17)

명세 `AdaptiveEcosystem/Docs/RL_Policy/RL_V3_WILD2_SPEC.md`. 두뇌는 게임 두뇌 R1b-F 그대로다(재학습 없음).

## 10-17 고침 — 은신처 먹이 부족을 다시 켠 지금 기본값으로 다시 잼

**무엇을 고쳤나.** 2 늑대 무리를 넣을 때(40b0c58·1b11c78) 사용자 말 '추천대로 끄고 2~4번 진행해'(10-17)를 '은신처 먹이 부족을 끄라'로 잘못 읽었다.
그 말은 팀 무리 경보 연결(`eco.IntegratedV3.SocialControl`)을 추천대로 끄고 2~4 단계를 하라는 뜻뿐이었다. 사용자의 서 있는 결정(10-14·10-15)은
'은신처는 안전하지만 먹이가 적다 — 배고픈 사슴은 나와야 한다'다. 그래서 다시 켰다.

- 파이썬: `configs/v3_wild2_pack_mirror.yaml`·`v3_wild2_obstacle_mirror.yaml` 에 `realism_cover_food`(0.15) 블록을 넣었다. 두 파일이 지금 거울이다
  (pack = `v3_wild2_mirror.yaml` + 늑대 4 + 협동, obstacle = pack + 세로 장애물). 고침 전 판은 `run_mirror.py --disable realism_cover_food` 로 똑같이 다시 나온다
  (`d128_pack` 을 다시 돌려 10초 줄이 모두 같음을 확인했다 — 그 뒤 더한 무리 칸만 새로 있다).
- 언리얼: `eco.IntegratedV3.ShelterFood` · `-EcoV3ShelterFood=` 기본 1(`FEcoV3IntegratedSettings::bShelterFood` 참). 끄려면 `-EcoV3ShelterFood=0`.
- 지금 기본값 = 늑대 4(잠행 2·추격 2) + 협동 사냥 + 늑대 몸 여유 1 m + 은신처 먹이 부족 + 세로 장애물 켬. 팀 레벨 무대에는 충돌하는 나무·바위가 없어
  (3 절) 언리얼 기본의 거울은 `v3_wild2_pack_mirror.yaml` 이다. 장애물 판은 앞과 같이 파이썬 원판을 넣어 쟀다(측정 전용 `-EcoV3ObstacleImport=`).
- 골든 헤더(`PackGoldenVectorsV3.h`·`ObstacleGoldenVectorsV3.h`)는 바뀐 설정으로 다시 만들어도 바이트 단위로 같다(한 스텝 장면은 먹이를 읽지 않는다).

### 결론

1. **은신처 안 시간이 12.3 → 8.1% 로 준다. 잡힘은 그대로다(5.03 → 5.10%).** 같은 시드 90쌍 세계마다 잡힘 +0.08마리(표준오차 0.14), 은신처 안 −4.2%p(0.45).
   사냥 성공률도 그대로다(55.7 → 56.4%). 1단계(늑대 2)에서 본 것과 같다.
2. **16분 판은 굶음이 는다(16.5 → 20.8%), 산 사슴은 63.4 → 58.4%.** 같은 시드 30쌍 세계마다 굶음 +5.6마리(2.4). 굶음은 480초 뒤에 늘어난다
   (누적 480·720·960초 = 207·433·632 → 218·591·799). 사용자 결정 그대로 '배고픈 사슴이 나와야 하는' 세계라 굶음이 는 것이다.
3. **세로 장애물을 더해도 같은 꼴이다.** 은신처 안 11.1 → 6.8%, 잡힘 5.49 → 5.60%(+0.14, 0.14), 사냥 성공률 39.8 → 44.5%. 16분 굶음 18.7 → 20.2%(+2.0, 1.9).
4. **언리얼 기본값은 같은 지도의 파이썬과 산·잡힘·굶음·은신처 안 시간이 같다**(세션 20000~20002 와 20006~20008, 그 네 칸 모두 |z| < 1). 숲(Forest)만 봐도 그 칸들은 |z| < 2.
5. **남은 차이 하나: 먹이 부족을 켜면 언리얼의 사냥 시작이 파이썬보다 많다.** 두 세션 묶음 합 231 대 203.5(+14%, 합친 z 약 +3.5) — 추격형·잠행형 모두
   많다. 끝난 사냥도 같이 많아 성공률은 낮게 나온다(50.9 대 60.0, 57.1 대 62.5). 잡힘 수는 같다. 먹이 부족을 끈 판(같은 세션)에서는 차이가 없다
   (204 대 208.5). 첫 묶음에서 언리얼 사슴 에너지가 낮았는데(z −2.9) 둘째 묶음에서는 반대(z +2.1)라 먹이 쪽 차이로 보지 않는다. 원인은 아직 모른다
   (다음에 볼 곳: 은신처 둘레를 드나드는 사슴과 추격형이 표적을 놓치는 경우 — 언리얼에만 있는 은신처 생명주기 `RefreshRefuges`·잃은 HIDE 목표 풀기).
6. 장애물 + 먹이 부족 판(같은 원판)은 언리얼 잡힘이 조금 많다(5.99 대 5.45%, z +3.0 — 범위 5.21..5.73 밖). 세션 한 묶음뿐이라 지금은 흔들림 후보로 둔다.

# 야생 2단계 1 — 은신처 먹이 부족 + 사냥 성공률 (10-17)

설정 `configs/v3_wild2_mirror.yaml`(= `v3_wild1_mirror.yaml` + 은신처 먹이 부족). 2·3 의 처음 측정은 사용자 말을 잘못 읽어 이것을 껐다 —
10-17 고침으로 다시 켰다(맨 위). wild1 = 지금까지의 기준(1단계 + 10-16 고침 + 10-17 늑대 몸 여유), wild2 = 그 위에 은신처 먹이 부족.

## 결론

1. **늑대 사냥은 이미 잘 성공한다. 모자란 것은 사냥 횟수다.** 사냥 한 번 성공률은 57%(파이썬 거울, 240초)로 현실 목표 띠 10~30% 보다 훨씬 높다.
   늑대 한 마리가 게임 하루(2분)에 사냥을 1.3번만 시작한다. 먹고 나면 60초 쉬고 밤에는 자기 때문이다. 그래서 잡는 수가 적다(하루 0.7마리).
2. **은신처 먹이 부족은 은신처에 숨는 시간을 줄였다.** 사슴이 은신처 원 안에 있는 시간이 10.9% → 6.8% 다(16분 판 10.3 → 5.8%).
3. **그런데 잡힘은 늘지 않았다.** 240초 2.10 → 2.20%, 16분 9.2 → 9.1% 로 흔들림 안이다. 늑대 사냥 횟수(하루 1.3번)가 그대로라서다.
4. **오래 두면 굶음이 는다.** 16분(게임 8일) 굶음 13.4 → 17.7% 다(같은 지도 30쌍, 세계마다 +5.4마리, 표준오차 1.8). 무대 먹이 총량이 평균 12% 줄었고(0~25%),
   굶음은 가난한 지도 10장에 몰린다(443 → 547마리, 풍부한 지도 10장은 2 → 3마리). 은신처 안 잡힘은 모두 0 이다.
5. **언리얼도 같다.** 은신처 안 시간 5.9% 대 파이썬 5.8%(같은 지도 짝 비교), 독립 지도 7.5% 대 6.9%. 잡힘·사냥 성공률도 모든 칸이 |z| < 2 다
   (짝 비교의 '사냥 시작' 하나만 z +2.1 — 독립 지도 세션에서는 z +0.5 라 표본 흔들림으로 본다). 숲(Forest)도 따로 보았다(아래 표).
6. 그래서 다음 단계 2(늑대 무리 4마리·협동 사냥)는 성공률이 아니라 **사냥 횟수**를 늘려야 한다. 성공률은 오히려 목표 띠 쪽으로 내려와도 된다.

## 사냥 성공률 정의 (파이썬·C++ 같음)

- 사냥 한 번 = 한 늑대가 전력으로 달린 스텝들이 이어진 것(추격형이 표적을 쫓음·잠행형 덮치기·플레이어 돌진 — 발소리 규칙의 전력 걸음).
- 성공 = 그 사냥이 이 늑대의 포획으로 끝남(전력 걸음이 끊긴 첫 스텝에 잡아도 성공). 실패 = 잡지 못하고 전력 걸음이 끊김. 성공률 = 성공 ÷ 끝난 사냥.
- 사냥 중이 아닌 늑대가 잡은 수는 '사냥 밖 포획'으로 따로 센다(이번 측정에서 0~1). 늑대만 센다.
- 현실 목표 띠 10~30%: 사냥 한 번 성공률 10~49%(Mech & Peterson 2003), 옐로스톤 엘크 혹독한 겨울 26%·포근한 겨울 15%(Mech 외 2001). 어림.
- 파이썬 `env_v2/world.py` `hunt_update`·`World.hunt_stats()`, 언리얼 `EcoWorldV3.h` `HuntUpdate`·`FWorldStats::Hunt*`, 10초 기록 다섯째 줄 `[EcoV3I] <지역> 사냥·은신처 |`.

## 파일

- `run_all.sh` — 파이썬 측정 묶음(결과 `runs/`, 커밋하지 않는다 — 끝 묶음이 2 늑대 무리). `summarize.py` — 위 파이썬 표(둘째 표 = 늑대 무리 칸).
  `compare_unreal_wild2.py` — 언리얼 견줌(언리얼 여섯째 줄 '늑대 무리 |'와 파이썬 10초 줄 pack_* 이 있으면 무리 칸도 견준다).
- `unreal_logs/` — 줄을 고른 언리얼 기록(커밋한다). `food*_…` = 1 (늑대 2), `pack_…` = 2 (늑대 4 + 협동, 먹이 부족 끔), `obst_…` = 3 (먹이 부족 끔),
  `packfood_…`·`obstfood_…` = 10-17 고침 뒤 지금 기본값(먹이 부족 켬), `pack_s20006-20008` = 같은 세션의 먹이 부족 끔 대조.
