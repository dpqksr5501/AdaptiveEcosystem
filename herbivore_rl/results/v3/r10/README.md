# R10 — 16 종 범용 동물 두뇌 (파이썬 학습·평가 줄기)

설계 `AdaptiveEcosystem/Docs/RL_Policy/RL_R10_UNIVERSAL_FAUNA_DESIGN.md`(사용자 답 16 절) · 0 단계 사양 `RL_R10_PHASE0_SPEC.md`.
R9(`env_v2/r9_*`, `results/v3/r9/`)는 그대로 두고 새 꾸러미 `herbivore_rl/r10/` 에 짰다.

## 무엇이 다른가 (R9 → R10)

| | R9 | R10 |
|---|---|---|
| 세계 | 평평한 2D 정사각형 | 높이·물·가림·먹이 층이 있는 무작위 지형(`r10/mapgen.py`), 땅·물·하늘 몸 물리 |
| 종 | 6 종 한도, 코드에 종 이름 | 종 카드 16 개(`herbivore_rl/species/*.json`), 코드에 종 이름 없음 |
| 누가 누구를 무나 | 종 표 | 몸무게 비율 하나(`combat.kill_mass_ratio`) + 같은 매체 + 머리 앞·다가감 |
| 감각 | 115 칸 | 206 칸(자기 16·몸 18·8 방향 × 6·발밑 6·다른 동물 8 × 12·같은 종 4·환경 6·예비 12) |
| 행동 | 19 칸 | 24 칸(오르기·내리기·급강하·덮치기 + 예비 1), 몸이 못 하는 칸은 감각으로 막음 |
| 행동 고르기 | 확률·가장 높은 칸 | 학습·실행 모두 확률 뽑기 (가장 높은 칸은 진단용) |
| 몸 숫자가 바뀌면 | 몸 해시 거부 → rebody | 몸 벡터가 감각에 있고 학습 때 ±15% 흔듦 → 범위 안이면 그대로 |

## 명령 (herbivore_rl/ 에서, PYTHONUTF8=1)

```
python -m pytest -p no:cacheprovider -q tests/test_r10_base.py tests/test_r10_world.py
python -X utf8 results/v3/r10/make_cards.py                                     # 종 카드 다시 만들기
python -X utf8 results/v3/r10/eval_r10.py --only deer wolf boar --flat           # 모두 규칙 두뇌 (잣대)
python -X utf8 results/v3/r10/train_r10.py --species deer --only deer wolf boar --flat --decisions 5000000 --out ckpt/r10/small
python -X utf8 results/v3/r10/eval_r10.py --only deer wolf boar --flat --brain deer=ckpt/r10/small/deer_<결정>.npz
```

## 언리얼에서 돌리기

```
python -X utf8 results/v3/r10/export_r10.py --brains-dir ckpt/r10/all1 --out ../AdaptiveEcosystem/Saved/R10Demo
```
- 켜기: 명령줄 `-EcoR10Demo[=폴더]`, 콘솔 `eco.R10Demo 1` (Play 전이나 Play 중). `eco.R10Demo.OnlyMap` 에 맵을 두면 콘솔 값으로 켠 판은 그 맵에서만.
  이 PC 는 `Config/UserEngine.ini`(git 제외)에 `eco.R10Demo=1` · `OnlyMap=/Game/EcoTest/Maps/LV_EcoV3_Island` — 섬 맵 Play 하면 바로 뜬다. R10 이 켜지면 그 실행의 R9 데모는 꺼진다.
- 플레이어 둘레 300 m 를 1 m 칸으로 훑어(학습 맵과 같은 칸) 높이·물·나무·가림을 코어 지형 층으로, 먹이는 mapgen 규칙으로 만든다. 물이 영역 밖이면 가장 가까운 물가 쪽으로 옮긴다.
- 종마다 8 마리(상한 12), 죽은 칸은 50 결정 뒤 다시 남. 결정마다 감각 → 개체마다 시드 둔 확률 뽑기 → 한 결정. 두뇌가 없는 종은 공통 규칙 두뇌.
- 단축키: N/P 종 · `,` `.` 개체 · T 위에서 · F 자유 · H 글.
- 알려진 것: 섬 메시 이름으로는 덤불·바위가 거의 안 잡혀 은신처는 가림 값만 있고 보이는 물체가 없다 · 먹이 층은 그리지 않는다 · 화면은 코어 x·y 를 언리얼 X·Y 그대로(거울 꼴, 코어 안에서는 일관).

## 정식 학습

```
python -X utf8 results/v3/r10/run_stage_r10.py --stage ground --out ckpt/r10/stage1 --init-from ckpt/r10/all1
```
- 설계 10·16 절 차례: 땅 10 종 → 하늘 2 종(까마귀·검독수리) → 물 4 종(밍크·메기·잉어·작은 물고기). 앞 단계 종은 이어 배운다.
- 리그: 같은 폴더에서 함께 배우는 다른 종의 최신 두뇌를 100 만 결정마다 다시 읽어 상대로 쓴다(상대도 확률 뽑기).
- 사냥하는 몸은 밀도 단계(처음 30~45 m 맵·먹잇감 종마다 4~8, 300 만 결정에 걸쳐 보통 범위로).
- 하늘·물 단계 앞에 먹이·기운 숫자를 맞춘다(규칙 잣대 16 종: 검독수리 굶음 1.6/k, 물고기 0.46~0.77/k).

## 지금 알려진 것 (2026-11-19)

- **먹이·기운 숫자는 아직 맞추지 않았다.** 크기 법칙 어림이다. 16 종 규칙 두뇌 시험에서 물고기가 수위가 내려가면 물 밖에 갇히고(물에서 죽음), 검독수리는 규칙 두뇌로 사냥을 못 해 굶는다. R9 C0 관문처럼 학습 앞 관문에서 맞춘다.
- **언리얼 값으로는 사슴(9 m/s)이 늑대(7.2 m/s)보다 빠르다.** 11-19 언리얼 Native 늑대의 덮치기(13.5 m/s · 1.6 s, 뒤에 1.8 m/s · 4 s)를 몸 능력(`body.burst_*`)과 행동 22 로 넣었다. 언제 덮칠지는 두뇌가 정한다.
- **언리얼 RuleFauna 는 종 이름 목록으로 사냥한다.** Native 사슴은 규칙 포식자가 못 잡는 식의 제약도 있다. R10 은 몸무게 비율로 정하므로, 언리얼에 넣을 때 실행기 쪽 규칙을 맞춰야 한다(12 절, 조연우 님과 범위 정하기).
- 환경 감각의 '큰 소리 방향'은 파이썬 세계에 플레이어가 없어 늘 0 이다.
- 마스크 정책은 sb3-contrib 없이 직접 짰다(이 PC 에 설치가 막힘). 감각의 몸 벡터(b_swim·b_fly)로 막을 칸을 계산한다.

## 작은 확인 결과 (2026-11-19, 평평한 맵·사슴·늑대·멧돼지, 종마다 500 만 결정, 점검 시드 60000~60015)

| 사슴 두뇌 | 끝/시작 | 물림/k | 굶음/k | 기운 |
|---|---|---|---|---|
| 규칙 | 67/96 | 0.160 | 0.098 | 0.82 |
| 배움 · 가장 높은 칸 | 60/96 | 0.034 | 0.270 | 0.39 |
| 배움 · 확률 뽑기 (`--sample`) | 76/96 | 0.104 | 0.069 | 0.83 |

- **배운 두뇌는 학습 때처럼 확률로 뽑아야 한다.** 가장 높은 칸만 고르면 사슴이 빈 칸에서 먹기만 되풀이한다(먹기의 91 % 가 먹이 없는 칸). 확률로 뽑으면 9 % 로 준다. 언리얼 실행기도 개체마다 시드를 둔 확률 뽑기로 맞춰야 한다.
- **늑대는 500 만 결정으로 사냥을 배우지 못했다.** 확률 뽑기에서 늑대 죽임이 0.044/k 로, 규칙 늑대의 0.157/k 보다 낮다. 사슴(9 m/s)이 늑대(7.2 m/s)보다 빠르고, 언리얼 Native 늑대가 실제로 쓰는 덮치기(지각 12 m 안에서 13.5 m/s · 1.6 s, 뒤에 4 s 지침 — `card_sources/wolf.json` pounce)가 종 카드에 없다.
- 학습 줄기 보상: 사슴 −9.7 → 약 22, 늑대 0 → 약 1.5.
