## 4. 판정 기준 (고른 모델 R7 하나 vs route0, 같은 시드 짝) — R6 4절 그대로

- 짝 단위 = 시드(지역 셋의 분자·분모를 각각 더한 뒤 나눈 몫). 문턱 = t 분포 양쪽 5%: N 은 t_crit(n − 1) = **+1.984**(n 100), G 는 **+2.023**(n_G 40).
  P1·GH 는 두 두뇌 모두 쫓긴 도망이 1 개 이상인 시드 n₁ 에서 t_crit(n₁ − 1)(빠진 시드가 없으면 1.984).
- 도구 `r7_eval.py judge` — 셈은 R6 판정과 같은 함수다(1차·GH·GN·GF·GV·GC·GG·G4·G5·G6 = `live.gate_live`, GT·GTr·GR = `r6_eval.route_guards`).

### 4-1. 1차 P1 (`P1_N_hide`)

- N 세계 **숨음 비율** = 쫓긴 도망(끝난 도망 가운데 끝 까닭이 unchased·truncated 가 아닌 것) 가운데 끝 까닭 cover 이고 그 사슴이 도망이 끝난 스텝 뒤 75 스텝(10 초)
  안에 잡히지 않은 몫(판이 그 안에 끝나면 지켜본 만큼 — 잡히지 않았으면 숨음, 지켜보는 동안 굶어 죽으면 숨음이 아님). 정의 LIVE_GATE 5-1·`World.flight_stats()['hide']`·
  `live.hide_pair`.
- **통과: R7 − route0 숨음 비율 짝 차이 > 0 이고 짝 t ≥ +1.984**(n₁ 100). 최소 차이 δ 는 0(유의성만).

- **R7 − 손 규칙 '늘 SHELTER'**(같은 시드): 숨음 비율·잡힘 비율·잡힌 몫·쫓긴 시간·GF·GR('늘 SHELTER' − route0 의 GF·GR 도 — R6 사후 셈에서 GF t +3.06 · GR t +6.73).
- 지역별(메마른 땅·숲·고지): 숨음 비율·잡힘 비율·잡힌 몫·GF·GR 짝 차이와 R7 SHELTER 몫(메마른 땅은 학습 지역 표에 없는 배치다).

- 그 밖: 학습 곡선(길 결정 수·π SHELTER·반사 밖 두뇌 FLEE 0 / 덮기 밖 결정 — 학습 기록 줄), 행동 몫.

### 4-4. 기대 크기와 검정력 (판정에 쓰지 않는다)

- 판정 뒤 진단(`results/v3/r6/diag/diag.md` — R6 점검 시드 37120~37139 × 지역 셋, n 20, 재학습 없이 평가 때만 막음)의 'R6 s1 + 반사 밖 FLEE 막음' 대 route0:
  - 숨음 비율 +6.82 %p(t +9.49) → 시드 짝 sd 약 **3.2 %p**. n 100 이면 숨음 비율 차이 약 **0.9 %p** 를 검정력 80% 로 가른다((1.984 + 0.842) × 3.2 / √100).
  - GF −0.086(t −1.23) → 시드 짝 sd 약 0.31. n 100 이면 GF 가 route0 보다 약 **+0.062**(route0 2.06 의 3%) 넘게 커지면 걸린다.
  - GR −4.5/시드(t −0.74) → 시드 짝 sd 약 27/시드. n 100 이면 GR 이 시드당 약 **+5.4 번**(route0 108 의 5%) 넘게 늘면 걸린다.
- 그래서 GR 이 가장 예민하다. 진단에서 막은 R6 두뇌의 GR 초과 −4.5 는 (가) 은신처 들락날락 +3.1(t +0.54) · (나) 그 밖 −7.6 · (다) 두뇌 스스로 뛰기 −0.1 로
  나뉘었다. R7 이 SHELTER 를 더 자주 고르도록 배우면 (가)가 늘 수 있다 — '늘 SHELTER' 규칙은 (가) +40.9(t +5.24)로 GR 이 걸렸다(진단 2절).
- 진단 값은 다시 배우지 않은 두뇌의 값이다. R7 은 막은 채 다시 배우므로 길 고르기·숨기 몫이 달라질 수 있다(설계 17-6).

## 5. 본 학습 2M·5M 점검 (판정이 아닌 제외·멈춤 — R6 5-1·5-3 + GF·GR)

### 5-1. 재는 것 (`early_checks.py` → `r7_eval.early_check`, 기준 판 = route0 같은 시드 `runs/early_base.json`)

체크포인트 `ckpt/v3/v3_r7_g995_s<시드>_20m_2m.zip`·`_5m.zip`(대조는 `v3_r7off_g995_s0_20m_<k>m.zip`)마다 점검 시드 38120~38139 × 지역 셋, N, 1800 스텝,
두뇌 argmax. 탐침(`r6_eval._Probe`)은 같은 세계를 같은 두뇌로 돌리면서 결정·궤적을 바꾸지 않고(시험 `test_world_gate_and_probe_keep_world`) 아래를 잰다.

- **(a) 길 고르기가 움직였나**: SHELTER 가 열린 도주 길 결정에서 학습 표본 확률 π′(SHELTER)(ε 0.05 섞음) 평균 − route0 같은 시드 값(0.138) 의 **|차이| > 0.05**.
  대조 '길 끔'은 보지 않는다.
- **(b) 가치망**: 도주 스텝(산 사슴 ∧ 다음 스텝 덮기 = 도주) 표본의 설명 분산 1 − Var(G^λ − V)/Var(G^λ) **> 0**, 수익 목표 = λ 0.98 의 λ-수익(R6 5-1 그대로 —
  γ 0.995, r = 그 세계 보상, 도주 비용 0). 점검 판 전체(60 세계)를 합쳐 셈한다. 몬테카를로 수익(λ 1)의 설명 분산은 보고만.
- **(c) 나빠지지 않았나** (route0 대비, 시드 짝 n 20):
  - 숨음 비율 짝 t **> −2.0**, 잡힘 비율(쫓긴 도망 가운데) 짝 t **< +2.0**, 잡힌 몫(사슴 가운데) 짝 t **< +2.0** — R6 5-1 그대로.
  - **GF**(1000 산 사슴-스텝당 시작한 도망) 짝 t **< +2.0**, **GR**(살아 끝난 도망 뒤 5 초 안 다시 도망 수) 짝 t **< +2.0** — R7 에서 더한 칸(R6 교훈).
    셈은 판정 GF·GR 과 같은 함수다(`live.flight_rate_pair` 'starts' · `r6_eval.route_seed` 의 refled). 문턱 +2.0 은 (c) 의 다른 칸과 같은 수다
    (시드 20 의 t_crit(19) 2.093 보다 조금 엄하다).
  - 대조 '길 끔'(판 6)은 길 기록이 없어 GR 을 세지 않는다(보고만 판이라 제외·멈춤에 쓰지 않는다).
- **결함**: 얼기·잠 몫 > 0, COVER 칸(3) 확률 > 0, 마스크 밖 SHELTER > 0, **반사 밖 두뇌 FLEE > 0**(막음 통계 `gate.brain_flee` — 판 5·6 마스크가 막으므로 0 이어야
  한다) — 하나라도 있으면 모든 학습을 멈추고 고친다.
- 보고만: R5 점검 칸(도망 몫·은신처 안·굶음), 길 기록, 두뇌 스스로 뛴 도망(길 none) 수, 몬테카를로 설명 분산.
- R6 기록을 같은 셈으로 보면(보고만 — `results/v3/r6/logs/judge_notes.txt` 2절) R6 세 시드는 5M 점검에서 GR t +11.42~+28.94 였다 — 이 (c) 였다면 셋 모두 제외되어
  판정 전에 멈췄다. s2 의 2M 은 GF t +1.20 · GR t +1.85 로 아직 넘었다(그래서 2M·5M 둘 다 본다).
