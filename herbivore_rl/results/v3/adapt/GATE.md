# 적응 고리 관문 — 미리 적은 규칙 (확정 2026-10-18, 첫 고리를 돌리기 전)

- 작성: 권신혁(RL·정책), 2026-10-18. 이 파일을 커밋·push 한 **뒤에** 첫 고리(학습·판정)를 돌린다. 판정 시드 33000~33099 로 이 고리의 후보를 돌린 것은 아직 없다.
- 사용자 말(10-18): '나무나 풀 같은 식생이 점점 변해서 환경이 달라지면 그 정보가 없는 상태로 사슴은 학습이 되어 있잖아? 거기에 적응이 안 된 상태니까
  우리가 계획한 가중치 로더 써서 두뇌 바꿔 주는 기술을 한번 적용해 보자. 바뀌는 환경에 맞는 적응을 시키는 거지.'
- 앞 문서: 시즌 재학습 계획 `AdaptiveEcosystem/Docs/RL_Policy/RL_SEASON_RETRAIN_PLAN.md`(4.2 채택 판정 — 1차 양은 게임에서 보이는 결과, 기본 결과는 기각),
  스냅숏 명세 `SEASON_SNAPSHOT_SPEC.md` 11절, R4 사전 등록 `results/v3/r4/PREREG.md`(같은 꼴의 기준 — 이번 관문은 그 축소판).
- 도구: `results/v3/adapt/adapt.py`(이 파일의 값은 코드의 `GATE` 상수와 같다. 바꾸려면 이 파일 변경 기록에 먼저 적는다).

## 0. 한 줄

후보 두뇌가 **지금 게임 두뇌보다 사슴을 유의하게 덜 잡히게 하고**, 굶음·산 수·지역마다·은신처 안 잡힘·끼임·은신처 악용 어느 것도 나빠지지 않을 때만
두뇌 파일을 낸다. 하나라도 못 넘으면 기각이고, 게임 두뇌는 그대로다. **기본 결과는 기각이다**(계획 0.2·1.5, R4).

## 1. 세계

- 스냅숏 세계 = `adapt.py convert` 가 스냅숏에서 만든 `runs/<이름>/world.yaml`(바탕 `configs/v3_wild3_mirror.yaml` + 바뀐 칸) + 지역마다 스냅숏의 날씨·장애물 원판·
  **먹이 용량 격자(언리얼 값 그대로)**. 부활 없음, 사슴 = 스냅숏 입양 수, 늑대 = 스냅숏 수, 두뇌 argmax(배포 모드).
- 학습 세계 = 같은 세계 + R4 학습 바꿈(학습 전용: 죽은 사슴은 늑대에게서 40 m 밖에 다시 남, 학습 시드 풀 32000~32049, 세계 8·교체 5000·지역 섞기 1:1:1).
  먹이 지도는 스냅숏 지도(`--train-food snapshot` 기본).
- K2-B 대조 세계 = 지금 두뇌가 원래 배운 세계 `configs/v3_r1.yaml`(나무·날씨·야생 규칙 없음) — '스냅숏 정보 덕분인가, 그냥 더 배워서인가'를 가른다(계획 5.3).

## 5. 관문 (판정 세계: 33000~33099 × 지역, 16 분, 짝 = 시드(지역 합), 시드 100, 짝 t 자유도 99)

| # | 기준 | 통과 | 까닭 |
|---|---|---|---|
| R (먼저) | 재현 확인: 지금 두뇌로 스냅숏 세계를 스냅숏 시각까지 (파이썬 시드 20 × 지역) | 지역 합 잡힘·굶음·산의 언리얼 값이 파이썬 분포에서 \|z\| ≤ 3 (sd 바닥 0.5 마리) **그리고** 지역마다 \|언리얼 − 파이썬 평균\| ≤ max(3 × sd, 3 마리) | 거울이 지금 게임과 다르면 배운 두뇌도 게임에 맞지 않는다(명세 9.3). 실패하면 학습하지 않는다. 지역 하나의 \|z\| 만 보지 않는 까닭은 변경 기록 (1) |
| P1 (1차) | 16 분 잡힌 몫 | 후보 − 지금 < 0 이고 짝 t ≤ −1.984 | 계획 4.2·#S14 의 1차 양 = 게임에서 보이는 결과(피식률) |
| P1b | 16 분 잡힌 몫, 후보 대 K2-B | 후보 − K2-B < 0 이고 짝 t ≤ −1.984 | P1 을 넘었을 때만 잰다(못 넘으면 잴 까닭이 없다). 그냥 더 배운 몫이면 기각(계획 4.2 A1(b)) |
| G1 | 16 분 굶은 몫 | 짝 t < +1.984 | 덜 잡히는 대신 굶으면 안 된다 |
| G2 | 16 분 산 몫 | 짝 t > −1.984 | |
| G3 | 지역마다 잡힘·굶음·산 | 잡힘·굶음 t < +2.626, 산 t > −2.626 (양쪽 1%, 칸이 많아서) | 어느 지역도 나빠지지 않는다 |
| G4 | 은신처 안 잡힘 | 후보 판정 세계 모두 0 | 은신처 안전 규칙 |
| G5 | 끼임 (`results/v3/wild2/stuck_check.py` 와 같은 셈, 끼임 세계) | 사슴 원판 끼임 0, 늑대 원판 끼임 ≤ 지금 두뇌 | 나무 사이에 끼는 행동을 배우지 않았나 |
| G6 | 악용 | 은신처 안 몫 ≤ 지금 두뇌의 2배, 먹기·도망·숨기 모두 1% 넘게 | 은신처 웅크림으로 이기지 않았나 |
| A5 (내보낼 때) | 두뇌 파일 다시 읽기 | sha256 같음, 골든 로짓 오차 ≤ 1e-4, 행동 같음, NaN·Inf 없음 | 언리얼 로더와 같은 검사의 파이썬 판(로더도 다시 본다) |

- **통과 = R, P1, P1b, G1~G6, A5 모두.** P1 을 못 넘으면 곧바로 기각(P1b·K2-B 학습은 하지 않는다). 지킴 기준이 하나라도 걸리면 기각.
- 통과하면 `export` 가 두뇌 파일을 `AdaptiveEcosystem/Saved/EcoBrains/`(git 밖, 언리얼이 찾는 폴더)에 쓴다 → 언리얼 `eco.V3Brain.Load <이름>`(또는 폴더 감시).
- 기각이면 두뇌 파일을 쓰지 않는다. 기각 까닭은 `runs/<이름>/gate.md`·`export.json` 에 남는다.
- 같은 두뇌여도 지킴 기준이 우연히 하나 걸릴 몫은 약 12%다(R4 와 같은 어림). 나빠짐을 놓치지 않는 쪽을 골랐다.

## 6. 미리 적는 예상 (첫 고리 — 지금 레벨 나무 + 날씨 대 나무·날씨 없이 배운 R1b-F)

- **기각될 것 같다.** R4 가 같은 세계(먹이 지도만 파이썬 난수)에서 6 시드 × 20M 을 배우고도 16 분 잡힌 몫을 못 줄였다(21.65 대 21.76%, t −1.10).
  이 세계에서 잡히는 수는 늑대가 배고픈 시간이 거의 정한다 — 늑대는 배고플 때마다 누군가를 잡고, 두뇌는 '누가 잡히나'만 바꾼다.
- 3M 짧은 학습은 R4 보다 덜 움직인다. 기각이면 고리가 계획대로 일한 것이다(나쁜·쓸모없는 두뇌를 막았다).
- 그래서 따로 민감도(`adapt.py sense`, 보고만)를 잰다: 지금 규칙의 계수만 바꾼 가정 세계(덤불 빽빽, 늑대가 짧게 덮치고 지침)에서 두뇌 행동 차이가
  결과를 바꾸는지. 판정이 아니고, 새 세계 규칙을 만들지 않는다.

## 7. 민감도 (보고만 — 게임에 없는 가정 세계, 미리 적은 셈법)

- 세계: 스냅숏 세계(1절)에 변형 하나씩 — `base`(그대로), `dense`(지역마다 덤불 원판 150 개/ha·반지름 1~2 m 를 더함, 세로 장애물 규칙 그대로),
  `short`(늑대 넷 모두 잠행-돌진형, 덮치기 8 스텝 = 1.07 초(지금 12), 놓치면 75 스텝 = 10 초 지침(지금 30)), `both`(둘 다).
  `short` 의 8 스텝은 지금 두뇌 사냥 성공률이 현실 띠 10~30% 의 가운데쯤(21%)이 되는 값이다(시드 32080~32083 × 지역 × 240 초로 6·8·10·12 를 재서 골랐다 —
  판정·민감도 값을 보기 전).
- 두뇌 둘: 지금 두뇌 R1b-F 와 R4 s0(늑대를 알면 숨기를 3.0 → 13.7% 로 쓰는 두뇌 — 행동이 뚜렷이 다른 두뇌). 시드 32080~32099 × 지역, 16 분.
- '두뇌 행동이 결과를 바꿀 여지' = R4 − R1b-F 의 16 분 잡힌 몫 짝 차이(시드 20, 자유도 19, |t| ≥ 2.093 이면 '여지 있음'). 굶음·산도 함께 적는다.
- 여지가 있는 변형이 있으면(잡힘이 줄어드는 쪽), 그 가운데 차이가 가장 큰 변형 하나로 고리를 한 번 더 돈다(`derive` → 3~9 단계, 같은 관문 — 가정 세계라
  재현 확인 R 은 없다). 이 결과는 '그런 세계라면 적응이 값을 하는가' 의 보고이고, 게임 두뇌를 바꾸지 않는다(그 세계가 게임에 없다).

## 변경 기록

### 2026-10-18 — 확정 (첫 고리 전)
- 도구·명세·언리얼 스냅숏을 만들고, 스냅숏 변환·재현 확인만 돌려 본 뒤 확정했다. 학습·판정은 아직 돌리지 않았다.

### 2026-10-18 (1) — 재현 확인 규칙을 확정 전에 바꿈 (첫 확인 판을 본 뒤 — 숨기지 않고 적는다)
- 첫 초안 규칙은 '지역마다 |z| ≤ 3' 이었다. 세션 20003 스냅숏(240 초)으로 처음 돌리자 **메마른 땅 잡힘이 걸렸다**: 언리얼 8 마리 대 파이썬 5.8 ± 0.6
  (시드 20 개 범위 5~7, z +3.66). 숲 z −1.44, 고지 +0.37, 지역 합 22 대 20.8 ± 1.4 (z +0.91).
- 이것은 10-18 날씨 독립 확인(`results/v3/wild3/verify/README.md` 3절)이 먼저 적은 현상이다: 지도 하나에서는 240 초 잡힘이 늑대 배부름으로 거의 차서
  (늑대 넷 × 2 마리 = 8 이 위 끝) 파이썬 흔들림이 작게 나와 z 가 부푼다(그때 숲 20004 는 z −5.6). 지도 27 장을 합치면 모든 칸 |z| ≤ 1.8 이었다.
  같은 세션 20003 의 메마른 땅은 그 확인에도 들어 있다(같은 설정 — 10-18 레벨 나무 확인에서 기록 줄이 실행 중 나무 판과 모두 같았다).
- 그래서 규칙을 '지역 합 |z| ≤ 3 그리고 지역마다 차이 ≤ max(3 × sd, 3 마리)' 로 바꿨다. 변환 실수(지도·날씨·규칙이 틀림)는 지역 합이나 여러 마리 차이로
  드러난다고 본다(어림). 3 마리 = 128 마리의 2.3% 다. 바꾼 규칙으로 세션 20003 은 통과한다(메마른 땅 차이 2.2 마리).
- 바꾼 까닭이 '이 판을 통과시키려고' 와 겹친다는 점을 적어 둔다. 첫 초안 규칙의 결과는 `runs/s20003/check.json` 의 `ok_v0`(실패)로 함께 남긴다.
