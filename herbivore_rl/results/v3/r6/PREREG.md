## 4. 판정 기준 (고른 모델 R6 하나 vs route0, 같은 시드 짝) — 설계 16-9 그대로

- 짝 단위 = 시드(지역 셋의 분자·분모를 각각 더한 뒤 나눈 몫). 문턱 = t 분포 양쪽 5%: N 은 t_crit(n − 1) = **1.984**(n 100), G 는 **2.023**(n_G 40).
  P1·GH 는 두 두뇌 모두 쫓긴 도망이 1 개 이상인 시드 n₁ 에서 t_crit(n₁ − 1)(빠진 시드가 없으면 1.984).
- 도구 `r6_eval.py judge`(1차·지킴 GH·GN·GF·GV·GC·GG·G4·G5·G6 은 실시간 관문 `live.gate_live` 의 셈 그대로 — 시험 `tests/test_live_v3.py`, 길 지킴 GT·GTr·GR 은

### 4-4. 기대 크기와 검정력 (판정에 쓰지 않는다 — 설계 16-10)

- 손 규칙 측정 m1(`results/v3/route/runs/m1/raw_rules.json`, N 세계, 예비 시드 34900~34959 × 지역 셋 × 1800 스텝, 늘 RUN 대 늘 SHELTER, **10 초 지켜보기 전 값**)
  에서 이 사전 등록 때 다시 셈한 시드 짝(시드 60): 쫓긴 도망(안 쫓김·잘림 뺌) 가운데 은신처 끝 몫 RUN 13.29% → SHELTER 21.86%(차이 +8.57 %p, **시드 짝 sd 2.68 %p**,

  다시 도망 +22.1 이 있었다 — GF·GR·G6·GN 이 가장 먼저 걸릴 수 있다(기각이 안전한 결과).
- 조기 점검(n 20)의 숨음 비율 짝 차이 표준오차는 약 0.6 %p 다(2.68 ÷ √20) — (c) 의 t > −2 는 대략 −1.2 %p 보다 나빠지면 걸린다.

## 5. 조기 점검 (판정이 아닌 멈춤·고르기 — 설계 16-8 1·2, 8-5)

### 5-1. 재는 것 (`r6_eval.py run --use check --probe` → `r6_eval.early_check`, 기준 판 = route0 같은 시드 `runs/early_base.json`)

점검 시드 37120~37139 × 지역 셋, N, 1800 스텝, 두뇌 argmax. 탐침(`_Probe`)은 같은 세계를 같은 두뇌로 돌리면서 결정·궤적을 바꾸지 않고(시험·스모크 9절) 아래를 잰다.

- **(a) 길 고르기가 움직였나**: SHELTER 가 열린 도주 길 결정(`rep_peek` route_decide ∧ 칸 1·4 열림)에서 학습 표본 확률 π′(SHELTER)(ε 0.05 섞음) 평균 −
  route0 같은 시드 값(0.138 — 0.95/(1 + e²) + 0.025) 의 **|차이| > 0.05**. 대조 '길 끔'은 보지 않는다.
- **(b) 가치망**: 도주 스텝(산 사슴 ∧ 다음 스텝 덮기 = 도주) 표본의 설명 분산 1 − Var(G^λ − V)/Var(G^λ) **> 0**. 점검 판 전체(60 세계)를 합쳐 셈한다.
  - 수익 목표 G^λ = **그 모델의 학습 GAE λ**(조합의 λ — 0.95 또는 0.98)로 셈한 λ-수익: G^λ_t = r_t + γ(1 − d_t)[(1 − λ)V(s_{t+1}) + λG^λ_{t+1}], γ 0.995, 판 끝 뒤는
    V(s_T). PPO 가 가치망을 맞추는 목표(stable-baselines3 의 이점 + V)와 같은 꼴이고, 학습 기록의 '가치 설명 분산'(R4·R5 스모크 0.8~0.97)이 이 셈이다
    (`r6_eval.lambda_returns`, 시험 `test_lambda_returns`). r = 그 세계 보상 + 그 조합의 도주 비용 c(보상 전용 키라 세계는 그대로).
  - 몬테카를로 수익(λ 1)의 설명 분산은 **보고만** 한다. 까닭(사전 등록 때 스모크 시드로 잼 — 10절): 다 배운 R5 두뇌(`v3_r5_g995_s3_20m`)도 도주 스텝 몬테카를로
    설명 분산이 N 세계 +0.02(시드 32083~32086 × 지역 셋 × 1800 스텝)·학습 세계 꼴 −0.30(시드 32083 × 지역 셋)으로 0 언저리라, '> 0' 이 배움의 표지가 되지
    못하고 (b) 멈춤이 헛되이 걸린다. 같은 판의 λ-수익 설명 분산은 R5 λ 0.95 +0.71·λ 0.98 +0.46, route0 +0.93·+0.71(몬테카를로 −2.18)이다.
  - 그래서 (b) 는 '도주 스텝에서 가치망이 망가지지 않았다'는 너그러운 안전 점검이다(PPO 의 설명 분산 ≤ 0 = 가치망이 쓸모없음과 같은 뜻). 칸을 바꿔 다시
    고르지 않는다.
- **(c) 나빠지지 않았나** (route0 대비, 시드 짝 — 10-23 잣대): **숨음 비율 짝 t > −2.0** 그리고 **잡힘 비율(쫓긴 도망 가운데) 짝 t < +2.0** 그리고
  **잡힌 몫(사슴 가운데) 짝 t < +2.0**.
- **결함**: 얼기·잠 몫 > 0, COVER 칸(3) 확률 > 0, 마스크 밖 SHELTER > 0 — 하나라도 있으면 모든 학습을 멈추고 고친다(대응으로 세지 않는다).
- 보고만: R5 점검 칸(도망 몫 < route0 의 절반, 은신처 안 > 3 배, 굶음 > 1.5 배)과 길 기록.

### 5-2. 조합 6 개 (5M, 모델 시드 0) → (λ, c) 고르기 (`early_checks.py combos` → `r6_eval.pick_combo`, 기록 `logs/early_pick.json`)

- **통과 조합** = (a)·(b)·(c) 모두 넘고 결함 없음.
- **고르기**: 통과 조합 가운데 점검 시드 **숨음 비율 짝 차이(R6 − route0)가 가장 큰 것**. 그것과 **1 %p(0.01) 안**인 조합이 여럿이면 **c 가 작은 것**, 그다음
  **λ 0.95**(지금 조리법)를 고른다.
  - 1 %p 의 근거(설계의 '쫓긴 시간 0.1 초 안'을 옮김): 0.1 초는 m1 '늘 SHELTER' 쫓긴 시간 효과(−0.67 초)의 약 15%, 시드 짝 sd(0.72 초)의 0.14 배다. 같은 몫을
    숨음 비율로 옮기면 +8.57 %p 의 15% ≈ 1.3 %p, sd 2.68 %p 의 0.14 배 ≈ 0.4 %p 이고 그 사이에서 1 %p 로 둔다. 점검 n 20 에서 두 조합의 숨음 비율 짝 차이끼리의
    차이 표준오차는 약 0.85 %p(0.6 × √2)라, 1 %p 안이면 점검 시드로 가를 수 없는 조합으로 본다.
- **멈춤** (본 학습을 띄우지 않고 보고):
  1. 결함이 있으면 — 고친 뒤 다시.
  2. 모든 조합이 (a) 에서 움직이지 않으면 — '못 배움'.
  3. (a)·(c) 를 넘은 조합이 있는데 그것이 모두 (b) 에서 걸리면 — 관측 25 대안(설계 16-4, '지금 길' 한 칸)을 사람에게 묻는다.
  4. 그 밖에 통과 조합이 없으면 — 멈추고 보고.
