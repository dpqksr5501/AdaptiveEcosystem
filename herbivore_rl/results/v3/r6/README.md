# v3 R6 — 두 길 두뇌 학습 (조기 점검 끝, 본 학습 전)

## 결론 먼저 (10-23, 조기 점검 — 판정 아님)

- **짧게 배워 본 여섯 가지 학습 설정이 모두 점검을 넘었다. 미리 적은 규칙대로 그 가운데 'λ 0.98 · 도주 비용 0' 을 골랐다.** 멈출 까닭은 없었다.
- 5M 스텝(약 11 분)만 배운 두뇌들도 이미 쫓길 때 은신처 쪽을 훨씬 자주 골랐다(은신처를 고를 확률 0.14 → 0.48~0.78). 점검 세계에서 쫓긴 사슴 가운데 은신처에
  숨어 살아남은 비율이 지금 두뇌 12.9% 에서 19.6~22.2% 로 커졌고, 잡힌 사슴은 늘지 않았다(오히려 조금 줄었다).
- 고른 설정은 그 비율이 가장 컸다(22.2%, +9.3 %p). 도주 비용 0.005 설정도 거의 같았는데(+9.3 %p, 차이 0.01 %p), 그럴 때는 비용이 작은 쪽을 고른다고 미리 적어 두었다.
- 이것은 판정이 아니다. 점검용 시드 20 개로 본 값이고 학습도 짧았다. 다음은 고른 설정으로 20M 스텝 × 3 시드를 배우고(+ 비교용 '길 끔' 1 개), 고르기 시드로
  하나를 고른 뒤, 아직 한 번도 쓰지 않은 판정 시드로 지금 두뇌와 견준다(`STATUS.md` 1-2~1-4).
- 표와 자세한 값: `STATUS.md` 0절, 조합마다 `logs/check_l<λ>_c<c>.txt`, 고르기 `logs/early_pick.json`.

## R6 는 무엇인가

**쉬운 말로**: 사슴이 늑대에게 쫓겨 도망칠 때, 지금은 세계 규칙이 늘 '늑대 반대쪽 트인 곳'으로 뛰게 한다. R6 는 사슴 두뇌가 그 순간 **트인 쪽(RUN)으로 뛸지,
늑대보다 먼저 닿을 수 있는 은신처(SHELTER)로 갈지**를 스스로 고르게 배우는 실험이다. 성공 기준은 하나다 — **늑대에게 쫓긴 사슴 가운데 은신처에 숨어 살아남는
비율이 지금 두뇌보다 분명히 커지고**, 더 잡히거나 더 굶거나 은신처에 처박히는 등 다른 것은 나빠지지 않아야 한다. 규칙은 학습 전에 미리 적어 두었다
(`PREREG.md`, 커밋 `d2bb1c2`).

- 규칙(사전 등록): `PREREG.md` — 1차 기준·지킴 18 칸·조기 점검·고르기 규칙을 수로 적었다.

- 설계: `AdaptiveEcosystem/Docs/RL_Policy/RL_V3_FLIGHT_ROUTE_DESIGN.md` 16절. 판정 1차(숨음 비율)는 `results/v3/live/LIVE_GATE.md` 변경 기록 (6).
