# 언리얼 통합 v3 거울 — 파이썬 세계가 언리얼과 얼마나 같은가 (10-15)

사용자 결정 10-15 (6)(`AdaptiveEcosystem/Docs/RL_Policy/RL_V2_PLAN.md`): 야생 규칙은 파이썬 세계에서 만들고 시험·학습한다. 그 전에 파이썬에 언리얼 통합 v3 모드의 판박이 세계를 만들고, 같은 조건에서 언리얼 결과와 얼마나 비슷한지 쟀다.

## 결론

- 파이썬 거울 세계는 언리얼과 거의 같게 돈다. 240초 동안 산 비율·잡힘·굶음의 차이는 대부분 3%p 안이고, 가장 큰 것이 약 5%p(사슴 32마리, 지도 따로)다.
- 언리얼 표본(세션 3개 = 지역 무대 9개)이 흔들리는 폭 안에 모두 든다(산·잡힘·굶음 모두 |z| < 2).
- 언리얼 지역 무대와 같은 먹이 지도로 돌리면(짝 비교) 더 잘 맞는다. 첫 1분에 무너진 두 지역(Highland@20000, Forest@20002)도 파이썬에서 똑같이 무너진다. 굶음은 먹이 지도 운이 거의 정한다.
- 그래서 앞으로 규칙 만들기·시험·학습은 파이썬 세계 결과를 믿고 해도 된다. 언리얼은 규칙이 정해진 뒤 C++로 옮겨 마지막에 확인한다.

## 무엇을 맞췄나

- 세계 설정 `configs/v3_unreal_mirror.yaml`. 머리 주석에 C++ 출처와 닫지 못한 차이를 적었다.
- 새 기능 블록 `features.integrated_stage`(번호 26, `env_v2/world.py`). 블록이 없거나 끔 값이면 지금 세계와 비트 단위로 같다(`tests/test_unreal_mirror.py`).
  - 부활 없음: 죽은 사슴은 그 자리에 멈추고, 다음 스텝부터 동족·늑대 표적·먹이 수요·번식·늑대 잠 판정에서 빠진다(C++ `bRespawnDead = false`).
  - 시작 위상 0, 무대 은신처 4개(반경 6단위), 늑대 잠행 1 + 추격 1, 무대 시작 배치(늑대 모서리, 사슴 균등·늑대에게서 14.5단위 밖), 시작 방향.
- 설정 값으로 맞춘 것: 맵 60단위(120 m), 늑대 2마리·속력 0.8배, 원거리형·야행성·플레이어 없음, 먹이 재생 배수 1, 하루 900스텝(낮 60초 + 밤 60초), 늑대 밤잠 점진화, 늑대 제자리 식사 38스텝(5초), 얼기 막음.
- 학습(`env_v2/vec_env.py`)은 부활 없는 세계를 받지 않는다. 빈 슬롯을 PPO 손실에서 빼는 마스크가 아직 없다.
- 학습 세계의 '번식으로 태어나기'(결정 10-15 (6))를 붙일 자리: `_respawn` 안의 새 개체 만들기를 `_spawn_slots`로 떼어 두었다.

## 닫지 못한 차이

- 난수열: C++는 자체 해시 난수, 파이썬은 numpy 스트림이라 궤적은 같지 않다. 짝 비교는 먹이 지도만 C++ 난수를 옮겨 같게 만든다.
- 지형 제약 이동: 비교 기록 모두 '막힘 사슴 0 늑대 0'이라 동역학 차이는 없다.
- 팀 시계 동기, 시체 2초 삭제: 동역학과 무관하다.
- 경계 거리 규칙(KeepAway): 커밋하지 않은 C++ 실험이라 흉내 내지 않는다. `unreal_logs/*_k1.log`는 그 실험 기록이고 비교에는 쓰지 않는다.

## 다시 돌리기

```
# herbivore_rl/ 에서
python results/v3/mirror/run_mirror.py --deer 128 --seeds 32000-32089
python results/v3/mirror/run_mirror.py --deer 64 --wolf-eat-steps 225 --seeds 33000-33089
python results/v3/mirror/run_mirror.py --deer 128 --unreal-maps 20000-20002 --replicates 10 --seeds 32000-32089
python results/v3/mirror/compare_unreal.py --unreal-dir results/v3/mirror/unreal_logs --out results/v3/mirror/compare.md
```

- 실행 결과 `runs/`는 커밋하지 않는다(재생성 가능, `herbivore_rl/.gitignore`). 세계 하나 1800스텝은 약 5.6초, 90개를 작업자 8개로 약 1분이다.
- 시드: 파이썬 세계는 탐색 범위 32000~32099·33000~33099만 쓴다. 20000~20002는 언리얼 지도를 다시 만드는 데만 쓴다.
- `unreal_logs/`는 통합 레벨 머리 없는 실행(경계 거리 규칙 끔, 240초, 세션 시드 20000~20002) 기록에서 비교에 쓰는 줄만 남긴 것이다.
