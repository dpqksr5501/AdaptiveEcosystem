## 4. 판정 기준 (판정 세계 J, 고른 모델 하나 vs 같은 세계 R1b-F)

- 짝 단위 = 시드(지역 셋을 합친 몫), 시드 100개, 짝 t(자유도 99, 양쪽 5% 문턱 1.984). 지역 기준은 그 지역 세계만의 짝 t.
- 도구: `r4_eval.py judge`(아래 칸 이름 그대로).

| # | 기준 | 통과 | 까닭 |
|---|---|---|---|
| P1 (1차) | 16분 잡힌 몫 | R4 − R1b-F < 0 이고 t ≤ −1.984 | 사용자 목표 '언리얼에서 사슴이 덜 잡힌다' |
| G1 | 16분 굶은 몫 | t < +1.984 | 덜 잡히는 대신 더 굶으면 안 된다(은신처 눌러앉기) |
| G2 | 산 몫 16분·240초 | 둘 다 t > −1.984 | 끝에 산 사슴이 줄면 안 된다 |
| G3 | 지역마다(메마른 땅·숲·고지) 16분 잡힘·굶음·산 | 잡힘·굶음 t < +2.626, 산 t > −2.626 (9칸 모두, 양쪽 1% 문턱) | 어느 지역도 나빠지지 않는다(메마른 땅 = 나무 없는 무대 회귀 확인, 계획 S7). 칸이 9개라 문턱을 1% 로 둬 같은 두뇌가 우연히 걸리는 몫을 약 4.5% 로 줄인다 |
| G4 | 은신처 안 잡힘 | 16분·240초 판정 600 세계 모두 0 | 은신처 안전 규칙이 깨지지 않았나 |
| G5 | 끼임 (`results/v3/wild2/stuck_check.py --model`, 4절 끼임 세계) | 사슴 원판 끼임 0, 늑대 원판 끼임 ≤ R1b-F | 나무 사이에 끼는 행동을 배우지 않았나. 늑대 은신처 둘레 기어감은 나무 없는 세계에도 있는 늑대 규칙 몫이라 보고만 |
| G6 | 악용 없음 | 은신처 안 몫(16분, 산 사슴-스텝) ≤ R1b-F 의 2배, 먹기·도망·숨기 모두 1% 넘게 씀 | 은신처 웅크림(R2 10-13)으로 이기지 않았나 |

- **R4 성공 = P1 과 G1~G6 모두 통과.** 하나라도 못 넘으면 실패다. 판정 세계로 다시 고르거나 문턱을 바꾸지 않는다.
- 같은 두뇌(차이 없음)여도 지킴 기준이 우연히 하나 걸릴 몫은 약 12%다(G1·G2 둘 한쪽 2.5% 씩 + G3 9칸 약 4.5%, 어림). 나빠짐을 놓치지 않는 쪽을 골랐다.
- 보고만(판정 아님): 사냥 성공률(계획 D6 — 늑대 규칙이 크게 정한다, 현실 띠 10~30%), 240초 잡힌 몫, 행동 몫, 지역별 표, 은신처 안 몫 짝 차이, 학습 곡선,
