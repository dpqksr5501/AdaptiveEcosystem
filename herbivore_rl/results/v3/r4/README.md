## 1. 결론 — R4 실패, 게임 두뇌는 R1b-F 그대로

- **새 두뇌(모델 시드 s0)는 사슴이 덜 잡히게 하지 못했다.** 16분 잡힌 몫 21.65% 대 지금 게임 두뇌 R1b-F 21.76%. 차이 −0.11%p 는 우연 흔들림(± 0.10%p) 안이라
  사전 등록 1차 기준(P1, t ≤ −1.984)을 넘지 못했다(t −1.10).
- **나빠진 것도 없다.** 지킴 기준 여섯(굶음·산 몫·지역마다·은신처 안 잡힘·끼임·은신처 악용)은 모두 통과했다.
- 그래서 사전 등록 8절대로 게임 두뇌는 R1b-F 그대로 두고, 가중치를 C++ 에 넣는 언리얼 확인(7절)은 하지 않았다. 다른 시드·체크포인트를 판정 세계로 다시 고르지 않는다.
- 왜 안 됐나(쉽게): 이 세계에서 잡히는 수는 거의 늑대가 배부른 시간이 정한다(사전 등록 9절에 미리 적은 위험). 새 두뇌는 늑대가 가까울 때 은신처로 훨씬 자주 숨으러 갔지만
  늑대 사냥 성공률은 그대로였고(62.5 대 62.3%), 잡힌 수도 그대로였다. 숨는 시간만큼 덜 먹어 굶은 몫이 조금 늘었다(+0.67%p — 기준 안).

## 3. 새 두뇌가 다르게 하는 것 (`situ.md` — 보고만, 판정과 같은 300 세계)

'두뇌 결정' = 도주 반사가 덮지 않은 스텝(반사는 늑대가 아주 가까우면 두뇌 대신 도망·웅크림을 넣는다 — 산 사슴-스텝의 약 10%). '늑대를 앎' = 깨어 있는 늑대를 보거나 들음.
도구가 세계마다 잡힘·굶음·산·행동 수가 판정 판과 같음을 확인했다.

| 상황 (두뇌 결정) | 결정 수 (R4) | 먹기 R4 / R1b-F | 도망 R4 / R1b-F | 숨기 R4 / R1b-F |
|---|---|---|---|---|
| 늑대를 모름 | 1억 9130만 | 99.9 / 100.0% | 0.0 / 0.0% | 0.0 / 0.0% |
| 늑대를 앎 (모두) | 1139만 | 85.7 / 96.6% | 0.7 / 0.5% | **13.7 / 3.0%** |
| 　늑대 15 m 안 | 366만 | 72.0 / 88.8% | 1.6 / 1.5% | **26.4 / 9.7%** |
| 　늑대 15~30 m | 729만 | 91.8 / 99.9% | 0.2 / 0.0% | **7.9 / 0.1%** |

날씨마다 (두뇌 결정, 늑대를 앎 → 숨기 몫 R4 / R1b-F): 맑음(메마른 땅) 13.1 / 2.3%, 비(숲) 15.0 / 3.1%, 눈(고지) 13.2 / 4.0%.
늑대 15 m 안에서는 맑음 32.6 / 12.0%, 비 26.8 / 9.4%, 눈 21.8 / 8.3%.

쉽게 말하면:
- **두 두뇌 모두 도망은 거의 반사가 한다.** 두뇌가 스스로 고르는 도망은 1% 안팎이다. 두뇌가 바꾼 것은 '늑대를 알았을 때 계속 먹을까, 은신처로 숨으러 갈까' 하나다.
- **새 두뇌는 늑대를 알면 훨씬 일찍·자주 숨으러 간다.** 늑대를 안 결정의 숨기 몫이 3.0% → 13.7%(약 4.5배), 15~30 m 거리에서는 0.1% → 7.9%. 날씨와 상관없이 같은 쪽이다
  (눈 오는 고지에서 늘어난 폭이 조금 작다 — 까닭은 재지 않았다).
- **나무 곁에서는 덜 숨는다.** 늑대를 알 때 나무 곁 숨기 6.9% 대 트인 곳 14.9%(R1b-F 도 0.9 대 3.9% 로 같은 쪽). 두뇌는 나무를 직접 보지 못한다(관측 18칸에 나무가 없다).
  나무 곁 결정 뒤 10초 안 잡힘(S5)은 아래 4절.
- 결과: 은신처 안에 있는 시간이 늘고(5.78 → 6.52%) 먹는 시간이 줄었다. 늑대는 여전히 배고플 때마다 다른 사슴을 잡아 잡힌 수는 그대로였다.
