- **덜 잡히고, 덜 뛰었다.**
  - 쫓긴 사건 가운데 잡힘은 9.89% 대 10.77%(t −3.90)다. 사슴 가운데 잡힌 몫은 13.16% 대 14.10% 다.
  - 도망 시작(GF)은 조금 적고(t −2.02), 쫓김 사건 시작(GE)도 적다(t −3.00). 달린 시간 몫은 10.6% 대 13.9% 로 줄었다.
    - GE 가 준 몫(−0.073) 가운데 약 4분의 1(−0.018)은 이어진 다시 뛰기를 한 사건으로 묶는 규칙에서 온다. 사전 등록 때 예상한 쪽이다(PREREG 약점 2).
      나머지(−0.055)는 도망 시작 자체가 준 것이다.
  - 늑대 포만을 켠 게임 설정 세계(G — 같은 파이썬 거울, 시드 40, 언리얼 아님)에서도 나빠지지 않았다.
    산 몫은 64.5% 대 63.0%(t +2.25)로 조금 나았다. 잡힌 몫 11.48% 대 11.67% 는 차이가 작아(t −1.60) 우연과 가르기 어렵다.
  - 끼임 0, 은신처 안 잡힘 0 이다. 늑대가 안 쫓는데 두뇌 혼자 뛴 도망도 0 이다(route0 은 8 번). 판 5 마스크가 막아서다 — 배워서 없앤 것이 아니다.
  - G 세계에서 은신처 안에 있는 시간은 6.2% → 9.4% 로 늘었다(1.5 배 — 한도 2 배). 먹기 몫은 89% 다.
- **정직하게 적어 둘 것**
  - 이 셈 규칙(쫓김 사건 단위)은 R7 이 옛 규칙에 걸린 것을 **본 뒤에** 사람이 정했다(10-24). 같은 학습을 두 번째 규칙으로 다시 본 것이다(PREREG 약점 1).

    새 규칙에서 GR 은 보고만이다. 이번 판정 시드의 GR 을 들락날락과 그 밖으로 나누지는 않았다.
    - 이 말은 고른 s1 을 같은 판정 판에서 옛 칸으로 본 것이다. 옛 규칙을 이번 점검·고르기 시드에 처음부터 썼다면 s1·s2 는 5M 점검에서

      s0 은 판정 시드에서 잰 적이 없어, 옛 규칙의 판정 결과는 모른다.
      GR 은 시드에 따라 문턱 근처를 오간다(R7 때 점검 시드에서는 s0 이 GR 로 빠졌다).
  - 두 번 세기를 빼도 숨는 이득은 거의 그대로 남았다. 옛 도망 단위 숨음 비율은 21.88% 대 13.32%(+8.56 %p)였고, 사건 단위는 +8.37 %p 다(보고만).
  - 판정 세계는 파이썬 거울이다. 언리얼 게임 세계에서 확인한 것이 아니다.
- **비교용(보고만)**

## 앞 단계: 점검·고르기 (10-24 — 판정 아님) — s1 두뇌를 골랐다

- **새 셈 규칙으로 R7 두뇌 세 개를 다시 점검했더니 하나도 빠지지 않았다.** 배우는 도중 남긴 2M·5M 두뇌 여섯 개가 모두 기준을 넘었다.

## 사전 등록 때 적은 결론 (10-24) — 규칙만 새로 적었다. 그때는 아직 아무것도 재지 않았다

- **R7 두뇌를 다시 배우지 않고, 새 셈 규칙으로 처음부터 다시 점검·고르고 판정하기로 하고 그 규칙을 먼저 적었다.**
  - 지금까지 한 것은 도구가 끝까지 도는지 본 짧은 스모크와 시험뿐이다.
  - 판정용 세계(시드 38000~38099)는 아직 아무 두뇌로도 돌리지 않았다.
- **왜 다시 하나**: R7 은 '도망이 끝나고 5 초 안에 또 뜀(GR)'에 걸려 고를 두뇌가 없었다.
  - 늘어난 '또 뜀'은 거의 모두 은신처에 들어갔다가 몇 초 만에 다시 뛴 '들락날락'이었다.
  - 사람이 10-24 에 정했다. 도망 하나하나가 아니라 **같은 사슴이 이어서 쫓긴 일을 한 번(쫓김 사건)으로 묶어**, 그 끝에 숨었는지·잡혔는지로 센다.
  - 그러면 들락날락이 숨음을 두 번 세지 않는다. '5 초 안 또 뜀' 대신 '쫓김 사건이 몇 번 시작했나(GE)'를 지킨다.
- **정직하게 적어 둔 것**: 이 규칙 변경은 R7 결과를 **본 뒤에** 정했다.
  - 새 지킴 GE 는 들락날락을 따로 벌하지 않는다. 그래서 R7 두뇌가 이번에는 점검·고르기를 넘을 가능성이 크다. 이것을 알고 정했다.
  - 대신 '숨음'은 더 엄해졌다. 마지막에 은신처에서 10 초 동안 가만히 살아남아야 숨음으로 센다.
  - 그래서 R7 이 지금 두뇌보다 정말 더 잘 숨는지는 판정 세계에서 처음 드러난다.
- 이미 값을 본 R7 의 점검·고르기 세계(시드 38100~38139)는 다시 쓰지 않는다. 새 점검 38220~38239 · 새 고르기 38200~38219 를 쓴다.
- 게임 두뇌와 실시간 고리는 지금 그대로다(관측 21 · 판 2 · 길 끔).
