# R5 — 두뇌가 나무 같은 장애물을 알아채게 하기

10-19 사용자: '일단 두뇌가 나무 같은 장애물을 인지할 수 있게 바꿔.' 결정과 설계는 `AdaptiveEcosystem/Docs/RL_Policy/RL_V2_PLAN.md` 10-19 (16), 식은 계약 `POLICY_CONTRACT_V3.md` 2-4.
사전 등록 `PREREG.md`(규칙·문턱·시드는 학습 전에 정함, 변경 기록 (1)~(5)), 진행 `STATUS.md`, 판정 표 `judge.md`·`judge.json`, 빽빽한 숲 `dense.md`·`dense.json`, 나무 곁 결정 `situ.md`·`situ.json`.

## 결론 먼저 (10-19, 판정) — R5 실패, 게임 두뇌는 R1b-F 그대로

- **나무를 보는 새 두뇌(모델 시드 s3)는 사슴이 덜 잡히게 하지 못했다.** 언리얼과 같은 세계(나무 + 날씨, 판정 시드 33100~33199 × 지역 셋 = 300 세계)에서
  16분 잡힌 몫 21.91% 대 지금 게임 두뇌 R1b-F 21.86%. 차이 +0.04%p 는 우연 흔들림(± 0.11%p) 안이고 줄지도 않았다 — 사전 등록 1차 기준(P1: 차이 < 0 이고 t ≤ −1.984)을 못 넘었다(t +0.40).
- **나빠진 것도 없다.** 지킴 기준 여섯(굶음·산 몫·지역마다·은신처 안 잡힘·끼임·은신처 악용)은 모두 통과했다.
- 그래서 사전 등록 8절대로 게임 두뇌는 R1b-F 그대로다. 두뇌 파일 내보내기와 언리얼 확인(7절)은 하지 않았다. 다른 시드·체크포인트를 판정 세계로 다시 고르지 않는다.
- **빽빽한 숲(나무 + 덤불 약 216, 학습에 없던 배치 — 보고만)에서도 같다.** 16분 잡힌 몫 22.23 대 22.13%(+0.10 ± 0.11%p, t +0.93).
- **두뇌는 나무를 보고 행동을 바꿨다. 그런데 잡히는 수는 그대로다.** (아래 3절, 두뇌가 스스로 고른 결정만 — 늑대가 아주 가까울 때는 반사가 두뇌 대신 도망·웅크림을 넣는다)
  - 늑대를 알 때 스스로 은신처로 숨으러 가는 일을 거의 그만뒀다(숨기 2.9% → 0.0% — 1106만 결정 가운데 48번). 대신 조금 더 도망친다(0.5 → 1.1%).
  - 도망칠 쪽이 5 m 안에서 막혀 있으면 도망을 덜 고른다(1.4 → 0.3%) — 막힌 쪽으로 뛰지 않고 그 자리에서 먹는다. 트인 쪽이면 더 도망친다(0.2 → 1.3%).
  - 줄기가 늑대 눈길을 가릴 때는 조금 더 도망친다(0.3 → 1.2%). 지금 레벨에서는 드문 상황이다(1만 8천 결정, 늑대를 안 결정의 0.2%).
  - 그 결정 뒤 10초 안에 잡힌 몫은 어느 상황에서도 R1b-F 와 같다(좁은 길·가림·나무 곁·트인 곳 모두 |t| < 1.3).
- **왜 안 됐나(쉽게)**: R4 와 같은 까닭이다. 이 세계에서 잡히는 수는 늑대가 배고플 때마다 거의 정해진다(사냥 성공률 62.6 대 62.7%). 도망의 대부분은 두뇌가 아니라
  도주 반사가 한다(산 사슴-스텝의 약 10%). 두뇌가 바꿀 수 있는 '늑대를 알지만 아직 반사 전' 결정은 산 사슴-스텝의 약 5% 이고, 그 결정을 바꿔도 늑대 사냥이 더 실패하지 않았다.
- **R4 와 견줌**: R4 두뇌는 숨기를 크게 늘렸고(3.0 → 13.7%) R5 두뇌는 거의 없앴는데(2.9 → 0.0%) 둘 다 잡힌 몫은 그대로였다. 두뇌가 '언제 숨고 언제 먹나'를
  크게 바꿔도 잡힘이 움직이지 않는다는 것을 두 번 봤다(4절).

쉽게 말하면:
- **R5 두뇌는 스스로 숨으러 가지 않는다.** 두 세계 모두, 모든 상황에서 숨기가 거의 0 이다(언리얼 세계 1106만 결정 가운데 48번, 빽빽한 숲 702만 가운데 941번 — R1b-F 는 늑대를 알 때 2.9~4.4%). 숨기는 이제 반사(늑대가 아주 가까우면 은신처로)만 한다.
  대신 늑대를 알면 도망을 조금 더 고른다(언리얼 세계 0.5 → 1.1%, 빽빽한 숲 1.2 → 2.2%).

  빽빽한 숲에서는 막혔을 때 차이가 작다(1.7 → 1.5%, t −1.48). 트였을 때만 는다(0.7 → 2.7%).
- **늑대 눈길이 가려졌을 때 '안 보이니 먹자'가 아니다.** 가림일 때 오히려 도망이 조금 는다(언리얼 0.3 → 1.2%, 빽빽한 숲 0.3 → 0.6%). 두 두뇌 모두 99% 먹는다.
  가림 결정 뒤 10초 잡힘이 다른 상황보다 높은 것(1.5~2.0%)은 두 두뇌가 같다 — 가린 늑대는 들어서 안 늑대라 이미 가깝다(재지 않은 추정).
- **결과는 같다.** 10초 안 잡힘은 12줄 가운데 11줄이 |t| < 1.3 이다. 빽빽한 숲의 트인 곳 한 줄만 R5 가 조금 높다(0.66 대 0.59%, t +2.05 — 보고만, 12줄 가운데 하나).

## 결론 먼저 (10-19, 파이썬 관측 단계)

- 두뇌가 보는 관측 18 칸 뒤에 세 칸을 더했다(관측 21). 세계는 바뀌지 않는다 — 기능을 켜도 사슴·늑대의 움직임과 난수가 그대로이고 앞 18 칸도 비트 단위로 같다.
  - `escape_room`: 도망칠 쪽(늑대를 알면 그 반대, 모르면 바라보는 쪽)으로 곧장 뛸 때 나무 줄기나 무대 끝에 막히기까지 거리 ÷ 20 m
  - `obstacle_near`: 가장 가까운 나무 줄기까지 거리(몸 가장자리 기준) ÷ 10 m, 나무가 없으면 1
  - `threat_hidden`: 가장 가까운 늑대와 나 사이를 줄기가 가리면 1(그 늑대는 지금 나를 못 본다)
- 세 칸 모두 한 끝에 붙지 않는다(분모 그대로). 지금 레벨은 나무가 적어 줄기 칸이 조용하고, 빽빽한 숲에서는 잘 움직인다.

| 지금 레벨 고지 (9) | 0.65 | 85% | 0.5% |

## 결론 먼저 (10-19, 언리얼 C++ 단계)

- **언리얼이 관측 21 두뇌를 돌린다.** 두뇌를 관측 21 두뇌로 바꾸면 게임이 세 칸을 더 만들어 넣고, 내장 두뇌(R1b-F, 관측 18)로 돌아오면 18 칸만 만든다. 두뇌 파일 검사는 이 두 계약만 받는다.
- **같은 식이다.** 골든 435 사례에서 C++ 과 파이썬의 세 칸이 비트 단위로 같다. 게임 안 실제 상태(세션 20000·20010, 10 초마다 산 사슴 모두 — 17,709 줄)를 파이썬으로 다시 재도 모두 비트 단위로 같다.
- **배관이 결정을 바꾸지 않는다.** R1b-F 에 새 세 칸의 입력 열을 0 으로 붙인 두뇌(`AdaptiveEcosystem/EcoBrains/v3_r1_g995_s3_obs21zero.json`)로 240 초를 돌리면 내장 두뇌 판과 기록 줄이 두뇌 이름 말고 모두 같고,
  사슴·스텝 664,893 개 결정의 지문(요청·로짓 비트·마스크)도 같다. 이 두뇌가 R5 이어 배우기의 시작점이다.
- 지금 레벨은 줄기가 적어 '줄기가 늑대를 가림' 이 드물다(17,709 줄 중 7). 숲에서 10 m 안에 줄기가 있는 줄은 약 46%, 메마른 땅은 0 이다.
