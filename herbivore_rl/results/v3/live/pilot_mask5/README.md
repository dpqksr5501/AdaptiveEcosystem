(두 길·판 5, 계약 `0xad7bad5e1acaf071`)다. `LIVE_GATE.md` 7절의 규칙대로 쟀다. **판정이 아니다.**

- 시험 폴더만 썼다. 실제 폴더 `Saved/EcoAdapt` 는 쓰지 않았다.

  - 10-27 덧붙임: 같은 날 `LIVE_GATE.md` 변경 기록 (10) 에서 제안대로 적용했다(S 1M·δ_H 1 %p·나머지 그대로, `flight_sizes_confirmed` 참). 관측 21 묶음은

## 결론 먼저 (쉬운 말)

- **이어 배운 두뇌 36 개가 모두 지금 두뇌보다 덜 숨었다. 지금 관문 크기로는 하나도 통과하지 못한다.**
  - 숨음 비율이 0.3~4.1 %p 줄었다. 지금 두뇌 숨음 비율은 약 20% 다.
  - 환경 변화 8 가지 모두 그랬다. 두 맵(통합 맵·조연우 맵), 나무 +10·+20·+30 그루, 날씨 종류 바뀜을 쟀다.
  - 학습 길이 1M·2M·4M 모두 그랬다. 오래 배울수록 조금 더 덜 숨었다.

## 한계

- 나무 자리는 C++ 시험용 대역과 같은 규칙이지만 파이썬 난수다. 날씨와 나무는 스냅숏 칸만 바꿨다. 언리얼이 이 바뀜을 실제로 만든 스냅숏은 아니다.
  다만 그 칸은 게임 스냅숏 칸 그대로다.
- 10-27 고침을 켠 칸은 게임 기본 값을 손으로 적은 것이다. 10-27 뒤 게임이 쓴 스냅숏으로 다시 확인하지 않았다.
- 같은 두뇌 흉내(효과 없는 두뇌)는 같은 시드끼리의 상관을 넣지 않았다. 진짜 후보의 짝 상관이 거의 0 이라 큰 차이는 없을 것으로 본다.
- 시간은 언리얼을 끈 채 쟀다. 다른 작업 흐름의 UBT·언리얼 창이 같은 때 돌았는지는 확인하지 않았다(측정 시작 때는 UBT·언리얼 프로세스가 없었다).
- `live.py pilot` 의 `pilot.md` 머리 줄 'f_dec = … (R5 조리법 값 0.858922)'는 판 5 묶음에서도 R5 값을 적는다. 판 5 조리법 값은 0.714694 다.
  글만 틀린 것이고 학습에는 묶음 값이 쓰였다(`variants/*/convert.json` `live.f_dec`). 고치지 않았다.

## 다시 돌리는 법

```
# herbivore_rl/ 에서 (PYTHONUTF8=1), <시험 폴더>·<raw 폴더> 는 저장소 밖
python results/v3/live/pilot_mask5/pilot_mask5.py make --base-j <level_jyu_eco 의 control/s20010_r7e.json>
python results/v3/live/pilot_mask5/pilot_mask5.py run --variant I_t20 --root <시험 폴더> --raw <raw 폴더> --workers 14 \
    --steps 1000000 2000000 4000000 --parts brains cands fdec --extra-same
python results/v3/live/pilot_mask5/pilot_mask5.py run --variant J_t20 … --steps 1000000 2000000 4000000
python results/v3/live/pilot_mask5/pilot_mask5.py run --variant I_t10 …        # 나머지 변형 (기본 1M·2M, 모델 시드 0·1, 시드 34900~34999)
python results/v3/live/pilot_mask5/pilot_mask5.py analyze --raw <raw 폴더>     # summary.json·pilot.md·seeds/
python results/v3/live/pilot_mask5/pilot_mask5.py timing --variant I_t20 --root <시험 폴더> --steps 1000000
```

- 바탕 스냅숏: I 는 `AdaptiveEcosystem/Saved/EcoAdapt_route5_test/snapshots/eco_v3_snapshot_s20004_t473_e1.json` 이다. J 는 10-25 세션 임시 폴더의
  `leco/control/s20010_r7e.json` 이다. 둘 다 저장소 밖이고, 지문은 `snapshots/manifest.json` 에 있다. 만든 스냅숏 아홉은 `snapshots/` 에 있다.
- 벽시계: 변형 8 + 대조 1 에 약 1 시간 59 분(11:44~13:43), 시간 재기 2 번에 약 10 분이 걸렸다.
