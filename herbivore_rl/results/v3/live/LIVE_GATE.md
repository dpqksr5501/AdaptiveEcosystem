## 0. 한 줄

게임 중 레벨이 나무·날씨를 바꾸면, 늑대 포만 없는 세계에서 지금 두뇌를 짧게 이어 배운 후보가 **포만 없는 세계에서 사슴을 유의하게 덜 잡히게 하고**,
포만 없는 세계의 굶음·산 수와 게임 세계의 잡힘·굶음·산 수·은신처 안 잡힘·끼임·은신처 악용 어느 것도 나빠지지 않을 때만 두뇌 파일을 낸다.
하나라도 못 넘으면 기각이고, 게임 두뇌는 그대로다. **기본 결과는 기각이다** — 적응 고리 첫 바퀴(t +1.60)·R4·R5 모두 기각이었다.

## 1. 세계

- G 게임 세계 = 스냅숏 세계(`live.py` 가 `adapt.convert` 로 만든 `world.yaml` — 바탕 `configs/v3_wild3_obs_mirror.yaml` + 바뀐 칸, 지역마다 스냅숏의
  날씨·장애물 원판·먹이 용량 격자). 늑대 포만은 **게임 값 그대로**(켬), 부활 없음, 사슴 = 스냅숏 입양 수, 두뇌 argmax.
- N 포만 없는 세계 = G 에서 늑대 포만(`features.wild_satiation.enabled`)만 끈 세계. 나머지는 G 와 같다.
- T 학습 세계 = N + R5 학습 조리법(`configs/v3_r5_train.yaml` 의 train 블록·부활 계수: 학습 전용으로 죽은 사슴은 늑대에게서 40 m 밖에 다시 남, 학습 시드 풀
  32000~32049, 세계 8·교체 5000·지역 섞기 1:1:1). R5 의 무작위 숲 섞기는 **쓰지 않는다**(지역 원판은 스냅숏 그대로). 먹이 지도 = 스냅숏 지도.
- 관측 21 두뇌와 관측 18 두뇌는 같은 세계에서 결정만 다르다(관측 21 거울은 관측 18 거울과 세계가 비트 단위로 같다 — R5 확인).

## 3. 학습

- 시작 = 스냅숏의 지금 두뇌: 관측 18 이고 가중치가 R1b-F 이면 R1b-F + 0 열, 관측 21 이면 두뇌 파일(`EcoBrains`·`Saved/EcoBrains`·`Saved/EcoAdapt/brains`)에서
  같은 가중치 sha256 의 모델 zip(zip 을 다시 재어 맞춘다). 다른 관측 18 파일 두뇌는 거부한다. 스냅숏 두뇌 계약 해시가 그 모델 계약과 달라도 거부.
- `train_v3.py` 그대로(`--init-from-model`): γ 0.995, `configs/ppo_best.yaml`, 배치 4096, 롤아웃 256, ε 0.05, 범주 엔트로피 0.01. f_dec 는 R5 조리법 값
  0.858922 그대로(예비 측정이 잰 T 세계 값 0.885549 는 기록만 — 예비 후보가 R5 값으로 배웠으므로 잰 결과와 같은 조리법을 쓴다).
- 길이: 모델마다 **S = 2M 스텝**, **K = 1 모델**(모델 시드 0), 프로세스마다 스레드 1. 마지막 판만 쓴다(체크포인트로 고르지 않는다).
- 지금 두뇌의 판정 판(N·G·끼임)은 학습과 겹쳐 돈다(학습 프로세스 수만큼 워커를 덜 쓴다). 워커 기본 max(2, CPU − 6) — 언리얼이 CPU 를 함께 쓴다.

## 4. 후보 고르기

- K = 1 이면 고르지 않는다(학습한 하나가 후보). K > 1 이면 N 세계 고르기 시드(35100~35119 × 지역, H_N)에서 잡힌 몫이 가장 낮은 하나(같으면 굶은 몫,
  그다음 모델 시드 번호가 작은 쪽). 고른 하나만 판정한다.

## 5. 관문 (짝 = 시드(지역 합), 문턱 = t 분포 양쪽 5%: N 은 시드 n = 80 · 자유도 n − 1 = 79 · t_crit = 1.990, G 는 시드 n_G = 40 · 자유도 39 · t_crit_G = 2.023)

문턱은 판정 시드 수에서 t 분포로 셈한다(`live.py t_crit` — scipy, 없으면 표). 시드 수를 바꾸면 문턱도 바뀐다.

| # | 기준 | 세계 | 통과 | 까닭 |
|---|---|---|---|---|
| R (먼저) | 재현 확인 | G | 스냅숏 `env.revision` 0 이고 두뇌 바꿈이 없을 때(`brain.last_swap_step` ≤ 0)만 잰다. 규칙은 적응 고리 GATE.md 변경 기록 (1) 그대로(지역 합 \|z\| ≤ 3, 지역마다 차이 ≤ max(3 × sd, 3 마리)). 실패하면 학습하지 않고 기각 | 거울이 지금 게임과 다르면 배운 두뇌도 게임에 맞지 않는다 |
| R (건너뜀) | 중간 변화로 재현 확인 없음 | — | 환경이 바뀌었거나 두뇌를 바꿔 끼운 뒤의 스냅숏은 Play 시작부터의 누적 수를 파이썬이 다시 만들 수 없다 — 건너뛰었다고 기록만 | |
| P1 (1차) | H_N 잡힌 몫 | N | 후보 − 지금 < 0 이고 짝 t ≤ −1.990 | 사람 결정 10-21 '포만 없는 세계 1차' |
| GN | H_N 굶은 몫 · 산 몫 | N | 굶음 짝 t < +1.990, 산 짝 t > −1.990 | 덜 잡히는 대신 굶으면 안 된다 |
| GG | H_G 잡힌 몫 · 굶은 몫 · 산 몫 | G | 잡힘·굶음 짝 t < +2.023, 산 짝 t > −2.023 | 실제 게임(포만 켬)에서 나빠지지 않는다 |
| G4 | 은신처 안 잡힘 | N·G | 후보 판정 세계 모두 0 | 은신처 안전 규칙 |
| G5 | 끼임 (`results/v3/wild2/stuck_check.py` 와 같은 셈) | G | 사슴 원판 끼임 0, 늑대 원판 끼임 ≤ 지금 두뇌 | 나무 사이에 끼는 행동을 배우지 않았나 |
| G6 | 악용 | G | 은신처 안 몫 ≤ 지금 두뇌의 2배, 먹기·도망·숨기 모두 1% 넘게 | 은신처 웅크림으로 이기지 않았나 |
| A5 (내보낼 때) | 두뇌 파일 다시 읽기 | — | sha256 같음, 골든 로짓 오차 ≤ 1e-4, 행동 같음, NaN·Inf 없음, 관측 21 계약, adapt 블록 그대로 | 언리얼 로더와 같은 검사의 파이썬 판 |

- **통과 = R(잰 때), P1, GN, GG, G4, G5, G6, A5 모두.** P1 을 못 넘으면 곧바로 기각. 지킴 하나라도 걸리면 기각. 보류는 없다.
- 판정 시드가 2개보다 적으면 짝 t 를 셀 수 없다(시드 하나면 표준오차가 없어 t = ±∞) — 어떤 t 기준도 통과로 두지 않고 기각한다. 판정·고르기 시드는 2개 이상만 받는다.
- 지역마다 기준(적응 고리 G3)과 K2-B 대조(P1b)는 빠른 판에서 뺐다 — 시드가 적어 칸마다 판단할 힘이 없고, K2-B 학습은 판 길이를 두 배로 늘린다.
  그래서 이 관문은 '이 환경에서 더 배운 두뇌가 덜 잡힌다'까지만 말하고, '스냅숏 정보 덕분인가'는 말하지 않는다.
- 같은 두뇌여도 지킴 t 칸 다섯(GN 둘·GG 셋, 한쪽 2.5%씩) 가운데 하나가 우연히 걸릴 몫은 약 12%다(서로 독립일 때 어림 — 칸이 얽혀 있어 실제로는 그보다
  작다). 나빠짐을 놓치지 않는 쪽을 골랐다.

## 6. 내보내기·판 번호

- 통과하면 `Saved/EcoAdapt/brains/live_r<판>_<시도 이름>.json.tmp` 에 쓰고, 파이썬에서 다시 읽어(A5) 확인한 뒤에만 `os.replace` 로 `.json` 이 된다.
  같은 이름은 덮지 않는다. 판 번호 = 지난 채택 판 + 1 (내장 두뇌 = 판 0). 시도 번호는 기각·거부·그만둠까지 센다.
- 두뇌 파일 `adapt` 블록: round(판)·attempt(시도)·run(시도 이름)·snapshot·env(Play 시작과 견준 환경 요약)·gate(관문 한 줄)·created_utc·play_id(바탕 스냅숏의 Play 번호).
  `model.name = live_r<판>_<시도 이름>` (언리얼 id = 이름@sha8).
- 언리얼(`eco.IntegratedV3.AutoAdapt 1`)은 Play 시작 뒤에 생긴, 그 Play 의 번호가 적힌 두뇌 파일만 받아 다음 결정 경계에서 바꿔 끼우고, 화면에 판 번호·환경·관문을 알린다.
  되돌리기 `eco.V3Brain.Rollback`. 되돌린 두뇌와 같은 환경의 스냅숏은 다시 배우지 않는다(환경 지문 + 두뇌 가중치가 이미 처리됨).
- 기각이면 두뇌 파일을 쓰지 않는다. 까닭은 `Saved/EcoAdapt/live/rounds/<시도 이름>/gate.md`·`result.json`, 상태 줄(`status.json`)에 남는다.
- 시험 크기(이 파일과 다른 크기, `--skip-check`, `--force-export`)는 `--root` 가 실제 폴더가 아닐 때만 받는다 — 판정이 아니다.

  4 분 G 잡힘 +0.10 %p(t +1.73, 시드 40)가 시드 80 에서 t ≈ +2.4 가 되어 GG 를 넘지 못할 것으로 어림했다. 그 차이는 384 마리 가운데 0.4 마리이고 8 분에서는
