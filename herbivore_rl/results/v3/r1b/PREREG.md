# v3 R1b 사전 등록 — RL 이 찾은 니치의 새 시드 확인 시험 (실행 전)

- 날짜: 2026-10-07. R1(`results/v3/r1/PREREG.md`)은 사전 등록 판정으로 **실패**했다(0/6, 모두 U_HIDE). 이 시험은 R1 판정을 바꾸지 않는다. R1 학습 모델 6개(`ckpt/v3/v3_r1_g995_s<시드>_20m.zip`)가 탐색에서 보인 행동 규칙을 **새 평가 시드**로 확인하는 새 시험이다(R0 의 '가까운 위협 앞 얼기' 확인과 같은 꼴).
- 가설 출처(탐색, 판정 아님): `results/v3/r1/explore/decision_map.py` → `decision_map.json`(판정 세계, 탐색 시드 12000~12007 × 3000, argmax, 결정 시점·마스크 두 칸 이상 표본). 6모델 공통으로
  - 숨기: **이미 은신처 안에서 위협이 가까우면 웅크린다**(거리 < 4: 59~93%, 4~6: 10~56%, 거리 ≥ 8·느린 접근: 0~1%). 은신처 밖에서는 먼 위협 때문에 은신처로 가지 않는다(FSM 은 거리 12 넘게 떨어진 위협에도 간다).
  - 얼기: **빠르게 다가오는 위협(접근 ≥ 0.9)** 앞에서 도망과 얼기로 나눠 반응하고(먹기 0~10%), 멀고 느린 위협에는 거의 얼지 않는다.
  - 천천히 기어 오는 위협은 가까워도 계속 먹는 비율이 높다(잠행형은 6 에서 돌진하며 접근 속력이 바뀐다).

## 1. 세계·시드·정책
- 판정 세계 `configs/v3_r1_on.yaml`, **새 평가 시드 10100~10119**(20개, 지금까지 어느 시험에도 쓰지 않았다) × 10000스텝, argmax. 마스크 판 2.
- 정책: RL(6모델), FSM, R_base·C_GRAZE·C1′(보고만). 도구 `eval_v3.py run --u-def r1b --seeds 10100 … 10119 --policies rl fsm rbase c_graze c1p --out results/v3/r1b/judge`.

## 2. 지표 (결정 시점 표본, 평가 시드 합침, 거리·은신처 단위는 세계 길이)
- U_ESC: R1 과 같다(P(FLEE ∪ HIDE ∪ FREEZE | 보임 & 접근 ≥ 0.75 & 거리 < 10) − P(같은 행동 | 위협 없음)).
- **U_HIDE′ (제자리 웅크림)** = P(HIDE | 보임 & 은신처 안 & 거리 < 6) − P(HIDE | 보임 & 은신처 안 & 거리 ≥ 8 & 접근 < 0.7).
- **U_FREEZE′ (빠른 위협 앞 얼기)** = P(FREEZE | 보임 & 접근 ≥ 0.9 & 은신처 > 5) − P(FREEZE | 보임 & 접근 < 0.7 & 거리 ≥ 8).
- 사용 비중·깜빡임·굶음·성과: R1 4절(10-07 개정 문턱) 그대로.

## 3. 시드별 통과 (모두)
1. 성과: RL − FSM G_γ 짝 t ≥ −2.093.
2. U_ESC ≥ 0.18, **U_HIDE′ ≥ 0.2, U_FREEZE′ ≥ 0.1**(탐색 값보다 낮게 잡았다 — '그 상황에서만 쓴다'가 있는지 확인하는 문턱이고, 탐색 시드에서 맞춘 값이 아니다. 무작위 C1′ 은 0 근처여야 한다).
3. 사용 비중 ≥ 0.5%(넷 모두), 깜빡임 ≤ 0.65.
4. 아사율 ≤ 1.5 × FSM.

## 4. 판정과 출시
- **R1b 성공** = 6모델 중 4모델 이상 통과.
- 출시: 통과한 모델 중 보정 시드 20000~20019 × 10000 의 G_γ 평균이 가장 높은 것(argmax). 평가 시드로 고르지 않는다.
- 실패하면 행동 레퍼토리는 규칙 장면(FSM)으로 닫는다. 대응은 없다.
