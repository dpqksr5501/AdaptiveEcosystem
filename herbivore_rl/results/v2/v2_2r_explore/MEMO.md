# v2.2r 탐색 메모 (탐색층, 학습 전 작성)

- 작성: 2026-10-03, 학습 시작 전. 근거: 10-03 결정 R1~R10(수정 제안서 `Docs/RL_Policy/RL_V2_REVISION_PROPOSAL.md` 3.1·3.2·3.8, 계획서 10절).
- **탐색층이다.** 평가 시드 10000~10019 는 쓰지 않는다. 결과를 주장에 쓰지 않고, 고른 팔은 확인층(학습 시드 5~9, 평가 시드)에서 다시 잰다.
- 실행기: `probe_v2.py` (train → eval → judge). 이 메모의 규칙은 결과를 본 뒤 바꾸지 않는다. 바꾸면 '결과 뒤 변경'으로 따로 적는다.

## 1. 묻는 것
v2.2(경계 행동 차원)는 전역 비용(정지·섭식 0) 때문에 μ 가 무너졌다(1-6, 1-6b, 모델 11개). 창(포식자를 놓친 뒤 약 13스텝) 안에서만 효력이 있는 표현이면 RL 이 상태에 따른 판단을 배우는가.

## 2. 팔과 예산
| 팔 | 설정 | 학습 시드 | 묻는 것 |
|---|---|---|---|
| T0 | `configs/v2_1.yaml` | 20·21·22 | v2.1 의 세 시드가 운이 좋았나. T1 의 기준 |
| T1 | `configs/v2_2r_t1.yaml` (v2.1 + 관측 8, 경계 열 없음) | 20·21·22 | 관측 8만으로 학습이 나빠지나. L 의 대조군 |
| L | `configs/v2_2r_l.yaml` (T1 + 반사 돌아보기) | 20·21·22 | RL 이 창 안 정지를 배우나 (1순위) |
| W′ | `configs/v2_2r_w.yaml` (v2.2 + 창 경계, 섭식 1.0·120°, 시작 편향 0) | 20·21 | 별도 차원으로 창 안 경계를 배우나 (보조) |

- 학습 11개 × 20M, γ 0.9916661555611042, ent_coef 튜닝값 그대로, `--probe-every 1000000`(1M마다 구간별 결정 확률 기록).
- 평가: 탐색 시드 12000~12039 × 5000스텝, 두 모드(결정, K24 유지 표본: 보행·경계 열만 표본, 조향은 평균).
- 기준선(학습 없음): C2(E2 C2 상수, T1 세계), C2_W′(C2 + 경계 1, W′ 세계 = C2-seg-L 근사), OVL(v2.1 원 모델 s0~2 + 창 안 정지 규칙, L 세계, 결정 모드), V21(v2.1 원 모델, L 세계, 결정 모드).
- 계산 예산: 학습 약 1h, 평가 약 0.5h. 정식 C2-seg-L(TPE 112)은 확인층의 학습 실패 감지용으로 따로 돌린다.

## 3. 조기 중단 (학습 중)
- L: `b3_l_prob`(아래 B3_L 의 확률판), W′: `p_vig_win`. 2M 또는 5M 기록에서 시드 절반 이상(올림)이 0.01 미만이면 그 팔의 남은 학습을 멈춘다. 멈춘 팔은 실패다.
- T0·T1 은 멈추지 않는다.

## 4. 팔별 새 결정 사용 지표 (B3)
- B3_L = P(정지 | 창 안) − P(정지 | 평시), 결정 때 energy ≥ 0.5 표본만. 2M·5M 은 학습 중 확률 기록(`b3_l_prob`, 명령 정지 확률), 20M 은 평가 값(`window_stats` 의 `b3_l`, 실제 정지).
- W′: 창 안 경계 확률. 2M·5M 은 `p_vig_win`(확률), 20M 은 평가의 `p_vig_win`(효력이 난 경계 비율).
- 창 = 결정 때 포식자 안 보임 & threat_recency > 0.5.

## 5. 모드 선택 (R1)
팔마다 C0 를 두 모드로 잰다. 팔 평균(모델 평균) G_γ 의 K24 − 결정 짝 t(탐색 시드 40개)가 |t| > 2.023 이면 높은 쪽, 아니면 크기 통과 수(새 결정 사용 지표 ≥ 기준, B1 ≥ 0.3)가 많은 쪽, 같으면 결정 모드. 아래 규칙은 고른 모드로 본다. C1′·C4 는 고른 모드에서만 잰다.

## 6. 선택 규칙 (탐색 시드 40개, 팔의 모델 평균, 고른 모드)
- (i) 새 결정 사용: L 은 B3_L ≥ 0.1 이 2M·5M·20M 모두. W′ 는 창 안 경계 확률 ≥ 0.05 가 2M·5M·20M 모두. 2M·5M 은 시드 평균이다.
- (ii-a) C0 − C2 > 0, C0 − C1′ > 0, 둘 다 짝 t > 2.023.
- (ii-b) C0 ≥ OVL − 0.3.
- (ii-c) W′ 만: C0 − C2_W′ > 0 (짝 t > 2.023), 그리고 C4-energy 고정(그 모델·모드 C0 의 평균 energy)에서 창 안 경계 비율이 떨어진다(C4 − C0 짝 t < −2.023).
- (iii) 아사율 ≤ 1.5 × C2 아사율.
- (iv) B1 ≥ 0.3.

## 7. 미리 정한 갈림 (사람 결정을 기다리지 않는다)
1. L 이 (i)~(iv)를 통과하면 L 로 간다 → 확인층.
2. L 이 실패하고 W′ 가 (ii-c)까지 통과하면 W′ 로 간다 → 확인층.
3. 모두 실패했고 4번 신호가 없으면 CM(범주형 보행 + L 반사)을 한 번 시도한다(10-06~10-08). 같은 기준을 쓴다.
4. T1 평균 G_γ 가 T0 보다 0.3 이상 낮고 3 대 3 완전 분리(T1 최고 < T0 최저)면 원인이 경계 밖(관측 8 의 정규화·감쇠나 코드)에 있다. 하루 조사 상자를 두고 그다음 대체안으로 간다.
5. 10-10 까지 통과가 없으면 대체안: (a) OVL − V21 이 탐색 시드에서 유의하면 규칙 장면(v2.1 + 창 규칙, 재학습 없음), v2.1 을 새 시드 30~34 로 확인. (b) 아니면 v2.1 확인 후 1단계를 "S1만"으로 닫는다.
6. 학습 실패가 아니고 B2만 미달이면 B2 를 2차로 내리고 닫는다.
7. T0 와 원래 v2.1 시드의 차는 기술로만 적는다(문턱 없음).

## 8. 확인층 (선택된 팔만, 10-06~10-09)
학습 시드 5~9 × 20M, 평가 시드 10000~10019, 출시 모드는 5절로 고른 모드에 고정한다. 1차 지표 B1·B2·B3(팔별 정의), 학습 실패 대조는 E1-b C2-seg 와 고른 팔의 정식 C2-seg. 사전 등록은 확인 학습 전에 따로 쓴다. 10-10 에 1단계를 닫는다.
