## 2. 무엇을 알았나
1. **환경은 의도대로 움직인다.** 밤에 포식자를 반 거리에서야 알아봐 피식이 늘고(C2F), 은신처에서 멈춰 쉬면 덜 굶는다(CSTOP). 밤 섭식 감소는 흡수 가능량 제한 때문에 하루 섭취를 거의 줄이지 못해(0.88) 뺐다 — 계획서 4.9.2 가 예상한 대로다.
2. **밤 은신처 휴식은 개체에게 손해다.** 소수 침입 시험(`diag_invasion/invasion.md`): 16마리만 '밤엔 은신처로 가서 쉬기'를 쓰면 16칸 조건 모두에서 피식은 유의하게 줄지만 개체-스텝당 보상은 16칸 모두 줄고 그중 15칸이 유의하다(−0.0014~−0.0103, 유의하지 않은 칸은 하루 600·느린 포식자·C2 바탕·배부를 때만 변형, t −1.69). 덜 먹어 번식(+10)을 놓치는 손해가 안전 이득보다 크다. 상수 정책 탐색도 같은 말을 한다: 위상 구간별 상수(C2-seg)는 C2 와 다르지 않고(1.328 대 1.256, t 1.42), 밤 900스텝 세계와 450스텝 이하 세계 모두 밤 최적 속도가 '늘 걷기'(0.534)다.
3. **휴식 할인이 '들판에서 멈추기' 함정을 만든다.** 원래 v2.4(정지하면 어디서든 할인)로 학습한 모델은 밤에 더 멈추지만(정지 0.29 대 낮 0.12) 은신처 비율은 낮과 같고, G_γ 가 C2 보다 낮다. 할인을 끄면(진단 팔) 성능이 v2.1 수준으로 돌아온다. 할인을 은신처 안으로 제한한 v2.4b 는 두 시드가 좋았지만(1.58·1.49) 한 시드가 굶는 갈래로 빠졌다(−1.35).
4. **낮밤 세계에서 새로 배우는 것보다 v2.1 정책이 낫다.** v2.1 학습 G 팔 24모델을 같은 v2.4 판정 세계에 넣으면 G_γ 중앙값 1.543(최소 1.221)이다. v2.4 레시피 6모델은 1.21·0.79·1.29·0.40·0.84·1.54(탐색 시드). 짧은 확인 평가 시드에서도 v2.1 출시 모델 FIX 1.814 > C2 1.712 > v2.4 3모델 평균 1.055.
5. **좋은 소식:** v2.4 모델의 낮 구간 B1(가까운 포식자에 뛰기)은 0.27~0.72 로 v2.1 G 팔(중앙값 0.21)보다 높다((iv) 통과). 밤이 위험해지니 뛰기 반응이 강해졌다.

## 5. 다음과 10-13 회의 안건
- 사전 결정(R4, 수정 제안서 4.3 물러섬): v2.4 N 주장은 2차. 다음 버전(v2.3 기억, 10-28~)으로 간다. 2단계 확인(11-18)도 실패하면 V2a 는 '1단계 산출물 + 낮밤은 탐지 배수 규칙(#21)'이다.
- 회의에서 확인할 것:
  1. 낮밤을 RL 장면으로 살릴지: 밤 은신처 휴식의 개체 이득을 만드는 손잡이(계획서 4.9.2 의 Gate N 실패용 조절값 — 밤 포식자 시야 ×1.3·속도 ×1.1·야행성. 속도는 E1-b 의 '뛰기는 모든 포식자보다 빠르다'를 깬다)를 쓸지, 아니면 탐지 배수 규칙(환경 장면)으로 둘지.
  2. Gate N (a1)·(a3)을 C2 대신 메커니즘을 느끼는 상수(C2F·CSTOP)로 판정한 것(`PREREG.md` 2절).
  3. N5′ 1차 정의를 C1′ 대비 차로 바꾼 것(원값은 상수에서도 −0.5 대라 쓸 수 없다).
  4. 휴식 할인 위치 키 rest_cover_only(v2.4b) — 계약 4.9.2 (c) 문구.
  5. γ 0.995 레시피 확인(#27 도 0.995).
  6. 출시: v2.1 s1a_g_s58 을 계속 쓸지, 규칙대로 고른 v2.4 s42 를 쓸지.
  7. v2.0b 는 학습에서 빼는 것으로 확정(R10 사전 결정). 격자 장부(#20)·M3 재생 사양은 급하지 않다.
