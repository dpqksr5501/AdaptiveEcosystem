## 권고
1. 대응은 **B 시작 상태 유도** 한 번으로 한다. 학습 세계의 리스폰 슬롯과 세계 리셋 슬롯 20% 를 '먹이 가장자리·배고픔' 상태에서 시작시킨다(발밑 먹이 < 0.05, 먹이 기울기 ≠ 0, 에너지 U[0.2, 0.4]). 평가는 표준 분포 그대로 둔다. R8 1순위 표현(CM 보행)은 공통 기제 forage 를 건드리지 않아 건너뛴다. 건너뛰는 이유는 메모에 적는다. 학습 전 점검 P4 가 실패하면 매개변수를 한 번 바꾸고, 다시 실패하면 C(C2-seg 모방 초기화)로 간다.
2. 재측정은 기준 팔과 유도 팔 각 24시드로 한다(새 학습 시드 50~73, 두 팔 같은 번호, `--threads 1`). 1차 통계는 나쁨 수에 대한 피셔 정확 검정(단측 α 0.05) 하나다. 대응이 실패를 모두 없애면 검정력은 0.86~0.97 이다. 실패율을 0.10 으로 줄이면 0.38~0.62 다.
3. '나쁨' 정의는 stage1_close.md 8절 그대로 두고 경계만 숫자로 고정한다. 판정은 결정 모드, 평가 시드 10000~10019 로 한다.
4. 조기 감지 규칙은 중단과 판정에 쓰지 않는다. 규칙 B(10M)·D(19~20M)는 기준 팔에서 예측 시험만 한다.
5. 출시 모델은 채택한 레시피 팔에서 탐색 시드 12000~12039 로 고르고, 평가 시드 값으로 보고한다(3절 8).
6. 사람 결정이 필요한 것(R8 밖): γ 0.998(이미 잡힌 v2.4 전 γ 재비교 #27 에 실패율 열을 넣는 안), 보상·대사 변경, 출시용 규칙 덧씌우기.

### 1.2 기제 (결과 뒤 기술)
- 아사의 88~98% 가 용량 0 셀에서 일어난다. food_grad 는 블러 반경 2셀의 기울기라 빈 땅 한가운데서는 0 이다. 그곳에서 forage 는 효력이 없다.
- 리스폰 에너지 0.5 는 배고픔 문턱과 같다. 굶는 경로는 '무작위 위치·에너지 0.5 리스폰'에서 시작한다. 아사 개체 73~84% 가 리스폰 뒤 0.5 를 넘지 못했다.
- forage 의 개체 이득은 기울기가 있는 곳에서만, 100스텝 규모에서야 보인다. 은신처는 피식을 조금 줄인다(cover 0.2 고정 시 s24 피식 +0.00028, t +6.8). 그래서 forage 의 정책 기울기 신호가 약하다. forage 가 한번 낮아지면 빈 땅 체류가 늘어 신호가 더 줄어드는 고리가 생긴다(추정). 학습 기록에서 나쁜 묶음의 은신처 비율이 7M 0.29 → 20M 0.42(좋음 0.29 → 0.25)로 늘었다. forage log_std 도 덜 줄었다(20M −0.165 대 −0.276). 두 관찰은 이 설명과 맞는다(추정).
- 정지는 그 위에 얹힌 2차 반응이다. 좋은 모델도 아사 직전 50스텝의 절반 이상을 정지한 비율이 0.65~0.99 다(s23 제외).

### 1.3 조기 감지
- 2M·5M 신호는 없다. 10M 후보(규칙 B)는 결과를 본 뒤 고른 것이고 p_fw 0.79 다. 학습 끝 규칙 D(18~20M reward_per_step < 0)는 13/13(p_fw 0.134)이다. 그러나 그 시점에서는 평가로 바로 가릴 수 있다.
- 10M 저장 모델 8개 중 7개(좋음·나쁨 모두)가 '배고프면 멈춤' 중간 상태에 있다(결정 모드 배고플 때 P(정지) 0.62~0.98). 감지 열을 더해도 10M 전에 가려내기는 어렵다(추정).

## 3. 재측정 설계 (학습 전에 고정)
1. 팔: 기준(`configs/v2_1.yaml`), 유도(`configs/v2_1_ind.yaml`), 선택 팔 T3(기준 설정, `--threads 3`, 시드 50~61). T3 는 10-05 18:00 까지 주 팔이 끝나면 돌린다. 모든 팔은 20M 이고 γ·ent·세계 수는 그대로다. `--save-at 10000000 --probe-every 1000000` 을 붙이고, 주 팔은 `--threads 1` 이다.
2. 학습 시드: 50~73(24개), 두 팔 같은 번호. 40번대는 계획서가 2단계 짧은 확인(40~42, 제안)에 잡아 두었으므로 피한다. 이름은 `s1a_base_s<시드>`·`s1a_ind_s<시드>`·`s1a_thr3_s<시드>` 다.
3. 예산: 주 팔 48개를 12개씩 4파로 돌린다(파마다 기준 6 + 유도 6, 같은 시드). 25~37분 × 4파 ≈ 2~2.5시간이다. T3 12개는 6개씩 2파(18스레드, 논리 코어 20)로 약 1시간이다(추정). 평가(두 팔 모두 평가 시드·탐색 시드, 결정·K24)는 워커 6개로 약 4시간이다(추정, A1 실측 잡당 약 2.3초로 환산).
4. 나쁨 정의(그대로): G_γ(결정, 평가 시드 20개 평균) ≤ C2 − 1 = 0.482 이고 아사율 ≥ 2 × C2 = 0.000854 다. 경계는 나쁨이 아니면서 G_γ < 0.982 이거나 아사율 > 0.000641 인 경우다. C2 는 기존 값을 고정해 쓴다. 정의를 고칠 이유는 없다. 14모델이 4·1·9 로 갈리고 기제 지표(forage, cos)와도 같은 쪽이다. s30 은 아사율 2.08배로 문턱에 붙어 있으므로 두 조건 값을 따로 적는다.
5. 평가: 평가 시드 10000~10019 × 5000스텝, γ 학습값, 끝 600스텝 제외다. 판정은 결정 모드(S1-c)로 하고 K24 는 한 줄로 보고한다. 경로는 diagnose_v2 와 비트 동일임을 확인한 rollout 경로(`a1/a1_check.json`, `a3_verify.json`)다. 유도 팔도 `configs/v2_1.yaml`(config_digest f068496361f9) 세계에서 잰다.

  - 나쁨+경계 수 피셔 단측
  - 모델별 G_γ − C2(유도 > 기준)와 log(아사율/C2)(유도 < 기준) 만-위트니 단측
  - 기준 팔 + 기존 스레드 1 모델 11개(t0 s20~25, v2_1c s30~34, 평가 시드 결정 모드 라벨: 나쁨 4, 경계 1)를 합친 35 대 유도 24 피셔 단측
  - 팔별 실패율 Clopper–Pearson 95% 구간
  - 같은 시드 짝의 2×2 표(기술)
- 채택:
  - (i) 1차가 유의하면 '개선 확인'으로 채택한다.
  - (ii) 1차가 유의하지 않아도 나쁨 수가 더 적고 G_γ − C2 만-위트니 단측 p < 0.05 이면 '개선(2차 지표)'으로 채택한다.
  - (iii) 그 밖에는 채택하지 않고 기준 레시피를 유지한다.
  - 해 점검(H2): 출시 모드 B1 ≥ 0.3 모델 수(피셔 양측)나 나쁨이 아닌 모델의 G_γ(만-위트니 양측)가 유도 팔 쪽에서 p < 0.05 로 낮으면 (i)·(ii)여도 채택하지 않는다.
- 기제(H3, 기술): 결정 모드 forage 평균, cos(이동, 먹이 기울기), 배고픔 비율, 은신처 비율, 배고플 때 P(정지), TB act/forage_mean 곡선. 유도 팔의 TB 값에는 유도 표본이 섞여 있다는 점을 함께 적는다.
- T3(H4): T3 와 기준 팔의 나쁨 수를 피셔 양측으로 비교한다. 유의하지 않으면 '판단 불가'로 적는다.
- 검정력(이항 정확 계산, 기준 실패율 0.29~0.36):
  - 24 대 24 에서 유도 실패율이 0 이면 0.86~0.97, 0.10 이면 0.38~0.62, 0.15 이면 0.21~0.41 이다. 실제 1종 오류는 약 0.026 이다.
  - 유의 경계: 유도가 0개면 기준 ≥ 5, 1개면 ≥ 6, 2개면 ≥ 8 이다.
  - T3(12 대 24, 양측): T3 실패율이 0 이어도 0.37~0.69 다.

## 7. 출시 선택 규칙 (S1-a)
- 후보: 채택한 레시피 팔의 24모델이다(채택하지 않으면 기준 팔).
- 모드: 그 팔 모델들의 탐색 시드 K24 − 결정 G_γ 짝 t(choose_modes(tie="det"))로 정한다. 유의하지 않으면 결정 모드다.
- 자격(탐색 시드, 정한 모드): 아사율 ≤ 1.5 × C2_탐색(0.00068027)이고 B1 ≥ 0.3. 자격 모델 중 탐색 시드 G_γ 가 가장 높은 모델을 고른다. 같으면 작은 시드를 고른다.
- 자격 모델이 없으면 B1 조건을 뺀다. 그래도 없으면 v2_1c_s34(K24)를 유지한다.
- 보고: 고른 모델의 평가 시드 G_γ·아사율·피식률·B1 과 팔 분포(n, 나쁨·경계 수, G_γ 중앙값·사분위)를 적는다. 주장은 분포와 실패율로 한다. S1-b 시연 모델(v2_1c_s34)은 이 규칙으로 바꾸지 않는다.
