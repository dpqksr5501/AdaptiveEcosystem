### H-지평: 계산과 실제 세계 표본
- 유효 지평 1/(1−γ) = 120.0스텝, 반감기 82.8스텝이다. 에너지 0.5 에서 정지 350 / 걷기 250 / 뛰기 100스텝이면 굶어 죽고, −10 의 현재 가치는 −0.53 / −1.23 / −4.33 이다. 에너지 0.2 에서는 정지 140스텝, −3.10 이다.
- 단순 모델(에너지 0.5, 빈 셀): 끝내 먹이를 못 찾으면 정지 0.435 대 걷기 −0.403 으로 정지가 낫다. 먹이가 249스텝 안에 있으면 번식 +10 덕분에 걷기가 +1.50~+9.01 낫다. 그래서 정지와 걷기 중 무엇이 나은지는 '걸으면 먹이를 찾는가'가 정한다.
- 같은 상태 갈래(S의 초점 16마리, 정지 대 걷기 K스텝 고정): 걷기−정지는 K30 에서 나쁨 +0.07~+0.46, 좋음 +0.32~+0.88 이고, K120 에서 나쁨 +0.26~+1.30, 좋음 +0.65~+1.81 이다. 120스텝 안에 먹이에 닿을 확률은 걷기 갈래가 나쁨 0.30~0.52, 좋음 0.50~0.60 이고 정지 갈래는 0 이다. 이득이 작고 늦게 나타난다. PPO 가 짧은 이탈에서 보는 신호가 약하다는 것은 (추정)이다.
- 아사의 88~98%가 용량 0 셀에서 일어난다. s31·s33·s24 는 S 에서 에너지 0.21~0.26 일 때 멈추고, 좋은 모델은 0.07~0.19 일 때 멈춘다. 나쁜 모델이 더 일찍 포기한다.

### H-보상·정지 대사
- 빈 셀의 즉시 보상은 정지 0.008571, 걷기 0.008 이다(획득량 보상이면 둘 다 0.01). 정지 쪽 차의 무한 할인 합은 0.069 다. 같은 궤적을 획득량 보상으로 다시 세면 모든 덧씌우기·침입 ΔG 가 0.044 이내로 같다(예: s31 ic +1.594 / +1.637).
- 정지 대사는 먹이가 없을 때 수명을 1.4배로 늘려 정지를 최선 반응으로 만든다. 그러나 s30 은 거의 멈추지 않고(0.2%) 굶는다. 좋은 모델도 아사 직전 50스텝은 대부분 정지다(s23 을 빼면 0.65~0.99). 정지는 나쁜 모델을 가르는 공통 원인이 아니다.

### H-스레드
- 나쁨 0/3 대 4/11 의 피셔 p 는 단측 0.330, 양측 0.505 다. 경계를 나쁨으로 치면 0.231 / 0.258 이다. 0개 실패로 p < 0.05 가 되려면 --threads 3 모델이 11개(경계 포함 시 8개) 필요하다.
- torch 스레드 1 과 3 은 같은 배치의 기울기를 비트 단위로 바꾼다(14텐서 중 8개, 상대 차 최대 2.3e-6). 같은 스레드로 다시 돌리면 같다. 그래서 같은 시드·다른 스레드 학습은 서로 다른 표본이고 짝 비교가 안 된다. 날짜(10-02 대 10-03)와 탐침 켜기도 같이 바뀌었다.

### 언제 갈렸나 (학습 곡선, 결과 뒤 기술)
- act/forage_mean(학습 표본)은 5M 에서 나쁨 0.59~0.74, 좋음 0.56~0.84 로 겹친다. 20M 에서는 나쁨 0.154~0.360, 좋음 0.509~0.830 으로 갈린다. 나쁜 4시드 모두 5M 이후에 떨어졌다.

### 대응 후보가 겨냥할 기제
- 겨냥할 기제는 5M 이후 forage 가중치가 상태와 무관하게 내려가는 붕괴다. 개체 이득(침입 +0.72~+1.26)이 있는데도 학습이 그 방향으로 가지 않는다. 빈 땅 정지는 그 뒤에 따라오는 2차 반응이다.
- 순변화 보상이나 c_rest 를 바꾸는 대응은 이 기제를 겨냥하지 않는다(재채점 차 ≤ 0.044).
- 겨냥할 수 있는 후보: '배고픔 + 빈 땅' 상태에서 시작하는 상태 유도(R8 (2) 재정의), 지평을 늘려 신호 키우기(γ 0.998 에서 침입 이득 2.4~3.0배. G_γ 비교 가능성 문제가 따른다), 감지 열(배고플 때 forage, P(정지 | S))을 1M 마다 기록. 어느 것이 효과가 있을지는 (추정)이다.
- 배고플 때만 고치는 규칙으로는 번식 차가 남는다. 그래서 대응은 배부를 때의 forage 도 회복해야 한다(추정).
