# 체형의 레벨 디자인 인계

상태는 제안이다. 새 레벨이나 원본 팀 맵을 변경하지 않았다. [공통 설계](../Architecture/INHERITED_MORPHOLOGY_DESIGN_20261105.md) · [자연 서식지 배치](NATURAL_HABITAT_LEVEL_HANDOFF_20261030.md)

| 비교 장면 | 배치와 확인 기준 |
| --- | --- |
| 열린 초지와 경계 | 평평한 구간과 완만한 방향 전환을 한 쌍으로 만든다. 같은 출발·목표·위협에서 실거리, 시간, 에너지, 충돌, 이주 통과를 함께 확인한다. 달리는 실루엣과 보폭이 맞는지 본다. |
| 관목 내부와 노출 가장자리 | 실제 지면에서 관목 높이·폭·밀도, 지면 경사, 시야 차폐와 접근 가능한 자리를 확인한다. 같은 거리·날씨·자세에서 은폐 차이를 비교한다. 자연 엄폐와 포획 보호가 설정된 은신처는 별도 표시한다. |
| 늑대의 추격과 근접 | 직선·모서리·막힌 경로·보호 은신처 경계에서 선행 확인한다. 턱/몸통의 표현, 실제 접촉 거리, 추격 중 회전·통과 폭을 같은 프레임에서 대조한다. |
| 새끼·성체·사체 | 가까이와 멀리에서 체형·자세가 읽히는지 보고, 색만으로 차이를 구분하게 하지 않는다. 지면 접촉, 애니메이션과 IK, LOD, 두 성장 메시 전환, 사체 외형 고정을 확인한다. |

지형·수면·차폐는 기존 권위 입력으로 저작한다. 장식 Mesh나 메시 크기만으로 은폐 또는 충돌 판정을 새로 부여하지 않는다. 기존 owned JYU 복사 맵에서 먼저 확인하고 팀 맵의 World Partition과 스트리밍, 실제 경로, 서버·Client·cook acceptance를 별도로 기록한다. 후속 적용에는 지형 기준 cm, 안정된 구역 ID, 지면/수원 설정, 허용 체형 범위, 반복 실행 시드를 인계한다.
