# 다종 생태계 팀 인수인계

> JWJ 브랜치에 PR #16/main을 가져온 후의 계약과 실행 결과는 [통합 기록](PR16_JWJ_MERGE_20261109.md)을 따른다. 그 통합본의 저장 포맷은 지역 순차 이주 상태를 포함한 5다. 아래 포맷 4/299개 검증은 PR 원본의 실행 이력이다.

작업 브랜치는 `codex/social-shelter-handoff`이며 검증 기준은 `cde24fa5`다. 역할별 후속 작업은 아래 표에서 확인한다. [통합 PR #16](https://github.com/dpqksr5501/AdaptiveEcosystem/pull/16)

## 첫 실행과 공통 기준

1. [프로젝트 공통 맥락](../PROJECT_CONTEXT.md)에서 UE 5.8, 권위 서버, 빌드 규칙을 확인한다. 다종 기능을 확인하는 맵은 로컬 `/Game/JYU/Maps/LV_JYU_Fauna`다. 팀 통합 맵을 대상으로 검증할 때는 맵과 결과를 별도로 기록한다.
2. 공개 체크아웃에는 코드와 작성 도구가 있다. 라이선스가 확인된 원본 모델·음원을 준비한 뒤 소유 테스트 맵을 생성한다. [로컬 에셋 준비와 맵 생성](../조연우/JYU_FAUNA_INTEGRATION_20261108.md#공개-pr과-로컬-재현)
3. 비교할 때 SHA, 맵, 활성 두뇌, 시드, 시간 배율, 서식지 단계와 대사 설정을 기록한다. 0단계는 기준 설정, 1단계는 쥐 서식지, 2단계는 공유 대체 먹이, 3단계는 표범 배치·접근을 누적 적용한다. [재현 명령과 30분·60분 결과](../Architecture/FAUNA_POPULATION_BALANCE.md)

## 지금까지 확인한 범위

- 소유 다종 맵에서 UE 5.8.4 빌드, 자동화 299개, 단계별 30분 비교 10회와 60분 확장을 수행했다. 최종 3단계는 여우가 세 시드 모두 생존했고 표범은 세 시드 모두 30분 전에 기아로 사라졌다. 쥐는 시드별 결과가 달랐고 60분에서는 쥐 2마리, 늑대 1마리였다. [개체군 비교 기록](../Architecture/FAUNA_POPULATION_BALANCE.md#최종-30분-비교)
- 다종 전용 서버 접속·복제와 포맷 4 새 Standalone 프로세스 복원은 별도 실행이다. 최종 포맷 4를 포함한 복수 Client, 팀 레벨, 패키지, 장기 플레이어 반복 사냥은 후속 검증 범위다.
- 생명주기와 피해·먹이 거래는 권위 서버에서 확정한다. Native 사슴·늑대와 규칙 종은 각자의 단일 이동 경로를 사용하고 Client는 Bubble 표현과 요약을 소비한다. 지역 식생, 서식지 먹이, 사체 재고는 각 지급 경계에서 차감한다.
