# AdaptiveEcosystem 전체 고려사항과 독립 감사 프롬프트

## 감사의 기준

환경과 생물이 서로 영향을 주는 장기 생태계를 검증한다. 토양·물·지형·기후가 식생을 바꾸고, 식생과 다른 생물에 관한 증거가 개체 행동을 바꾸며, 그 행동의 결과가 다시 환경·자원·개체군을 바꾼다. 플레이어도 이 고리에 들어간다. 자원, 행동, 번식, 세대 교체의 시간차를 기록한다.

어떤 종이 살아남도록 주변 자원이나 출생을 맞추는 규칙은 감사 대상이다. 자연스러운 성장·감소·이주·지역 소멸도 유효한 결과다. 개체에게 현실적으로 가능한 선택지가 있었는지, 실제로 그 선택을 실행할 수 있었는지, 환경이 회복된 뒤 살아 있는 개체가 돌아올 수 있었는지로 결과를 판단한다. 장기 생존을 비교할 때 생태적 결과, 구현 결함, 레벨 설정, 실행 시간 조건의 영향을 각각 근거로 판별한다.

## 전체 고려사항

### 환경, 서식지, 자원

| 범위 | 확인할 사항 |
| --- | --- |
| 토양·수문·기후 | 지형, 경사, 고도, 배수, 그늘, 토양 수분·영양, 물의 연결과 수심, 강우·기온·수온·바람, 낮밤과 계절이 실제 지역 입력으로 이어지는가. 비가 그친 뒤 남는 수분과 서식지별 회복 속도, 날씨 순서와 누적 효과가 있는가. 날씨 표현과 실제 자원 입력을 대조한다. |
| 식생·먹이·물 | 발아·성장·번식·고사·재생의 조건, 식물과 먹이의 위치·분포·양·품질·영양가, 먹을 수 있는 부위와 시기, 수원 접근과 고갈을 살핀다. 표시된 식생과 권위상 섭식 가능량을 대조한다. 지역 총량, 탐지 가능한 양, 도달 가능한 양, 실제 지급량을 구별한다. |
| 공간의 질과 연결 | 같은 면적이라도 먹이터·수원·그늘·은신처·번식지·비행 및 착지 공간의 배치와 연결이 결과에 미치는 영향을 본다. 지역 경계, 종별 이동 가능 면적, 도착지의 수용력, 유입이 끊기면 유지되지 않는 서식지를 구별한다. 통로 위치·폭·단차·수심·장애물과 여러 지역이 동시에 악화되는 조건을 비교한다. |
| 생물이 환경에 되돌리는 영향 | 섭식, 밟힘, 뿌리 파기, 씨앗 이동, 사체 분해, 토양으로 돌아가는 물질이 이후 식생과 자원에 어떻게 반영되는지 확인한다. 분해나 만료 시 실제 장부에서 빠지는 양과 시점을 확인하고, 식생 재고와 토양 영양에 같은 양을 두 번 지급하는 경로를 찾는다. |
| 교란과 공간 규모 | 단발·지속·반복 교란, 가뭄→비와 비→가뭄, 통로 차단·재개방, 플레이어 사냥과 환경 악화의 중첩을 비교한다. 지역만 바뀐 경우와 여러 지역이 함께 바뀐 경우를 분리한다. 물·서식지·식생 변화의 시간과 공간 규모가 동물의 이동과 번식 주기에 맞는지 검토한다. |

### 개체의 감지, 판단, 실행

| 범위 | 확인할 사항 |
| --- | --- |
| 감각과 흔적 | 시야·시야각·차폐·낮밤, 청각·표면·거리·강도·차폐, 냄새·발자국의 출처·시각·신뢰도와 감쇠를 확인한다. 날씨와 지형에 따른 증거 품질, 거짓 단서, 사라진 흔적과 포기 조건을 본다. 직접 목격, 마지막 흔적 위치 수색, 공유 경보, 실제 표적의 현재 위치는 각각 다른 근거로 추적한다. 공유 경보가 직접 목격으로 다시 퍼지는 경로도 찾는다. |
| 기억과 적응 | 성공·실패·위협의 기록이 다음 탐색과 선택에 미치는 영향, 기억이 갱신·감쇠하는 시점, 익숙한 자원이 고갈된 뒤 전환까지 걸리는 시간을 확인한다. 환경이 되돌아왔을 때 이전 행동을 다시 선택할 수 있는지, 목표가 지나치게 자주 바뀌거나 오래 고정되는지도 본다. |
| 욕구·대사·건강 | 허기 시작, 포만, 에너지 0 체류, 기아 피해, 실제 섭취와 회복을 분리한다. 휴식·보행·질주·비행·추격·성장·번식과 체급·나이·부상·피로에 따른 비용, 갈증·체온·휴식의 우선순위를 점검한다. 저장 단위와 게임 시간·실시간·배속의 적용 위치를 확인한다. 질병·기생·부상 회복은 현재 관찰에 필요한지 평가할 후보로 둔다. |
| 후보와 행동 선택 | 종별 능력·식성·체급·성숙도·공격성·사회성·개체 상태가 가능한 후보를 결정하는가. 현장에서 얻은 먹이·위험 증거, 예상 영양·거리·시간·경쟁·실패 비용에 따라 살아 있는 먹이, 사체, 식생과 대체 먹이를 비교하는가. 여우의 먹이 전환, 물소의 방목 위치·시간·새끼 보호 전환처럼 종마다 다른 반응을 검증한다. 동물이 접근할 수 없는 서버 전역 정보를 행동 입력에 쓰는 경로를 찾는다. |
| 포식·도주·방어 | 감지→접근→추격→공격 준비→접촉→포획→섭식을 이어서 추적한다. 잠행, 가로채기, 협동 포획, 상처 난 먹잇감 재추적, 추격 포기, 대형 먹잇감 반격, 보호자 개입과 무리 경보를 종별로 본다. 선택됐으나 지형·스태미나·사거리·차폐·충돌·애니메이션 상태 때문에 실행이 막힌 경우를 확인한다. |
| 죽음과 사체 | 사망 확정, 사망 모션과 지면 안착, 먹기 가능 시점, 경쟁 개시, 소진·분해·만료, 표현 제거를 대조한다. 사체에 왜 접근하지 못했는지, 먹다가 왜 떠났는지, 포획자·청소동물이 받은 양과 남은 양을 확인한다. 사면에서의 옆으로 눕기, 공중 사망 후 착지와 권위 사체 위치도 본다. |
| 이동·이주·정착 | 일상 탐색·도주·무리 이동·계절 이주·어린 개체 분산을 구분한다. 종별 경사·수심·단차·회전·비행 고도와 착지 제한, 장애물 회피, 우회·포기·재시도를 검증한다. 출발부터 도착까지 ID, 권위 위치, 자원 소비와 인구 장부가 이어지는지 확인한다. 재정착 후 생존·번식과 자연 출생·초기 배치·운영 보충의 출처를 각각 기록한다. |
| 표현·조작 감각 | 종별 Blend Space·AnimBP·IK, 가감속·회전·고개 선행, 경사 발 접촉·발 미끄러짐, 행동 전환과 죽음·사체 안착을 본다. 발소리의 발 접촉 시점, 표면·날씨·체급별 재생과 범위, 플레이어 소음에 대한 권위 감지가 서로 일치하는지 검증한다. 공격·섭식 타이밍과 네트워크 수신 표현을 함께 확인한다. |

### 개체군, 팀 계약, 장시간 운영

| 범위 | 확인할 사항 |
| --- | --- |
| 번식·성장·세대 | 번식 가능한 성체·성비·친족·짝 접근·영역·에너지·위협·임신·출생 지면·양육·새끼 생존·성체 도달을 본다. 번식 보류·취소 사유와 회복 시간, 창시 개체 의존, 일부 가계 편중, 세대 상한을 점검한다. 개체의 경험에 의한 적응, 후손에게 전달되는 형질, 생존·번식 차이로 바뀌는 집단 구성을 각각 기록한다. |
| 무리와 종 간 파급 | 무리의 경보·차폐·새끼 보호·협동 이점과 먹이 경쟁 비용을 함께 평가한다. 포식·방목·사체 이용 변화가 다른 포식자·청소동물·초식동물·식생으로 전달되는 경로를 확인한다. 개체군 상한, 자원 예약, 동시 섭식 자리, ID와 배열 순서·동률 처리·갱신 순서가 특정 종에 반복적으로 유리한지 본다. |
| 플레이어와 운영 개입 | 반복 사냥, 접근, 발소리, 통로 차단, 채집, 장기 부재와 재방문이 남기는 지역 상태와 기억을 확인한다. 자연사·피식·플레이어 사냥·운영 보충을 출처별로 기록한다. 플레이어 유무와 밀도가 바뀌어도 권위 장부·개체 수·자원 회복을 일관되게 추적하는가. |
| 학습·권위·팀 경계 | 학습 요청, Social 보정, 세계 규칙과 실행 결과를 분리한다. 관측·모델·정규화·행동 및 backend 차이를 확인하고, 서버/Standalone의 이동·대사·피해·자원·개체군 권위와 Client 표현의 소유자를 찾는다. 중복 writer, 증거 없이 실행하는 경로, 개발 fixture와 실제 팀 레벨의 설정 차이를 확인한다. |
| 시간·저장·스트리밍 | 시뮬레이션 시계·월드 시계·클라이언트 시계와 배속·프레임 간격·서버 부하의 관계를 본다. 저장 복원·월드 파티션 언로드·재로드·접속과 재접속에서 자원 재생·흔적 감쇠·출산 예약·이주·사체 만료·영속 ID·난수 상태가 이어지는가. 중복 거래·누락·과거 시각 적용·고아 예약을 찾는다. |
| 규모와 관측 가능성 | 낮은 부하와 높은 부하, 여러 지역, 개체 수 증가, 표현 거리와 LOD 변화에서 종별 감지·추격·섭식 기회가 달라지는지 본다. 후보 검색·충돌 검사·로그·메모리·시간 따라잡기 비용, 누락된 표본과 권위 데이터 차이, 단위 오류와 표본 간격에 따른 해석 편향을 점검한다. |

## 독립 감사에 필요한 비교

1. **교란 전·중·후를 이어서 본다.** 가뭄→강우, 통로 차단→재개방, 먹잇감 감소·반복 사냥→압력 해제를 각각 시험한다. 복합 교란은 단일 조건을 확인한 뒤 실행한다. 식생·감각·행동·번식·인구가 반응하는 순서와 지연을 기록한다.
2. **요인을 분리한다.** 같은 맵·시드·모델에서 조건을 하나씩 바꾼다. 먹이 총량 고정 배치 비교, 배치 고정 총량 비교, 총량 고정 면적 비교, 밀도 고정 면적 비교를 분리한다. 다른 시드와 다른 맵에서도 원인이 유지되는지 확인한다.
3. **개체군의 궤적을 본다.** 종료 수와 함께 평균·변동폭·처음 0이 된 시각·지역 간 분포·회복 시간을 기록한다. 출생과 성체 도달, 사망 원인, 실제 섭취 간격·에너지 0 체류, 이동 시도·포기·도착·정착 번식을 집계한다. 한 종 개선이 다른 종에 옮긴 비용을 기록한다.
4. **실행 조건을 대조한다.** 실제 게임 시간 기준의 실시간·배속·프레임 간격, 저부하·고부하, Standalone·전용 서버·Client, 저장과 복원, 관측 거리와 스트리밍을 구분한다. 첫 차이가 나는 시점을 찾아 로그와 실제 실행 경로로 설명한다.

```text
AdaptiveEcosystem의 전체 생태계 구조를 독립적으로 감사해줘. 첫 결과물은 수정 전 한국어 감사 보고서야. 저장소의 AGENTS.md, Docs/PROJECT_CONTEXT.md, Docs/Team/FAUNA_TEAM_HANDOFF.md, Docs/Architecture/FAUNA_PERSISTENCE_CAUSE_REPORT.md, Docs/Architecture/FAUNA_POPULATION_BALANCE.md, 이 문서의 전체 고려사항을 읽어. 현재 브랜치·커밋·작업 트리와 실제 Source, 활성 맵/EntityConfig, 설정, 권위 실행 로그를 대조하고 기존 결론과 이 문서의 전제도 재검증해.

목표는 환경 변화 → 개체가 얻은 증거 → 행동 의도 → 실행과 실패 → 자원·개체군 변화 → 다음 환경과 행동의 고리를 확인하는 거야. 자연스러운 지역 감소·소멸·회복도 결과에 포함해. 모든 종을 살려 두는 값으로 맞추거나, 자원을 특정 종 주변에 공급하는 편법은 구조 문제로 지적해. 먹이·면적·표범은 출발점이야. 전체 고려사항을 감사하고 목록 밖에서도 생태적·구조적 결함을 찾아. 각 종과 개체의 차이, Native와 규칙 기반 backend 차이, 지상과 비행, 지역과 월드 규모, 플레이어 유무를 함께 봐.

기능의 존재만 확인하지 말고 실제 입력·상태·책임자·소비자·실행 결과를 따라가. 값이 작성되어도 활성 맵에서 소비되지 않는 경우, 한 하위 시스템에서는 정상인데 다른 하위 시스템과 결합하면 깨지는 경우, 임의 종 이름·상수·고정 순서에 묶인 분기, 관측할 수 없는 정보의 유출, 중복 writer와 장부 불일치, 취소·죽음·이주·로드 후 정리 실패, 시간차와 누적 효과가 빠진 구조를 찾아. 기존 기능을 복합 교란 아래 검증하고 신규 기능 후보는 관찰하려는 현상과 적용 비용을 명시해.

첫 우선순위는 (1) 흔적과 자원을 감지한 뒤 어디서 실행이 끊기는지, (2) 악화된 지역에서 같은 ID의 개체가 실제로 빠져나가 정착할 수 있는지, (3) 공유 자원과 출생 슬롯에서 처리 순서와 상한이 종별 결과를 왜곡하는지야. 기존 표범 기아, 사슴 식사·출생 예약, 식생 교란 뒤 늑대 소멸과 인구 112에서의 출생 보류를 다시 대조해. 같은 증상이 다른 원인에서 나올 가능성도 검증해.

재현은 안전한 소유 맵과 기존 검증 도구에서 진행해. 첫 산출물 범위는 조사·읽기와 승인된 검증 실행이야. 코드·원본 맵·에셋·학습 모델을 변경해야 하는 실험은 보고서에 필요한 최소 변경과 이유를 기록해. 실험마다 SHA, 맵, 권위 모드, 활성 플래그, 모델, 시드, FPS, 배속, 기간, 초기 개체·자원, 교란 시점, 로그 경로를 남겨. 권위에서 실행됐는지와 종료 조건을 확인하고, 실험 실패와 해석 불가능한 자료도 기록해.

보고서에는 다음을 포함해.
1. 환경·개체·종 간 상호작용·팀 경계의 전체 흐름과 실제 활성 경로.
2. 고려사항별 확인 상태, 증거, 미확인 이유. 목록에 없던 발견도 별도로 기록.
3. 발견마다 코드/맵 위치, 재현 조건, 개체·종·지역·시각, 관찰된 사건, 예상 계약, 원인 후보, 대안 설명, 다른 종에 미친 효과, 확신도.
4. 실제 생태를 단순화한 모델의 한계, 구현 결함, 레벨/데이터 설정, 실행 조건, 계측 누락의 구분. 확인된 원인과 가설을 명시.
5. 영향도와 근거에 따른 우선순위, 최소 검증 실험, 성공 지표, 예상 부작용, 담당 계층과 인계 작업.

종료 개체 수만으로 결론 내리지 말고 환경 변화부터 실제 결과까지 같은 개체와 시각으로 연결해. 자연스러운 소멸과 실행 결함이 의심될 때는 먹이 공급량, 도달·섭취 가능성, 포획 실패, 번식 가능성, 이동·재정착 경로를 각각 확인해. 외부 생태 자료가 필요하면 원자료나 1차 연구를 사용하고, 연구 결과와 게임 설계에 적용한 가정을 구분해.
```
