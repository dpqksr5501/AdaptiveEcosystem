# 11월 2일 JWJ 통합 점검 결과

| 문제 | 확인 결과 |
|---|---|
| 1102 맵에서 캐릭터가 지형 아래로 떨어짐 | 저장본에 PlayerStart가 없었다. 지형 충돌 컴포넌트 256개는 모두 Pawn을 차단하도록 설정돼 있었다. 실제 스폰 위치와 PIE에서 지형이 로드되는 시점은 확인이 남았다. |
| 에디터에서 보이는 지형의 눈이 PIE에서 사라짐 | 1102 맵과 SHC 원본은 같은 Landscape 재질을 참조했다. Nanite를 꺼도 증상이 재현됐다. 저장된 재질에서 높이 기반 눈 마스크를 확인했으며, PIE에서 눈이 사라지는 원인은 확정하지 못했다. |
| 접속 시점이 다른 클라이언트의 낮밤 동기화 | 공통 시계 단독 테스트가 통과했다. 공통 테스트 맵과 기존 `Integration_JwJ`에서 각각 Dedicated Server와 클라이언트 2개로 같은 낮밤 경계를 확인했다. 로컬 테스트에서 클라이언트 간 전환 시각 차이는 각각 최대 43ms와 26ms였다. |
| 전체 통합 검증 | 에디터 빌드는 성공했다. 전체 자동화는 은신처 시각화 테스트에서 엔진이 종료되어 미완료다. 새 `1102_Integration_JWJ` 맵은 저장본 설정을 조사했으며, PIE와 멀티플레이 실행 검증이 남았다. |
