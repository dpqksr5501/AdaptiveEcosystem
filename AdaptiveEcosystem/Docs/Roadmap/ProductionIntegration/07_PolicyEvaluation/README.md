# 07. PPO·StateTree 비교와 파리티

상태: 비교 기반·평가 계획. [전체 구조·기준](../README.md)을 따른다.

## 필요한 기능

같은 환경에서 판단 방식만 바꾸어 생존·행동·비용을 비교한다. V1의 연속 가중치 4개와 v3의 행동 5개는 다른 계약이며 입력도 7개 대 기본 18개/추가 21개다.

## 구현 방향

```text
같은 환경·초기 상태·관측 → 비교할 판단 방식
  → 같은 행동 실행기·이동·생존·자원 → 결과·비용 기록
```

1. 기존 V1 Utility/PPO 및 V1 StateTree 비교를 먼저 분리한다. v3와 비교할 때는 v3 관측·마스크·실행기를 공통으로 쓰는 비교 경로를 별도 설계한다.
2. 맵·장애물·seed/ID·Food·개체 수·포식자·시간·Social 설정·LOD·실행 길이를 고정한다. v3 기본 SocialControl=0과 켠 실험을 구분한다.
3. 관측 순서·정규화·단위·선택/실행 결과를 Python/C++ Golden Vector로 대조한다. 추론 일치와 전체 생태 결과 일치를 별도로 검증한다.
4. 반복 실행의 생존·섭식·피식/기아·이주·예약/이동 실패·CPU를 기록한다. 가중치 교체는 같은 모델·계약 식별자를 기록하고 RL 담당의 평가를 거친다.

## 기술과 완료 기준

PPO 추론·행동 마스크, StateTree·Utility, 결정성·수치 허용 오차, 통제 실험·반복 평가를 익힌다. 전체 SpeciesAI와 v3의 단순 비교는 정책만의 우열로 해석하지 않는다.

완료: 조건·모델·Source SHA·결과 분포가 재현 가능하고 관측/실행기 차이가 공개된다. 새 모델이나 수치를 이 문서 작성만으로 변경하지 않는다.
