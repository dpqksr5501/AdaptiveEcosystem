# JYU 섬의 16종 동적 생태계 구현 목표

## 최종 목표

최신 JYU 섬을 기반으로 **환경과 동물이 서로의 다음 상태를 바꾸는 서버 권위 생태계**를 구현한다. 지형·식생·먹이·물길·기후·시간대·플레이어 활동에 따라 각 동물이 실제로 감지하고 이용할 수 있는 기회가 달라진다. 개체의 섭식·경쟁·포식·이주·번식·사망은 다시 먹이 재고·서식지 이용·다음 세대에 영향을 준다. **나중에 16종의 학습 두뇌를 장착했을 때**, 이 환경의 변화가 종별 감각과 선택에 전달되고 선택 결과가 실제 행동과 생태 상태에 반영되도록 환경과 실행 계약을 준비한다.

예를 들어 물이 빠지면 수생 먹이터와 피난처 사이의 통로가 닫힐 수 있다. 잉어와 치어는 다른 깊이의 수역을 이용하고, 밍크는 상륙 경로 또는 먹이터를 바꿀 수 있다. 늑대가 남긴 사체는 여우·까마귀·멧돼지에게 먹이를 제공하고, 늑대나 표범이 남아 있으면 접근 위험도 달라진다. 이 두 사례에서 실제 섭취, 피난, 경쟁과 자원 재고의 변화까지 관측한다.

## 구현 원칙

- **환경·감각·두뇌·실행의 책임을 연결한다.** 월드는 상태와 통과 조건을 제공한다. 정책은 직접 감지, 유효한 기억·공유 신호를 받아 행동을 요청한다. 실제 이동·피해·먹이 거래·출생·사망은 기존 권위 실행기가 확정한다. 종별로 단일 이동·대사 writer와 기존 자원·개체군 장부를 유지한다. 렌더링에는 권위 상태의 표현을 사용한다.
- **기존 학습 행동을 기준선으로 보존한다.** 늑대–표범의 드문 접근·공격·이탈과 사체 경쟁을 조건별로 비교한다. 체급·피로·부상·성숙도·새끼 보호·지형은 주로 실행 가능성, 비용, 성공률에 반영한다. 상호작용의 물리적 한계와 개체의 선택을 구분하고, 공격 빈도나 종별 논문 평균을 보상 목표로 사용하지 않는다. 접근과 공격을 관찰해도 동기는 추가 비교 없이 확정하지 않는다.
- **장기 생존은 현재 실행기별로 해석한다.** 팀이 학습 두뇌를 사용한 6종에서 관찰한 장시간 생존과 생태계 유지를 장기 비교 기준으로 삼는다. 각 실행에서 실제 장착한 두뇌와 버전을 기록한다. 학습 두뇌를 아직 장착하지 않은 종은 감지·접근·섭취·회피·통로 이용 및 장부 반영으로 환경을 검증한다. 그 종의 기아·사망·개체군 변화는 원인 진단에 사용하며, 현재 규칙 실행기의 생존율을 목표로 먹이 총량·재생·통로를 조정하지 않는다. 향후 해당 종의 학습 두뇌가 들어오면 같은 맵·시드·먹이 예산에서 장기 생존과 상호작용을 비교한다.
- **자원 부족과 회복을 생태계 결과로 검증한다.** 같은 먹이터를 이용하는 개체는 유한한 재고를 공유한다. 고갈 시 실제 지급이 줄고 개체는 조건에 따라 다른 먹이터를 찾거나, 이동하거나, 에너지와 개체군이 감소할 수 있다. 소비 압력이 줄고 기후·토양 조건이 허용할 때 재생으로 회복하는지도 본다. 생존율을 맞추려고 영양·용량·재생을 보정하지 않는다. 배치 비교는 같은 공급 예산에서 시작한다.
- **공간·먹이·식생은 여러 실행기에서 쓸 수 있도록 검증한다.** 현재 R9 학습 범위는 6종이며 로컬 섬의 실제 실행기는 종마다 확인한다. 나머지 종의 현재 생존율을 맞추기 위해 맵을 조정하면 향후 학습 두뇌가 다른 방식으로 자원을 이용할 때 왜곡될 수 있다. 먼저 같은 먹이·재생 예산에서 종·성장 단계별 연결 면적, 먹이·피난처의 실제 도달, 고갈과 회복을 비교한다. 통로와 배치를 바꿔도 필요한 공간이 부족하면 소유 맵 확장이나 성장 조건을 별도 변수로 시험한다. 기존·학습 정책과 여러 시드에서 재사용할 지형·날씨 대조를 보존한다.
- **팀 과섭식 피드백을 섭식 빈도·양·표현으로 나눠 검증한다.** 종과 성장 단계별로 섭식 행동 시간, 식사 사이 간격, 재고 차감, 실제 에너지, 저에너지 체류를 함께 측정한다. 사체를 두고 쫓아내는 행동과 사냥·섭취는 따로 기록한다. 먹이 예산과 기존 두뇌를 고정한 초기 대조에서 접근성과 영양 거래를 검증하고, 종별 식사 규칙은 근거가 있는 조건부터 검토한다. [섭식 근거와 대조 결과](FAUNA_HABITAT_CAPACITY_20261113.md#팀-피드백의-과섭식-점검)
- **현장 자료로 가설을 고르고 대조로 도입을 결정한다.** 종 동정이 불확실한 외형은 참고 생태 유형을 기록한다. 새로운 구조는 기존 코드·실행 근거와 연구를 대조하고, 최소 재현 장면에서 바꾸는 조건 하나와 기대하는 효과를 명시한다. 종간·지역간 평균을 그대로 이식하는 대신 근거의 적용 범위, 설계값, 검증 결과를 기록한다.
- **로컬에서 세계를 검증하고 Dots에 Python 실행을 인계한다.** 현재 6종 R9 M1과 기존 R7e는 기준선이다. RL 담당과 관측·행동·보상·몸 해시 및 이전 모델의 호환 범위를 합의하고 Python 세계를 검증한다. Dots는 검증 커밋의 학습과 팩 반환을 맡는다. 로컬에 새 기능이 들어간 시점과 학습에 반영된 시점을 각각 기록한다.

## 로컬 작업과 검증 순서

작업 범위와 위의 완료 조건을 유지한다. 같은 기능을 검증하는 과정에서 에디터 기동, 전체 맵 캡처, 수동 로그 요약을 반복하는 시간을 줄인다.

| 실행 순서 | 작업 단위 | 다음 단계로 넘기는 근거 |
| --- | --- | --- |
| 1. 기존 증거 재사용 | 현재 맵·빌드·시드·초기 개체·두뇌·먹이 예산이 맞는 JSON과 권위 로그를 먼저 찾는다. 비교할 장면의 해당 열이 있으면 기존 실행을 분석한다. | 조건과 관측 항목이 맞으면 같은 기준 실행을 공유한다. 맵·런타임 변경으로 기준이 달라진 항목은 새로 측정한다. |
| 2. 짧은 원인 대조 | 한 번에 조건 하나를 바꾸고, 확인할 권위 사건과 제한 시각을 먼저 정한다. 발견용 한 시드는 화면 없이 사건 또는 제한 시각에서 끝낸다. 빌드는 독립적인 소스 변경을 검토한 뒤 묶어 한 번 실행한다. | 사건 시각·조건·실패 지점을 JSON으로 기록한다. 빠른 실행이 전체 검증과 같은 판단을 내리는지 첫 사례에서 확인한다. |
| 3. 변경 후보 채택 | 빠른 대조가 통과하면 두 시드의 전체 PIE에서 실제 이동·거래·자원 수지를 읽고 관련 장면을 캡처한다. 섭취·상륙처럼 같은 실행에서 확인할 수 있는 결과는 함께 추출한다. | 두 시드의 결과와 시각 증거가 일치하는 변경을 소유 맵에 반영한다. 고수위·저수위, 장애물·무장애 등 독립적으로 비교해야 할 조건은 계속 분리한다. |
| 4. 통합 검증 | 서로 영향을 주는 변경을 소유 맵에 모아 같은 장시간 실행에서 30·60게임분, 종별 이동·지급·사망·재생을 함께 수집한다. 플레이어 개입과 저장·복원·서버 및 클라이언트는 각 실행이 증명하는 범위를 기록한다. | 최초 설정과 장부, 종·성장 단계별 근거, 재현 절차와 후속 두뇌 비교 기준을 남긴다. |

각 변경은 **실패를 보여 준 첫 증거 → 변경한 조건 → 채택 근거**를 하나의 항목으로 기록한다. 같은 가설에서 결과가 반복되면 새로운 측정으로 어떤 결정이 바뀌는지 먼저 정한다. 섬 면적과 같은 근본 제약은 관측값과 후속 작업으로 남겨 다른 통로·먹이·개체 상호작용 검증을 계속 진행한다. Dots 학습 시간은 로컬 일정과 별도로 관리한다.

첫 적용은 밍크 고수위 경사로다. [섬 실행 스크립트](../../Tools/Editor/run_jyu_island_audit.ps1)는 시드를 순차 실행하고 실행 시간, 보고서, 로그를 반환한다. `FocusedMinkRamp`는 화면 없이 실제 육상 도달 또는 시험 수위 복원에서 끝나고, `Full`은 기존 렌더링 검증을 사용한다. 시드 20000의 같은 경사로에서 전체 실행과 빠른 실행은 모두 상륙 후 마른 Landscape 도달을 관측하지 못했다. 엔진 로그 구간은 85.8초에서 28.4초로 줄었고 새 실행기의 전체 벽시계 시간은 32초였다. 표본은 각각 43개와 19개로, 빠른 결과의 판정 범위는 고수위 중 육상 도달이다. 이 실측 절감률을 전체 개발 일정에 곱하지 않는다.

다음 작업 묶음은 최신 섬의 지상·수륙·수중·비행, 먹이·날씨·개체군 검증을 한 표에 모은다. 전체에 영향을 주는 막힘과 거래 불일치를 먼저 수정하고, 선택 가능한 개선은 같은 두 시드의 근거로 묶어 검토한다. 밍크 경사로는 별도 항목으로 추적하며 다른 검증을 진행한다. 장시간 무개입 실행은 같은 시드별 60게임분 실행에서 30·60분을 함께 읽고, 개입 효과·저장 왕복·클라이언트는 필요한 별도 조건에서 비교한다.

### 로컬 작업 시간과 재개 기준

변경마다 기준선, 실제 수정 시간과 검증 시간, 확인한 결과와 남은 검증을 기록한다. 다음 묶음을 시작하기 전에 해당 재개의 시간 상한과 Codex 잔여 사용량을 확인한다. 잔여 사용량이 3%에 이르거나 시간 상한에 가까워지면 새 변경과 검증을 시작하지 않고, 진행 중인 에디터나 빌드가 정상 종료된 뒤 마지막으로 검증한 상태와 다음 명령을 남긴다. 상한 시점에 남은 항목은 기존 완료 조건과 함께 이월한다.

첫 재개 작업에서 고원 쪽 진입점을 저장하고 두 시드에서 검증했다. 다음 실행은 최신 저장 맵에서 기존 두 시드의 `Grassland` `NoOutgoingSeam` 결과를 기준으로 초지–하류 지면과 지역 소속을 대조한다. 재현 입력은 `-EcoIslandSurveySeams`이며, 통로 후보를 정할 때 양방향 체급 검사와 92m 구간의 권위 지역 소속을 함께 읽는다. 고원 변경에 약 12분, 그중 최종 임시 시험과 저장·재실행에 약 6분이 들었다. 이 수치는 기존 통로의 접근점 변경에 해당한다. 초지 신규 통로, 수위에 따라 바뀌는 통과, 장기 검증 및 저장·복원에는 각각 별도 시간이 든다. [고원 검증 수치와 다음 작업](FAUNA_HABITAT_CAPACITY_20261113.md#고원-쪽-진입점-보강)

재개 후 약 1시간 32분 시점의 로컬 잔여 추정은 8–14시간이다. 통로·먹이 접근 1–3시간, 식생·수문·섭식과 종간 상호작용 4–6시간, 장기·저장·멀티플레이 검증과 학습 인계 정리 3–5시간을 배정했다. 장기 기준선 두 시드에 8분 2초, Drift 저장·복원 두 쌍의 에디터 실행에 약 2분 14초가 걸렸다. 나머지 시간은 배치와 실행 규칙의 원인 분리, 회귀 수정과 재검증에 든다. 기존 구현과 실행 근거를 재사용하는 조건의 추정이다. Dots 학습과 모델 수령 뒤 검증은 별도이며, 잔여 사용량 3%가 먼저 오면 마지막 검증 지점을 기록하고 작업을 중단한다.

초지–하류는 구간 소속, 출구에서 먹이 감지, 경유점에 따른 이동 비용을 순서대로 분리했다. 두 시드에서 말의 하류 도착과 섭취를 재현했다. 출구 근처에 군락을 두 곳으로 늘린 대조에서도 두 시드 모두 추가 기아가 발생했다. 중간 먹이터는 출발을 유도할 수 있었지만 시드 20017에서 도착과 지급이 없었다. 검증한 경로는 비활성 상태다. 다음 재개는 도착 예상 에너지와 실제 지급을 맞춰 보고, 예상 경쟁·고갈·복귀 가능성을 각각 측정하는 데서 시작한다. [초지 통로 후속 먹이 배치](FAUNA_HABITAT_CAPACITY_20261113.md#초지-통로-후속-먹이-배치)

두 시드의 최신 섬 30·60게임분 기준선을 확보했다. 계측 실측은 8분 2초였다. 하류의 체급별 수주 연결을 비교하고 메기가 실제 섭취한 Drift 20% 분산안을 소유 섬에 저장했다. 소형어류의 대체 지점도 두 시드에서 실제 섭취를 확인했으나 기존 잉어의 섭취 감소로 보류했다. 다음 재개는 잉어 산란장 주변 공급을 유지하면서 소형어류가 퇴수 후 이용할 후보와, 수정된 소유 섬의 다음 장기·저장 비교를 검증한다. [최신 섬 장기 기준선](FAUNA_HABITAT_CAPACITY_20261113.md#최신-저장-섬의-3060게임분-기준선) · [하류 먹이터 실측](FAUNA_HABITAT_CAPACITY_20261113.md#하류-먹이터-사이의-수중-연결)

재개 후 약 1시간 40분 시점에도 로컬 잔여 추정은 8–14시간이다. Drift 저장본의 60게임분 두 시드 실행은 합계 7분 32초였다. 새 먹이터 이용과 재생을 재현했으며 기존 먹이터의 반복 고갈도 확인했다. 이 배분값의 최종 채택은 보류한다. 잔여 추정에는 접근·통로의 후속 대조, 식생·수문·섭식·상호작용 수정, 종별 장기 회귀와 서버·저장·인계 검증을 포함한다. 비교 가능한 기존 구현과 검증 근거를 활용하는 조건의 추정이다. 시드 20017의 렌더링 횃대 대조는 88초에 끝났다. 기존 횃대에서 검독수리 99번의 선택과 도착을 각각 3회 확인했고, 추가 후보 3곳은 모두 착지 표면 검사를 통과하지 못해 등록되지 않았다. 다음 실행은 `-EcoIslandTrialSecondEaglePerch`의 후보 좌표를 실제 충돌 지면으로 확인하는 데서 시작한다. 근거는 `Saved/FaunaAudit/Island_20017_eagle_second_perch/IslandFaunaPIE.json`이다. [Drift 장기 비교](FAUNA_HABITAT_CAPACITY_20261113.md#저장된-drift-먹이터의-체크포인트-왕복)

고원 착지 표면을 두 시드에서 추가 조사했다. 후보가 실제 지면을 통과해도 새 횃대 선택은 관측되지 않아 저장 맵에는 적용하지 않았다. 같은 양의 연속·간헐 강우를 권위 초지 날씨로 적용해 강우 간격이 Native 토양 수분에 미치는 영향을 재현했다. 소유 섬에서는 이제 격자가 있는 육상 군락 8곳이 뿌리 위치의 토양 수분을 읽는다. 기존 두뇌와 작성 재고·재생 설정을 고정한 8개 실행, 새 프로세스 저장·복원과 서식지 자동화 2개를 통과했다. 다음 장기 비교는 저장 섬에서 초지 고갈·회복과 말·물소의 실제 지급을 읽고, 격자가 없는 하류·이행 지역의 군락에 적용할 수분 입력과 퇴수 조건을 별도로 다룬다. [착지 표면 대조](FAUNA_HABITAT_CAPACITY_20261113.md#최신-섬의-밍크와-검독수리-기준선) · [군락 토양 수분 연결](FAUNA_HABITAT_CAPACITY_20261113.md#군락-위치의-토양-수분-연결)

저장 섬 60게임분의 토양 입력 대조를 두 시드에서 완료했다. 초지 군락의 지급은 늘었고 습윤 초지의 종료 재고는 줄었다. 현재 실행기로 두 시드의 말·물소는 30분까지 남지 않았다. 하류 현장 조사에서 SouthBrowse만 물 볼륨에 포함됐으며, 나머지 세 군락과 이행 지역은 별도의 토양 입력이 필요하다. 다음 검증은 같은 건조 조건에서 해당 수변 군락의 명시적 수원 공급과 다른 군락의 강우·배수만 따로 비교한다. Dots 인계에 기존 Python 기본 토양 검증 결과와 섬의 실제 부분 표본을 추가했다. [장기 토양 대조](FAUNA_HABITAT_CAPACITY_20261113.md#60게임분-토양-입력-대조) · [하류와 이행 지역 조사](FAUNA_HABITAT_CAPACITY_20261113.md#토양-격자-밖의-하류와-이행-지역)

격자가 없는 하류·이행 지역 군락 5곳에 강우·배수에 따른 토양 수분을 연결했다. 실제 수원 범위에 있는 SouthBrowse만 하천 수위를 읽는다. 두 시드의 수원 유무 대조와 새 프로세스의 포맷 15 저장·복원에서 수분을 확인했다. 하류 육상 군락의 실제 섭취는 이번 대조에서 발생하지 않았다. 다음에는 저수위·고수위의 지상 접근과 먹이 선택을 확인하고, 확인된 수위 효과를 밍크·어류·산란장 연결과 같은 조건에서 비교한다. [격자 밖 수분 구현과 검증](FAUNA_HABITAT_CAPACITY_20261113.md#토양-격자-밖의-하류와-이행-지역)

하류 SouthBrowse에서 같은 말과 출발점의 저수위·고수위 섭취를 두 시드로 검증했다. 고수위에 마른 강둑의 공용 재고 접근점을 연결한 뒤 두 시드와 새 프로세스에서 실제 섭취를 확인해 소유 맵에 저장했다. 두 시드에서 초지–하류 통로만 열었을 때 목적지 먹이터가 출구의 탐색 거리 밖에 있었고 자연 유입·복귀는 없었다. 통로는 저장 맵에서 비활성 상태다. 다음 이주 대조에서는 먹이 예산을 유지하면서 출구와 현지 먹이터가 이어지는 배치, 귀환과 도착 에너지에 미치는 영향을 함께 본다. [수위별 접근과 지급](FAUNA_HABITAT_CAPACITY_20261113.md#하류-southbrowse의-수위별-실제-섭취) · [자연 유입 검증](FAUNA_HABITAT_CAPACITY_20261113.md#초지-통로-후속-먹이-배치)

최신 저장 섬의 플레이어 정지·은밀 이동·달리기 대조를 두 시드에서 완료했다. 발소리, 네 종의 회피, 산토끼의 경유점 갱신과 첫 실제 섭취를 기록했다. 자연 생성 사체의 지급 장부도 같은 실행에서 대조했다. 사냥 경로는 최신 섬의 기본 `PlayerState`에서 전투 옵션만 켜면 권위 프록시가 생기지 않는 지점을 확인했다. 다음 검증에는 팀의 전투 게임모드와 플레이어 입력이 연결된 섬 세션이 필요하다. ### 이전 현장 검증 이력

1. 검증용 에디터를 정상 종료한 뒤 저장 당시 DLL로 [중간 먹이터 복원](../../Tools/Editor/run_jyu_saved_habitat_restore.ps1)을 실행한다. `-PrepareOnly`는 맵·파일 형식·DLL 해시만 확인한다. 전체 실행은 새 프로세스의 환경·재고·개체 스냅샷과 산토끼의 후속 지급을 확인한다.
2. 복원 결과를 보존한 뒤 직접 UBT로 Editor를 빌드한다. 낮밤 자동화와 저장 맵 두 시드를 실행해 권위 낮·밤·박명, 하류와 이행 지역의 실제 활동·섭식, 초기 118개체·작성 재고 215·R7e를 비교한다. 새 DLL에서도 해당 빌드의 저장→복원을 한 쌍으로 검증한다.
3. 같은 시드의 기준 실행에서 지역 강우, 군락 요청, 플레이어 통과를 각각 바꿔 실행한다. 하류 치어 수심 조사와 두 번째 밍크 입수점 조사를 먼저 읽기 전용으로 실행하고, 검독수리 추가 횃대는 PIE에서만 비교한다. 확인된 조건을 바탕으로 소유 맵의 채택 여부를 결정한다. [각 시험의 조건과 관측 항목](FAUNA_HABITAT_CAPACITY_20261113.md)

환경이나 정책 하나만 바꾸는 시험에서는 [요약기](../../Tools/Editor/summarize_fauna_runtime.py)에 시험 JSON과 로그, `--compare-baseline <같은 시드의 기준 JSON>`을 전달한다. 첫 표본의 사슴 두뇌·개체 ID/종/지역/체력/에너지/좌표, 군락별 초기 재고·용량·재생률·소비자 등 기록된 값을 대조한다. 차이가 있으면 JSON에 항목을 남기고 종료 코드 1을 반환한다. 의도적으로 군락을 이동하거나 재고를 나눈 시험은 그 차이를 먼저 검토한다. 이전 두 시드에서는 총량과 종별 개체 수가 같아도 초기 위치가 다른 개체가 64마리였으므로 환경 효과는 시드별로 짝지어 비교한다. 이 검사는 보고서 첫 표본을 사용하며 전체 환경과 정책의 동등성까지 판정하지 않는다.

시드 20017의 저장본은 기존 DLL을 사용한 새 프로세스에서 복원됐다. 환경·개체·재고 스냅샷이 일치했고 산토끼 70번이 복원 후 권위 시각 72초에 먹이 에너지 0.411을 받았다. 결과는 `Saved/FaunaAudit/IslandSavedHabitat_20017_load/IslandFaunaPIE.json`에 있다. 다음 비교는 낮밤과 먹이 요청 진단을 포함하는 새 DLL을 사용한다.

## 현재 시작점과 자료

수중 먹이의 공유 접근점은 탐색·섭식과 지역 이동 시 도착지 자원 평가에서 같은 위치 목록을 사용한다. 자원 평가는 접근 가능한 위치가 하나라도 있으면 해당 군락 재고를 한 번만 계산한다. 저장 섬에서 활성화된 통로는 Riverbank·Highland의 지상 경로이며 지역을 건너는 수중 통로의 실제 도착 검증은 남아 있다. 추가 Drift 좌표는 PIE 시험 배치다. 좌표를 선택할 때는 시드별로 시작 개체의 실제 섭취, 기존 이용자별 지급 변화, 재고 고갈과 저수위 때의 대체 경로를 대조한다. [수중 배치 대조](../RL_Policy/Examples/island_water_food_connectivity_20261114.json) · [퇴수와 저장 복원](../RL_Policy/Examples/island_shared_forage_drawdown_20261114.json)

이번에 합의한 로컬 세 묶음은 잉어 선반·밍크 독립 출구와 종별 접근성, 식생·수위·먹이 전환과 종간 행동, 16종 장기·저장·서버·Python 대응 확인과 인계다. 최신 저장 맵은 설원과 초지의 경계 조정까지 적용했다. 강변·고원 확장 후보는 공통 개선이 확인되지 않아 보류했다. 저장·복원과 서버 검증은 최신 초지 저장본에서 재확인했으며 16종 장기 비교 및 인계 근거도 갱신했다. 초지–하류의 물리적 단절과 검독수리 기본 맵의 사냥 기회는 후속 레벨 작업이다. 신규 10종의 Python 세계와 섬 전체 파리티는 후속 학습 준비 범위에 남아 있다. [최신 16종 비교](FAUNA_HABITAT_CAPACITY_20261113.md#최신-저장본의-종별-장기-비교) · [후속 레벨 작업](FAUNA_HABITAT_CAPACITY_20261113.md#섬의-물리-구조와-후속-레벨-작업) · [Dots 학습 안내](../RL_Policy/R9_CLOUD_TRAINING.md)

고원 지면 표본과 개체 ID를 고정한 포획 대조에서 실제 섭식·포획까지 확인했다. 초지에서 독립 재고 분할은 두 시드 모두 먹이 선택 하한 아래인 용량 비중을 늘렸다. 공용 재고를 두 지점에서 이용하도록 연결한 대조에서는 두 시드 모두 말이 새 지점에 도달해 먹었고, 선택 하한 아래인 용량 비중이 줄었다. 종별 저에너지 체류 개선은 반복 확인이 필요하다. 지역 간 통로와 종별 가림·퇴로의 검증이 쌓이면 유효 공간 확장 여부를 판단한다.
