# 다종 발소리와 청각 인계

`/Game/JYU/Maps/LV_JYU_Fauna`의 `FootstepAudioSet`에 `/Game/JYU/Fauna/Audio/DA_FaunaFootsteps`를 연결했다. 플레이어도 이 맵의 세트를 읽는다. 해당 세트에 종 프로필이 없는 기존 맵은 기존 발소리 경로를 사용한다.

## 접촉과 환경

- 동물의 로컬 재생은 걷기·달리기·회전용 Blend Space의 우세한 클립에서 발뼈 접촉 Notify를 읽는다. 시각 개체가 실제로 이동했을 때만 소리를 내고, 같은 순간의 여러 발은 중복 재생을 제한한다. 사슴·늑대는 기존 접촉 클립을 사용한다. 물소 보행은 생성할 때 지정한 발별 디딤 위상을 사용한다. 까마귀는 지상에서 발소리를 내며, 비행에서 착지로 끝나는 전환에서 접촉음을 한 번 낸다.
- 플레이어는 실제 지면 이동 거리와 걷기·뛰기·은밀 이동을 사용한다. 클라이언트는 수신한 다른 플레이어의 보행도 재생한다. 접촉 위치의 물리 머티리얼이 풀·흙·눈·물·진흙·돌·나무 음원을 결정한다. 연결 수면 아래의 지면은 물로, 강우량 0.65 이상인 풀·흙은 젖은 지면으로 판정한다. 클라이언트는 기존 지역 요약의 날씨를 사용한다.
- 종별 음량·피치·기본 간격·공간 감쇠 거리와 지면별 배율을 설정했다. 실제 속도·개체 크기를 함께 반영한다. 크기가 작은 개체는 같은 종에서도 음량과 범위가 줄고 발소리 간격이 달라진다. 로컬 플레이어 청취 거리 밖에서는 오디오 컴포넌트를 생성하지 않는다. 공간 감쇠와 장애물 감쇠를 쓰고 로컬 동시 발소리 예산은 16개다. [Epic 공간 감쇠](https://dev.epicgames.com/documentation/en-us/unreal-engine/sound-attenuation-in-unreal-engine) · [Epic 물리 머티리얼과 충돌](https://dev.epicgames.com/documentation/en-us/unreal-engine/physical-materials-user-guide-for-unreal-engine)

## 음원 선택

`FOOTSTEP26c687a65462V1`에서 GRASS, SOIL, SNOW, WATER, MUD, ROCKS, WOOD의 걷기·뛰기 클립을 두 가지씩 골랐다. 기존 풀·흙·눈·물·젖은 흙 음원과 길이·피크·평균 레벨을 비교했다. 원본에서 특히 나무 클립의 피크가 높아 가져올 때 레벨을 맞췄다. 플레이어는 부츠 원음을 사용한다. 동물은 이 팩의 짧은 표면 소리를 잘라 발바닥과 발굽에 맞게 각각 필터링했다. 적용한 동물 음원은 가공한 폴리다.

선택한 번호, 길이, 필터는 [에셋 작성 스크립트](../../Tools/Editor/author_jyu_fauna_footsteps.py)에 있다. 원본 Vault 파일을 읽고 필요한 PCM만 임시 추출해 소유한 SoundWave로 가져온다. 씬에는 지면 판정 재현용으로 이름이 `Fauna_Footstep_*`인 일곱 표면을 둔다. 기존 녹음과 적용 샘플을 `Saved/FaunaFootsteps/SurfaceComparison.wav`에서 풀→흙→눈→물→진흙→돌→나무 순서로 들을 수 있다. 처음 두 지면에는 기존 녹음이 앞에 나오고, 각 지면은 부츠→발바닥→발굽 순서다.

## 서버 청각

| 담당 | 실행 |
| --- | --- |
| 발소리 방출 | 서버는 실제 지면 이동으로 동물과 플레이어의 발소리 이벤트를 만든다. 클라이언트 Notify와 재생 성공 여부는 서버 청각의 입력으로 쓰지 않는다. 개체 발소리는 최근 접촉만 유지하고, 플레이어 및 경보와 별도로 512개 소스 한도를 둔다. |
| 규칙 동물 | 종별 청각 거리와 감도, 발소리 자체의 전파 거리·세기, 장애물, 기존 날씨의 청각 배율을 평가한다. 플레이어와 실제 위협 발소리는 회피 근거가 된다. 사냥 자격이 있는 먹잇감의 소리는 마지막 소리 위치를 조사하게 하고, 추격·포획 자격은 다시 평가한다. |
| Native 사슴과 늑대 | 실제 플레이어 발소리에 각자 다른 청각 프로필을 적용하고 기존 경험 기억 경로에 기록한다. Native 사슴의 늑대 감지와 늑대의 사슴 탐색에는 기존 규칙이 적용된다. PPO 관측 스키마와 가중치는 기존 계약을 사용한다. |

수치는 게임 튜닝이다. `eco.Footsteps.Log 1`은 음원·지면·재생 범위와 접촉 발을, `eco.Senses.NoiseLog 1`은 권위 소음 이벤트를, `eco.Footsteps.HearingLog 1`은 동물의 선택된 소리 증거를 기록한다. 재생 범위, 서버 방출 범위, 청취자의 실제 감지 거리를 각각 해석한다.

## 검증

- 직접 UE 5.8.4 UnrealBuildTool의 Editor 빌드와 전체 자동화 298개를 완료했다. 크기·속도·지면별 전파 차이, 청취 종별 감지 문턱, 차폐·강우 배율, 비행 중 지상 소리 차단을 검사했다. 로그는 `Saved/Logs/FaunaFootstepAutomationFinal.log`다.
- 오디오가 켜진 D3D11 PIE에서 플레이어가 일곱 표면을 밟을 때 각 물리 머티리얼과 해당 부츠 음원이 확인됐다. 풀 표면의 강우량을 0.9로 설정한 경우 젖은 지면 음원이 재생됐다. 풀밭에서 플레이어의 재생 바깥 반경은 걷기 19.36 m, 뛰기 최대 30 m, 은밀 이동 10.71 m였다. 이 단계의 표면·재생 횟수는 네이티브 로그에서 확인한다.
- 같은 풀밭 보행에서 성체 기준 쥐 3.64 m, 여우 9.66 m, 돼지 13.30 m, 까마귀 6.44 m, 표범 12.04 m, 물소 21.70 m, 사슴 16.80 m, 늑대 13.65 m였다. 여덟 리그 모두 Notify로 재생됐다. 같은 속도의 까마귀 비행은 지상 발소리 0회, 약 6.6 m에서 쥐 0회와 물소 6회를 확인했다. 여우와 쥐의 가까운 접촉은 중복 억제로 합쳐지는 경우가 있다. 증거는 `Saved/Logs/FaunaFootstepPlaybackFinal.log`, `Saved/FaunaFootsteps/PlaybackAudit.json`, 실제 믹서 녹음 `FaunaFootstepsPIE.wav`다.
- 로컬 전용 서버에서 클라이언트의 실제 걸음으로 쥐·여우·돼지·까마귀·표범·물소의 회피 증거와 사슴의 청각 기억을 확인했다. 별도 시야 밖 접근 시험에서 늑대도 청각 기억을 기록했다. 움직이지 않는 두 번째 클라이언트는 이동한 첫 플레이어의 발소리를 로컬 재생했다. 이 전용 서버 검증은 실제 걸음과 권위 청각 경로를 대상으로 했다. 지면별 질주·은밀 이동과 강우 전환은 위 PIE 결과를 따른다. 로그는 `Saved/Logs/FaunaFootstepHearServer.log`, `FaunaFootstepWolfServer.log`, `FaunaFootstepHearObserver.log`다.
