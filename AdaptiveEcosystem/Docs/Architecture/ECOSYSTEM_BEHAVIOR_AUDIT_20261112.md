# 생태계 전체 행동·구조 점검

기준은 `codex/social-shelter-handoff`의 `051ef5f7` 및 2026-11-12 로컬 작업 트리다. 다종 재현 맵은 `/Game/JYU/Maps/LV_JYU_Fauna`다. 이 맵에서 사슴·늑대는 Native v3를, 돼지·여우·까마귀·표범·물소·쥐는 규칙 기반 실행을 사용한다. 코드에서 확인한 조건, 새로 재현한 현상, 기존 검증과 남은 실험을 구분했다. 팀 통합 레벨·모든 에셋·모든 서버 설정을 새로 실행한 결과로 해석할 수 없다.

## 사슴의 포만 상태 섭취

후속 통합 레벨 복사 검증은 두 시드에서 R7e와 자연 출생을 함께 적용하고, 매 결정 스텝의 실제 사슴 섭취량을 분리해 기록했다. 포만 섭취 규칙 변경의 엔진 회귀와 R7e 단독 효과는 이 비교에 포함되지 않는다. [통합 레벨 복사 검증](FAUNA_POPULATION_BALANCE.md#integration_jwj-복사본의-r7e자연-출생과-다종-공존)

**팀원 관찰을 재현했다.** 시드 20017, R7e `v3_r7_g995_s1_20m@40d8710d`, 서식지 3단계, NullRHI Standalone, 1배속·60 FPS에서 90초 동안 고정 사슴 ID 5–16을 읽었다. 두 실행은 생활 마스크만 0과 1로 바꿨다. 각 실행에서 8,100개 표본 중 직전 Native 스텝과 연속인 8,088개를 비교했다. 직전 권위 에너지가 기준 이상인 스텝 가운데 실제 `last_intake > 0`을 집계했다. 연속 섭취 스텝은 여러 번으로 집계된다.

| 직전 에너지 | 기본 마스크 0 | 사슴 식사 주기만 활성화한 마스크 1 |
| --- | ---: | ---: |
| 90 이상 | 1,254 / 1,723 | 85 / 417 |
| 95 이상 | 1,161 / 1,398 | 59 / 189 |
| 99 이상 | 853 / 914 | 43 / 71 |

기본 실행에서 사슴 9는 약 10.73초에 직전 에너지 99.808/100, 비축 1.0, 직전 섭취 0에서 실제 섭취 0.003834로 전환했다. 해당 스텝은 `NativeAlertGraze`였다. 약 14.43초에는 직전 에너지 98.323, 비축 1.0에서 직접 위협 수 0인 상태로 실제 섭취를 시작했다. 즉 경계 채식과 평상 채식 모두에서 확인했다. 에너지 표시가 양자화되므로 이 비교는 화면 게이지가 아닌 권위 `energy`를 사용했다.

- **기본 동작.** R7e의 채식 요청·실행이 섭식 배수를 주면, Native 월드는 먼저 대사량을 차감한 뒤 부족한 만큼을 같은 셀에서 요청한다. 채식을 유지하는 한 별도의 허기 시작 문턱 없이 방금 차감된 양을 채울 수 있다. LIFE의 `Energy < .9`는 특정 정지 채식 조향 조건이다. 보행 채식의 섭식 권한과 별개다. [Native 자원 지급](../../Source/AdaptiveEcosystem/AI/Policy/EcoWorldV3.h#L4432) · [섭취 수요](../../Source/AdaptiveEcosystem/AI/Policy/EcoRepertoire.h#L818) · [정지와 보행 조향](../../Source/AdaptiveEcosystem/AI/Policy/EcoPolicyV3IntegratedProcessors.cpp#L208)
- **식사 주기의 적용 범위.** 일반 채식은 에너지 65%에서 재개한다. 비축이 낮으면 80%에서 재개하며 90%에서 식사 종료를 평가한다. 이동·경계 유지 행동은 일반 채식 게이트 밖에 있다. 마스크 1에서 직전 에너지 95 이상 섭취 59개 중 55개가 `NativeAlertGraze`였다. 이 실행에서 에너지 90 이상일 때 직전 섭취 0에서 다시 양수가 된 연속 표본은 0개였다. [실제 활성 조건과 개입](../../Source/AdaptiveEcosystem/Creature/Runtime/EcoCreatureIntegrationSpawner.h#L87) · [사슴 식사 게이트](../../Source/AdaptiveEcosystem/AI/Policy/EcoPolicyV3IntegratedProcessors.cpp#L509)
- **출생과 연결.** 기존 30분 두 시드에서는 식사 주기만 켜도 사슴 자연 출생이 25→7, 43→9건으로 감소했다. 부모의 에너지 요건 70%와 일반 식사 재개 65% 사이에서 출산 자격을 잃어도 바로 채식을 재개하지 않는 구간이 생긴다. 이번 90초 재현에서 출생에 대한 새 인과 실험은 하지 않았다. 해결을 검증할 때 평상·경계·이동 중 섭식, 비축, 출산 전후 영양, 실제 식생 소비와 다른 일곱 종을 함께 본다. [기존 규칙 단독 비교](FAUNA_POPULATION_BALANCE.md#생활-규칙-분리와-포획-검증)

재현 입력은 `-EcoV3Seed=20017 -EcoFaunaHabitatStage=3 -EcoFaunaPersistence=1 -EcoFaunaPursuitFix=0 -EcoFaunaCarrionAccess=1 -EcoAdaptiveRoutineMask=0/1 -benchmark -fps=60 -EcoIntegrationExitAfter=94`다. 로컬 읽기 전용 기록기 `Saved/FaunaAudit/audit_deer_high_energy_local.py`와 원시 `Saved/FaunaAudit/DeerHighEnergy_20017_M{0,1}.json`, `Saved/Logs/DeerHighEnergy_20017_M{0,1}.log`에 실행 증거가 있다. 두 엔진 프로세스가 정상 종료했다.

## 여덟 종 점검

| 종 | 확인된 행동과 어색해질 수 있는 제약 |
| --- | --- |
| 사슴 | 먹기 요청, 채식 실행, 실제 식생 지급이 별개다. 포만 근처의 미세 섭식과 식사 주기·번식 자격의 충돌을 위에서 확인했다. 비축으로 생존하는 동안의 표시 에너지는 생존 보호용 최소값을 포함하므로 기아 판정에는 Native 에너지와 비축을 각각 사용해야 한다. |
| 늑대 | Native 사슴 추적·협동 포획, 공유 사체 섭식이 연결돼 있다. 규칙 종의 살아 있는 개체를 같은 후보 선택·협동 포획 경로로 다루지 않는다. 사슴 총수가 유지돼도 실제 포획과 영양 공급이 줄어드는 사례가 기존 교란 실행에서 확인됐다. |
| 돼지 | 땅 파기, 식생과 사체 소비, 새끼에 대한 다른 부모의 가로채기가 있다. 뿌리 먹이의 별도 공급과 땅 파기 행동은 따로 봐야 한다. 가족 반격은 기존 강제 장면에서 확인했고 자연 실행의 발생 빈도는 미확인이다. |
| 여우 | 쥐와 착지한 까마귀를 사냥하며 패치·사체도 비교한다. 살아 있는 후보는 현재 맵의 두 종으로 제한된다. 먹잇감의 발소리는 조사 위치를 제공하지만 먹잇감 적격 판단도 함께 거친다. 공격 가능 여부, 소리를 들은 사실, 위험을 감수할지의 차이를 현재 기록으로 모두 읽기 어렵다. |
| 까마귀 | 날기·착지·지상 섭식은 있다. 비행은 목표 착지점과 고정 순항·상한을 사용한다. 이 맵의 작성 값은 지상 12m 순항·30m 상한이다. 단계별 비행과 지형 제약은 코드에 있다. 공중에서 수색한 뒤 가치 있는 자원에 맞춰 착지점을 고르는 경로와 횃대·둥지·알 단계는 점검한 실행에서 확인되지 않았다. |
| 표범 | 멧돼지·쥐·조건을 통과한 어린 물소가 살아 있는 후보이며 Native 사슴은 공유 사체 경로다. 사냥 실패와 포만·경로 실패·만료에 따른 실제 영양 손실을 확인했다. 시작 체력만 조정해도 접촉·경쟁·사체 공급 문제는 남는다. |
| 물소 | 얕은 물 통과와 보호자 가로채기, 정면 반격이 있다. 보호자 이동은 새끼를 노리는 공격자 기준으로 선택한다. 성체 무리의 수원 이동·원형 방어를 같은 보호자 기능의 일부로 볼 수 없다. 경사에서의 접촉은 합성 검사와 실제 팀 레벨 보행을 구분한다. |
| 쥐 | 체형에 맞춘 좁은 은신처·턱·수심, 낮밤 활동, 번식과 사망 자세가 있다. 예약당 한 마리로 태어나며 은신처·자원 지점은 작성된 패치에 의존한다. 짧은 거리에서의 바닥 틈·작은 장애물·성장에 따른 이동 통과율과, 쥐 은신처 안에서 공격과 소리가 어떻게 이어지는지는 추가 비교가 필요하다. |

## 수정 우선순위

1. **사슴의 섭식 승인 경계를 정리한다.** 학습 행동 번호나 가중치를 바꾸기 전에 채식 의도, 경계 중 소량 섭식, 실제 지급을 하나의 관측 가능한 계약으로 연결한다. 포만에 가까운 사슴의 불필요한 섭취를 줄이면서 비축·식생 경쟁·출산이 의도대로 움직이는지 같은 시드로 확인한다.
2. **접근과 목표의 연결을 보완한다.** 사냥 접촉 실패와 지면 이동 실패를 분리하고, 쥐·물소·표범처럼 체형이 크게 다른 경우 실제 우회·포기 이유를 비교한다. 접근성 개선이 쥐 피식과 물소·돼지의 생존에 미치는 영향도 확인한다.
3. **환경 변화가 지역과 생애에 전해지는 경계를 연결한다.** 규칙 종의 지역 이동을 추가할 때 서버 이동 권한, 개체 ID, 부모와 새끼, 자원·출생·사망 장부, 복원을 함께 다룬다. 출생 한도와 번식 상태의 실패 이유를 계측해 환경 반응과 운영 제한을 구분한다.
4. **행동을 플레이에서 읽을 수 있게 검증한다.** 휴식·경계·추격·반격·부상·안착이 실제 의도와 맞게 보이고 들리는지 팀 레벨과 서버 Client에서 확인한다. 규모 검증은 개체·플레이어 밀도와 후보 스캔 비용을 같은 실험에 넣는다.

이번 변경은 감사 기록과 로컬 읽기 전용 재현이다. 새 빌드, 시각·오디오 재검사, 패키지, 학습·복제 계약 변경은 이번 감사의 검증 범위 밖이다.

## 행동 전환 후속 점검

| 행동 | 시작·유지·포기에서 비교할 조건 |
| --- | --- |
| 먹이 탐색·추격·섭취 | 단서의 신선도와 종류, 살아 있는 먹이·사체·패치의 접근 비용, 실제 섭취까지 걸린 시간과 대사, 경로 실패 후 다른 후보로 전환하는 시점을 비교한다. 이번 소스에서는 목격·청각·냄새 목표의 종료를 분리하고, 자원 접근 시 짧은 측면 대안을 추가했다. 살아 있는 후보와 사체의 전체 기대값, 냄새 기억의 최근 추적 ID 제한은 별도다. |
| 도주·은신·휴식·순찰 | 실제 위협과 잠시 감지한 단서, 입구 체급, 다시 드러나는 위험, 체력·피로 회복 및 추격 재개를 비교한다. 종별 위협 시야 입력은 실행에 연결했다. 일반 순찰의 주기 질주와 휴식 리듬은 같은 시드의 비교 대상이다. |
| 무리·양육·번식·성장 | 무리 이탈 및 복귀 조건, 부모와 새끼의 물리 접촉, 위험·영양·공간·수용량으로 인한 출생 보류를 함께 기록한다. 고립된 한 개체를 계속 포함할지와 무리의 나머지 개체가 떠날 수 있는지는 별개다. |
| 비행·착지·사망 | 높은 지형, 아래의 착지 가능 여부, 목적지까지의 에너지와 위험, 안전한 대체 착지 여부를 비교한다. 현재 비행의 지면·수심·천장 검사와, 착지가 계속 막힌 경우의 복구를 따로 검증한다. |
| 장기 환경 반응 | 낯선 지역, 계절, 자원 재생, 반복 사냥, 규칙 종의 지역 이동을 분리한다. 종의 감소나 이탈을 기록하고 선택지의 부재, 처리 실패, 실제 환경 변화의 결과를 구분한다. |

소스 변경과 새 빌드 없이 확인한 범위는 [프로젝트 전체 후속 점검](PROJECT_RUNTIME_AUDIT_20261112.md#환경과-입력-변화에-대한-후속-점검)에 있다.

후속 구현에서 사슴 포만 판정은 경계·이동 중 섭식에도 적용된다. 인접 통로는 초식·잡식·포식·청소 전략에 맞춰 지역 자원 보고를 읽고, 비행 경로는 직접 하강이 막히면 충돌 없는 대체 착지를 검사한다. 실제 장기 궤적, 다지역 맵, 공중 지역 이전은 별도로 확인해야 한다. [동일 입력 비교와 통로 설정](PROJECT_RUNTIME_AUDIT_20261112.md#후속-구현과-동일-입력-비교)
