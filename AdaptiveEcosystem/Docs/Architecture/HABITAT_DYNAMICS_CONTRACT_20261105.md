# JYU 서식지 회복과 계절

`-EcoHabitatDynamics`를 붙여 자연 서식지 프로필이 있는 통합 v3 월드를 시작한다. 기준 검증 맵은 `/Game/JYU/Maps/LV_JYU_Ecosystem`이다. 인자 없이 시작하면 기존 설정을 사용한다.

| 상태 | 입력과 소비 |
| --- | --- |
| 방목 압력 | Native 섭식에서 경쟁을 해결한 뒤 셀의 실제 차감량을 용량으로 나누어 누적한다. 기존 군락 발달과 재생 속도가 낮아지며, 다음 섭식이 없어도 서서히 회복한다. 관목 회복은 초지보다 느리다. |
| 고인 물 | 권위 강수와 지형·서식지의 배수 값으로 일시적인 얕은 물을 적분한다. 비가 그친 뒤에도 남아 토양 수분과 과습 스트레스에 영향을 준다. 기존 먹이 행동은 물이 많이 고인 후보지의 점수를 낮춘다. 평평하고 수면과 중첩하지 않는 지면에서 Client 표현에 웅덩이를 사용한다. |
| 먹이 질 | 남은 생물량의 새순 비율은 시간과 스트레스에 따라 감소하고 재생한 양만큼 보충된다. Native가 실제 섭식량을 동일하게 차감하고 에너지·비축 전환율만 바꾼다. 먼 곳의 영양 상태를 행동기가 자동으로 알 수 있게 하지 않는다. |
| 계절 | Native 시뮬레이션 960초 주기의 온도 편차 ±6℃를 식생 생육에 적용한다. 지역별 기본 기온과 실제 강수는 기존 권위 입력에서 온다. 기존 guild의 온도 허용 범위와 차폐가 달라 생육 시점이 달라진다. |
| 사냥터 기억 | 실제 플레이어 공격에서 공격자를 확인한 피해 개체와 직접 목격 개체만 위치를 기억한다. 인접한 반복 공격으로 강해지고 시간·거리로 감쇠한다. 기존 안전한 Graze 안의 후보 선택만 보정하고, 긴급 허기·도주·이주·Social 예약을 우선한다. |
| 흔적 | 젖은 땅의 이동 흔적은 시각적으로 더 오래 남고, 섭식 흔적의 수명은 해당 셀의 방목 압력에 따라 달라진다. 기존 유한 버퍼와 표시 예산을 사용한다. 늑대가 읽는 추적 증거의 TTL은 유지한다. |
| 빈터 | 권위 Blueprint의 `QueueGroundDisturbance(WorldPosition, Severity)`가 검증된 한 셀에 손실을 예약한다. 다음 Native 단계에서 한 번만 장부의 환경 손실로 반영한다. 군락 발달·은폐가 떨어지고, 식생이 거의 사라진 자리에는 잔재를 표시한다. 기존 재생으로 회복한다. |

빈터 이벤트는 국소 지표 교란 계약이다. 자연 발생 산사태 생성, 나무 쓰러짐 애니메이션과 물리 충돌 지형 변경은 후속 authoring이다. 고인 물은 수영·유체 시뮬레이션으로 소비되지 않는다. 계절과 영양을 PPO 관측·행동·보상·가중치에 추가하지 않았다. 이 환경에서는 기존 입력값과 결과 분포가 달라질 수 있으며 학습 mirror와 재학습은 별도 계약이다.

서버만 식생·개체 기억을 소유한다. 웅덩이·군락·흔적은 기존 가시 셀 및 표현 데이터로 Client에 전달한다. M4 먹이 장부에는 실제 섭식, 환경 손실, 재생이 각자 기록된다. Native 위치·섭식·대사 경로는 각각 기존 writer를 사용한다.

체크포인트 형식은 2다. 같은 빌드·맵·모델·서식지 옵션에서 방목 압력, 고인 물, 새순 비율, 교란/예약 상태, 사냥 위치 기억을 복원한다. 형식 1과 이전 빌드의 체크포인트는 호환 계약상 거절된다.

## 실행과 확인

프로젝트 `Tools/Editor/run_natural_habitat_validation.ps1`을 사용한다.

- `-Mode Automation`은 프로젝트 전체 회귀와 과방목 회복, 낮은 배수의 강수 잔류, 영양 차이, 계절 주기, 중복 빈터 요청, 사냥 기억 감쇠를 검사한다.
- `-Mode Play -HabitatDynamics -PlaySeconds 185`는 권위 날씨로 플레이하며 Forest 한 셀에 명시적으로 빈터를 요청한다. 셀의 발달·손실·회복과 전체 장부, 웅덩이 표현을 확인한다.
- `-Mode Hunt -HabitatDynamics`는 실제 플레이어 Pawn과 `TryStrike`를 사용한다. QA가 플레이어를 이동시켜 공격 장면을 재현한다.
- `-Mode HabitatComparison -LineageSeconds 1200`은 seed 23과 47 각각에서 같은 늑대 설정으로 기존 세계와 새 세계를 비교한다. 사슴의 초기 ID·지역·나이·성별·유전값 일치를 먼저 확인하고, 자손의 세대 및 양쪽 부모 유전값과 대조한다. 이 비교는 새 서식지 규칙 묶음의 결과이며 단일 규칙의 선택 효과를 분리하지 않는다.
- `-Mode Persistence -HabitatDynamics`, `-Mode Network -HabitatDynamics`는 같은 빌드 저장 복원과 전용 서버의 Client 표현을 검증한다.

개체군에는 기존 유전 공식을 적용한다. 성체 기준 유전값을 세대별로 집계해 나이에 따른 성장과 분리한다. 두 시드의 표본으로 특정 체격이 계속 유리해진다고 판정하지 않는다.

## 후속 검증 · 같은 비에서의 방목 이력과 사냥터 복귀

`AdaptiveEcosystem.Vegetation.PairedBrowseRecovery`는 같은 Native 재생 코드에 두 자연 식생 셀을 넣는다. 시작 먹이량(용량의 35%), 발달도(0.60), 토양·배수·날씨를 맞추고 한 셀에만 16회 섭식에 해당하는 방목 압력을 남겼다. 두 셀 모두 이후 섭식 없이 진행하고 20~60초에 같은 비를 준다. 매 스텝에서 자원 수지가 맞는지 확인한다. 맵에서의 자연 관찰과 별도로 방목 압력의 영향만 분리한 실험이다.

| 시뮬레이션 시간 | 방목 이력 없음 | 방목 이력 있음 |
| ---: | ---: | ---: |
| 0초 | 35.0% | 35.0% |
| 20초 | 63.2% | 48.7% |
| 60초 | 91.1% | 74.4% |
| 120초 | 98.1% | 92.9% |

60초에 차이는 16.7%p였고, 120초에는 5.3%p로 줄었다. 직접 UE 5.8 UBT와 `AdaptiveEcosystem.Vegetation` 8개 테스트가 성공했다. `Saved/Logs/FollowupPaired.log`.

### 새순과 마른 풀의 표시

`AEcoVegetationField`는 새 규칙이 켜진 자연 식생의 `Soil.FreshFraction`을 0~255로 양자화해 기존 `FEcoVegetationVisualCell`에 담는다. ISM의 네 번째 Per Instance Custom Data 슬롯(인덱스 3)을 통해 `M_JYU_EcosystemGrass`의 Base Color로 전달한다. 재질은 Vertex Interpolator를 거쳐 새순은 녹색, 마른 풀은 황갈색 쪽으로 보정한다. 기존 먹이량·수분·스트레스 표현 위에 더해지며 새 규칙을 끈 셀, 비자연 셀과 교란 잔재에는 중립값을 보낸다. 권위 Native 식생과 영양 계산은 기존 경로에서 수행하고 색상값은 화면 표현에만 사용한다. JYU 맵의 D3D11 PIE에서 같은 카메라로 화면 두 장을 캡처했다. 이 캡처에는 실제 섭식과 날씨가 함께 반영된다. 전용 서버의 새 색상 수신과 cook은 이 후속 변경에서 재검증하지 않았다.

### 사냥 뒤 한 개체의 이동

`audit_ecosystem_encounters.py`의 `-EncounterTrial=hunt -EncounterFollowReturn`은 실제 `TryStrike`로 피격과 인접 피격 목격을 재현한다. 약 20초 뒤 QA 플레이어를 빼고 위협 신호를 끈 뒤 같은 ID를 추적한다. 장소 기억 중심의 수평 거리가 18m를 넘는 표본 뒤 12m 안으로 들어오면 복귀로 센다. 생존 개체를 이동시키거나 복귀를 강제하지 않는다.

시드 23, 늑대 0 조건에서 사슴 17번의 장소 압력은 최대 0.523이었다. 공격 중단 이후 22~260초의 120개 표본은 장소 중심에서 26.2~77.8m였다. 추적 종료까지 생존했고 12m 안에 들어온 표본은 없었다. 개체 하나의 관측으로 무리의 장기 복귀 여부를 판단할 수 없다. `Saved/HabitatFollowupHunt20261105/Encounter_hunt.json`.
