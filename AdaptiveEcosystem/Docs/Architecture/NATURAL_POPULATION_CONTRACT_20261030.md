# 자연 개체군·성장·군락 발달 계약

2026-10-30 작업 트리. [자연 서식지 계약](NATURAL_HABITAT_CONTRACT_20261030.md)의 후속이며 기존 모델/관측/Raw Request·SocialControl=0·Native 단일 이동/대사/섭식 writer와 M4 장부를 유지한다. 구현 완료 범위는 아래 실행 근거와 구분한다.

## 생물 자료와 게임 해석

[펜실베이니아 Game Commission](https://www.pa.gov/agencies/pgc/wildlife/discover-pa-wildlife/white-tailed-deer)은 어미·새끼·이전 세대 암컷으로 구성된 가족 관계와 나이/영양/계절에 따른 뿔의 차이를 설명한다. [미주리 대학교 Extension](https://extension.missouri.edu/publications/g9479)은 출생 직후 은폐와 이후 어미를 따라다니는 단계의 차이를 설명한다. 특정 흰꼬리사슴 자료의 방향을 현재 예제 사슴에 제한적으로 참고했다. 모든 사슴/몬스터에 동일한 사회 구조를 적용한다는 뜻은 아니다.

현재 기본값은 **게임 시간** 성숙 360초, 초기 어린 개체 25%, 암컷 추첨 확률 60%, 초기 최고 연령 1800초다. 체격/속도 초기 분산은 별도 FounderBodyVariation으로 설정한다. 실제 나이·번식 주기나 조사된 자연 개체군의 비율이 아니다. 레벨이 아닌 `NaturalHabitatProfile`의 Population 항목에서 조정한다. 출생할 때 성숙 시간·성별·확률을 개체에 복사하므로 이주한 곳의 프로필이 기존 개체를 다시 어리게 만들거나 성별/부모를 바꾸지 않는다.

## 초기 배치와 개체 정보

초기 그룹마다 층화한 연령대를 만들고 seed/RegionId와 서로소 순열로 spawn ordinal에 분산한다. 작은 무리가 우연히 전부 성체가 되거나, 어린 개체만 배치 순서 앞쪽에 몰리는 문제를 줄인다. 같은 seed/설정/순서는 재현된다. 기존 명시적 spawn points는 레벨 담당의 실제 지면/공간 authoring으로 유지한다. 이 변경이 스폰 지점을 새로운 지형 전체에서 자동 생성하지는 않는다.

초기 어린 개체는 같은 그룹의 가까운 성숙 암컷을 **사회적 보호자**로 연결한다. 알려지지 않은 혈연을 ParentA/B에 지어 넣지 않는다. 실제 출생은 기존 양쪽 Parent ID와 유전/에너지/인구 거래를 유지하며 어미를 보호자로 지정한다. Natural 개체는 성숙한 암수 조합만 번식 후보가 되고 기존 근친 제외와 지리/먹이/이주 검사를 그대로 거친다. 성체 초기 번식 가능 시각은 분산한다. 계절 번식/수유/성선 호르몬/실제 임신 기간은 구현하지 않았다.

나이·유전·사회적 관계는 개체별 state이며 프로필의 공유 값을 런타임 개체 상태로 사용하지 않는다. 저장/복원은 이를 보존하며 죽은 개체의 **표현**은 사망 시 나이로 멈춘다. 다른 runtime image의 옛 checkpoint를 변환했다고 주장하지 않는다.

## 위험·먹이보다 우선하지 않는 가족 행동

가족 행동은 기존 Native control hook에서만 속도 의도를 보정한다. 부모 좌표를 전역에서 추적해 이동시키지 않는다. 같은 지역의 살아 있는 성숙 암컷, 가까운 거리, 수풀/물리 시야 차폐와 지면 높이 차이를 검사한 관찰만 목표를 갱신한다. 스캔은 약 1초 간격이고 보통 보호자 1명, 분리 후 대안 최대 4명의 물리 검사를 한다. 관찰 후 3초까지만 마지막 위치를 따라가며 가족 관계는 유지하고 오래 분리된 경우 가까운 임시 동행 대상을 관찰해 사용한다. 지역 origin 변경은 좌표 증거를 무효화한다.

따라가기에는 개체별 옆자리와 도착 여유를 두고 기존 접촉 회피/지면 sweep/경계 검사를 통과시킨다. 보호자 사망/이동·분리 시 원격 재결합이나 순간이동을 하지 않는다. 아주 어린 개체는 살아 있는 관목 군락에서 조용하고 에너지 여유가 있을 때 정지할 수 있다. 위협/도주·은신처 의도·여행/정체·Social 예약·개인 반응·굶주림은 가족 따라가기보다 우선한다. 보호자의 수유/능동적 구조/기다리기, 가족 단위 이주 계획을 완료한 것은 아니다. 기존 Persistent Herd/Migration의 소유권을 바꾸지 않는다.

## 성장 외형과 복제

성장 비율은 매끈한 곡선을 사용하고, 유전 크기와 별도로 권위 성숙도 1바이트를 Mass 표현 DTO에 실어 전달한다. Client가 시간을 적분하거나 크기만으로 나이를 추측하지 않는다. 머리 비율과 몸통/다리 실루엣은 성숙도에 따라 연속적으로 바뀐다. 성별 외형 ID는 고정돼 성숙 경계에서 ID가 갑자기 바뀌지 않는다.

기존 vendor Stag 리그에는 뿔 전용 뼈가 없다. 새 owned Blueprint는 어린 수컷의 Doe 리그와 Stag 리그를 성숙 후반에 상보적인 마스크로 점진 전환한다. 전환 중에만 두 Mesh를 표시하고 논리 개체/충돌/음식 writer를 추가하지 않는다. 원본 vendor 메시/재질/애니메이션을 수정하지 않으며 머티리얼의 기존 털 mask를 보존한다. **이는 메시 교체의 시각적 완화(구조적 우회)이며 뿔 자체의 실제 성장/탈락 모델이나 전용 새끼 메시가 아니다.** 최종 아트 단계에는 동일 topology의 growth morph/별도 antler mesh와 계절 표현으로 교체할 수 있다.

새 표현 DTO는 서버/클라이언트 같은 빌드가 필요하다. `BP_EcoNaturalDeer`의 AppearanceVariants/GrowthMaterials와 age-driven AnimBP를 새 레벨에 함께 지정한다. 기존 맵/표현은 `bContinuousGrowthAppearance=false` 기본값으로 보존한다.

## 군락 발달과 먹이

식생 발달도는 기존 Native `FCell`에 저장한다. 최초 자연 서식지 확인 때 seed/cell별로 다른 발달도를 주고, 이후에는 빛·온도·수분 적합도와 guild별 MaturationSeconds(기본 풀60/물가120/관목300초)에 따라 전진한다. 완전 고갈/부적합 지면에서는 어린 군락 단계로 되돌아간다. 완전한 어둠에서는 새 발달/성장이 없다. 발달도는 기존 성장량의 계수로만 소비하며 새 Food writer나 별도 잔여량을 만들지 않는다. 회복은 단순화한 씨앗/뿌리 bank를 가정한다.

같은 안정된 지면 site에서 발달도와 site별 변이를 받아 키/폭이 달라진다. 저밀도에서 갑자기 인스턴스를 켜던 임계치는 연속적인 emergence scale로 바꿨다. 먹이 잔여량/국소 뜯김/수분/스트레스와 실제 cell 수지는 기존 장부와 일치해야 한다. **이는 cell 군락 cohort이며 식물 한 포기마다 영속 나이·씨앗 확산·개화·수목 수명을 시뮬레이션하는 구조는 아니다.** 표시 표본은 최대1024 cells/각9 sites이고 논리 먹이는 현재 cell 해상도다. 보이는 각 잎마다 독립 음식 잔여량이 있는 것으로 설명하지 않는다.

## 실행 근거

실제 결과와 최신 실패/제한은 [실행 기록](../조연우/JYU_NATURAL_POPULATION_20261030.md), [검증 JSON](Evidence/NaturalPopulation_20261030.json)을 따른다. 다른 통합 레벨의 경사/수원/streaming/cook acceptance나 모든 seed의 평형/기아0을 대신하지 않는다. 새 세계 Python mirror/재학습은 별도다.

## 개체 특성 추가와 학습 담당 경계

세부 기획 §7.1/11.4/12.1/17에 맞춰 자연 초기 개체의 size/speed 분산(기본 ±8%, 허용 ±10%), 부모 평균+제한 변이, 경계 기질 Caution, 사회적 간격 성향 Sociability, 털색 명도 Coat를 개체별 genome에 둔다. 크기/속도는 기존 유지 비용·충돌 반경·실제 Native 속도와 연결한다. Coat는 고정된 부모 유전 정보이고 권위 CoatTone byte를 수신해 owned 머티리얼에 제한된 명도 차이를 표시한다. 영양/건강은 기존 권위 Energy/HP로 몸의 살집을 작은 범위에서 표현하며 유전자를 덮어쓰거나 별도 HP/에너지 writer를 만들지 않는다. 영양 때문에 뼈 길이를 바꾸거나 몸이 즉시 성장했다고 처리하지 않는다.

**사용자의 학습 담당 범위 보존 지시:** Caution 값은 유전 상태/진단/인계 데이터만 제공한다. 이를 새 PPO 입력으로 자동 삽입하거나 도주/호기심/공격 선택 임계값에 적용하지 않는다. 임시로 연결했던 Caution 기반 Memory.Decide 보정은 최종 구현에서 제거했다. 기존 경험 반응의 로직과 임계값은 유지한다. Sociability는 이미 선택된 Graze 안에서의 먹이터 혼잡 평가와 동행 옆자리 간격만 조정한다. 위협·이주·Social 예약보다 우선하지 않으며 새 정책 행동이나 정책 분류기를 만들지 않는다.

역할은 다음과 같다.

| 소유자 | 제공/소비 | 이번 변경 경계 |
|---|---|---|
| World/개체 생명주기 | 실제 지면/먹이/몸 크기·에너지·건강·성숙·유전·번식 가능 조건 | 자연 출생의 충분한 건강/안전도 확인. 자원/인구 receipt와 Native 단일 writer 유지 |
| Social/Steering | 같은 행동 안의 자리·간격·관찰한 보호자 목표와 도착/접촉·지형 검증 | 가족 관계와 임시 관찰 대상을 분리. Raw Request/Action을 덮어쓰지 않음 |
| RL 담당 | 관측 schema/정규화·mask·행동 의미·reward·학습·가중치/추론 정책 | 이번 변경에서 수정/재학습/자동 연결하지 않음. Caution/새 나이를 학습에 사용할지 담당자가 별도 계약으로 선택 |
| 표현/Client | 권위 BodyScale/Maturity/CoatTone/Energy/HP로 외형·기존 애니메이션 | Client 자체 생태/유전/추론 없음 |

관측 V1 7/4와 통합 v3 18/5·mask2·기본 모델/가중치, 학습 코드/보상을 보존한다. `training_ready=false`이고 새 자연 세계의 Python mirror/전체 궤적 parity/재학습이 완료된 것은 아니다. 설계 문서의 학습 범위는 [RL 담당 안내](../RL_Policy/ECOSYSTEM_RL_AGENT_GUIDE_20261024.md)와 기존 계약을 따른다. Source가 AI/Policy 폴더에 있다는 이유로 이 world/생명주기 helper를 새 학습기로 설명하지 않는다.

가족 관계 `Caregiver`는 잠깐 안 보인다고 재지정하지 않는다. 별도 `FamilyObserved`가 임시 동행 대상이다. 원래 보호자 관찰을 우선하고, 관찰이 오래 끊긴 뒤(30초) 근처 동행 후보를 찾으며 이 과정도 기존 관계/혈통을 덮어쓰지 않는다. 실제 이동에는 항상 마지막 3초 이내 관찰만 사용한다.
