# 세부 기획 대조: 자연스러운 개체·성장·군락과 역할 경계

2026-10-30 사용자 요청으로 [세부 기획 §1–27](DYNAMIC_ECOSYSTEM_DETAILED_DESIGN_20261023.md)을 Source 및 기존 life/자연 서식지 계약과 대조했다. 이 기록은 제안 문서의 모든 후속 기능을 활성화한 완료 선언이 아니다. 개체 다양성/성장/생활을 실제로 연결한 항목과 명시적 후속/담당 경계를 구분한다. 학습 담당 변경은 하지 않았다. V1/v3 관측·행동/보상/가중치/추론 코드를 바꾸지 않고, 새 특성이 모델에서 어떻게 사용될지는 학습 담당자가 별도 adapter/schema 계약으로 결정한다. 세계·신체·출생 조건이 달라진 실행 세계를 기존 모델과 완전 파리티라고 부르지 않는다.
