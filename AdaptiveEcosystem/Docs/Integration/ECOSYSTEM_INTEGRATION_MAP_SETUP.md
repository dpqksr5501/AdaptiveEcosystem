# 생태계 통합 테스트 맵 안내

## 맵 정보

- 맵 경로: `/Game/Map/LV_Ecosystem_IntegrationTest`
- Unreal Engine 5.8 월드 파티션 맵

2026-10-08 Social 브랜치의 지역·동물·은신처 런타임 배치와 실행 방법은 [팀 레벨 런타임 배치](../조연우/ECOSYSTEM_LEVEL_RUNTIME_PLACEMENT.md)에 정리되어 있습니다. 아래는 원본 레벨의 구성 설명입니다.

현재 테스트 레벨에는 사슴 16마리·늑대 3마리, 논리 지역 3개와 은신처 2개가 연결되어 있습니다. 발 접촉 Notify·Grass/Dry 물리 재질·SA 및 시야/청각 디버그, 서버/Client 검증은 [최신 감각·발소리 통합 기록](../조연우/CREATURE_SENSORY_AND_NOTIFY_REFINEMENT.md)을 참고합니다. 논리 낮밤 시계는 60초 낮/60초 밤이며 아래의 비활성화 설명은 원본 시각 낮밤 설정입니다. 지역 날씨·식생 성장·물/수분의 실제 학습 입력 연결은 별도 후속 작업입니다.

이 맵에는 생태계 통합 테스트에 사용하는 지형, 지역 구분용 트리거 볼륨,
내비게이션 영역과 제외 영역, 물 위치, 폴리지, 생태계 타깃 포인트가 포함되어
있습니다.

## 포함된 기능과 구성요소

- 초원, 황무지, 설원으로 구분된 생태계 지역
- 지역 판정을 위한 트리거 볼륨
- 플레이어를 따라가는 지역별 날씨 관리 기능
- 물 영역과 물 접근용 타깃 포인트
- 수풀 은신처와 은신처용 타깃 포인트
- 이동 가능 영역을 지정하는 내비게이션 메시
- 물처럼 이동할 수 없는 영역을 제외하는 내비게이션 설정
- 지형 머티리얼과 절차적 풀
- 직접 배치한 수풀 폴리지
- 월드 파티션 스트리밍 및 외부 액터/오브젝트 데이터
- 원거리 렌더링 최적화를 위한 HLOD 설정
- 생태계 개체 배치와 행동을 시험하기 위한 통합 테스트 환경

자동 낮밤 주기는 현재 비활성화되어 있습니다.

지형, 폴리지 또는 HLOD 설정을 변경한 경우 관련 월드 파티션/HLOD 데이터를
다시 빌드하고 모든 외부 액터를 저장한 뒤 커밋해야 합니다.
