# 체형의 서버·네트워크 인계

상태는 제안이다. 현재 Mass Bubble, 연결 프로토콜, 체크포인트 포맷을 이번 문서에서 변경하지 않았다. [공통 설계](../Architecture/INHERITED_MORPHOLOGY_DESIGN_20261105.md) · [기존 네트워크 안내](ECOSYSTEM_SERVER_NETWORK_AGENT_GUIDE_20261024.md)

## 데이터 소유권

- 권위 서버가 출생 시 유전·혈통을 기록한다. Native가 이동, 시야, 근접 포획, 대사에서 같은 시점의 표현형을 사용한다. 클라이언트에는 기존 `BodyScale`, `Maturity`, `CoatTone`에 더해 실제로 필요한 시각 축만 보낸다.
- 유전자 전체·부모 ID·비공개 기억·정책 출력은 일반 Client DTO에 넣지 않는다. 디버그용 개체 질의는 권위에서 별도로 제한한다.
- 별도 시각 축이 필요하면 고정 범위의 양자화, 중립 디코딩, 유효하지 않은 코드의 기본값을 정한다. 성장과 건강 업데이트의 송신 주기, 늦은 접속의 최초 스냅숏, 패킷 손실·relevance 재진입에서 재구성 가능한 표현을 우선한다.
- 기존 개체 ID·시각 리비전·이주/표현 재바인딩 계약을 보존한다. 액터 풀 재사용과 새끼/성체 전환 시 이전 개체의 색·메시·스케일이 남지 않아야 한다. 클라이언트의 메시·애니메이션 결과로 서버 충돌·포획을 결정하지 않는다.

## 저장과 배포

유전·연령 기준과 규칙 버전을 저장한다. 재계산할 수 있는 파생치와 클라이언트 캐시는 재구성한다. 구버전과 호환되지 않는 저장은 검증된 변환 또는 기존 거절 경로를 사용한다. 네트워크 스키마가 바뀌면 연결 호환 버전과 같은 빌드 동시 접속을 검사한다. 상호 운용 테스트가 끝날 때까지 다른 빌드 접속을 허용하는 범위는 넓히지 않는다.

## 검증

Standalone과 Dedicated + Client 2개에서 같은 ID의 출생·성장·사망·이주를 대조한다. 늦은 접속·이탈/재접속·relevance 재진입 시 근거리 체형·털색·성숙도의 양자화 오차를 측정한다. 클라이언트 논리 개체와 Native Step은 0이어야 한다. 세대별 개체 수가 늘 때 전송량, 표시 개체 수, 서버 Native 배치 시간을 기존 같은 장면과 비교한다. 로컬 루프백과 패키지/Steam 접속 결과를 별도로 기록한다.
