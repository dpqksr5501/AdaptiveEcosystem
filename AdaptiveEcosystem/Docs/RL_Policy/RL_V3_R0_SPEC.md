# v3 R0 명세 — 행동 레퍼토리의 세계 규칙과 행동별 통과 시험 (학습 없음)

- 작성: 2026-10-07. 근거: 사용자 결정(10-07) — 행동 레퍼토리 확대, **플레이어를 위협으로 넣는다**, **유인은 뺀다**, **파이썬은 개체마다 행동 상태를 관리하고 언리얼은 그 상태에 애니메이션을 묶는다**, **세계 규칙·관문 먼저**. 설계 초안과 적대적 검토 `RL_V3_REPERTOIRE_DRAFT.md`(검토의 '반드시 바꿀 것 5가지'를 반영했다).
- 목표: 행동마다 '그 행동만이 이기는 상황'을 세계 규칙(장치)으로 만들고, 손 규칙 소수 침입 시험으로 확인한다. 통과한 행동만 R1 학습에 넣는다. 보상은 바꾸지 않는다(생존 +0.01, 에너지 순변화, 번식 +10, 사망 −10).

## 1. 바탕 세계
- v2.4s(낮밤, 주행성 포식자 밤잠, 밤 먹이 ×0.1)에서 시작한다. 시간 단위는 결정 스텝(1스텝 = 0.133초).
- 새 기능 두 개(기능 번호 15·16): `repertoire`(행동 실행기와 개체 상태, 행동 장치) 와 `threats`(잠행-돌진 포식자와 플레이어형 위협). 둘 다 끄면 v2.4s 와 비트 동일.

## 2. 행동 (번호는 계약 — 한 번 정한 뜻을 바꾸지 않는다)
| 번호 | 행동 | 실행 규칙 | 섭식 / 대사 | 보이는 정도·지각 |
|---|---|---|---|---|
| 0 | GRAZE 먹기 | 조향 n(0.83·먹이 기울기 + 0.71·무리 + 분리). 현재 셀 먹이가 충분하면 정지(머리 숙여 먹기), 아니면 걷기 | 정지 1.0·걷기 0.5 / 정지·걷기 대사 | 고개를 숙여 자기 포식자 탐지 반경 ×0.6(M5). 은신처 안이면 포식자 체감 거리 ×1.5 |
| 1 | FLEE 도주 | 위협 반대(마지막 위협 방향 유지) ×3 + 무리, 뛰기. GRAZE 에서 들어오면 처음 3스텝 정지(놀람, M2) | 0 / 뛰기 대사 | — |
| 2 | HIDE 숨기 | 가장 가까운 은신처로 걷기(위협이 보이면 뛰기), 도착하면 웅크려 정지 | 0 / 이동·정지 대사 | 도착(웅크림)하면 포식자 체감 거리 ×2.5(은신 배수는 웅크림에만, M6), 움직이지 않음(M1) |
| 3 | FREEZE 얼기 | 그 자리 정지, 위협 쪽으로 고개 | 0 / 정지 대사 | 움직이지 않음(M1), 고개를 들어 자기 탐지 반경 그대로(GRAZE 의 ×0.6 이 없다) |
| 4 | SLEEP 잠 | 진입 3스텝 → 수면 → 기상 3스텝(이동 불가, M4) | 0 / 정지 대사 × (1 − 0.6·d), **은신처 안에서만 할인**(휴식 할인은 SLEEP 전용) | 자기 탐지 반경 ×0.3, 움직이지 않음(M1) |

- 개체 상태(애니메이션 계약): `behavior`(위 번호), `phase`(0 진입·1 지속·2 이탈), `steps_in`(행동 경과 스텝), `seq`(행동이 바뀔 때마다 +1). 파이썬 `World` 의 배열로 둔다. 언리얼은 이 넷을 받아 애니메이션을 고른다(사용자 몫).
- 잠금(최소 유지)과 사건: GRAZE 12, FLEE 8, FREEZE 12, HIDE 도착까지(최대 40) + 12, SLEEP 3 + 60 + 3. 사건(새 위협 보임, 위협 8 안·돌진, 잠 중 위협 감지, 에너지 < 0.25, 어둠 0.5 통과, 은신처 도착)이 생기면 잠금을 풀어 결정 시점만 만든다(행동을 강제하지 않는다). 사건 결정은 개체별 결정 지연 0~3스텝(개체 번호 해시)으로 흩는다.

## 3. 세계 장치 (보상이 아니라 규칙, 값은 R0 에서 보정하는 시작값)
- **M1 정지 탐지**: 포식자·위협의 표적 선택 체감 거리 = 실거리 × max(은신 배수, c_still). c_still 1.8 은 FREEZE·도착 HIDE·SLEEP 에만(행동 기준 — GRAZE 정지에는 주지 않는다. 먹는 동작은 눈에 띈다). 포획 판정은 그대로.
- **M2 놀람 지연**: GRAZE → FLEE 처음 3스텝 속력 0. FREEZE·HIDE → FLEE 는 지연 0.
- **M3 잠행-돌진 위협**(threats): 표적을 잡으면 체감 거리 > 6 이면 ×0.3 으로 몰래 접근, ≤ 6 이면 ×1.5 로 최대 12스텝 돌진, 놓치면 30스텝 탈진(×0.2). 세계마다 이 유형의 비율 p_stalk ~ U[0.3, 0.7], 나머지는 기존 추격형. 밤잠 규칙(v2.4s)은 모든 포식자 유형에 같다.
- **M4 기상 지연**: 위 SLEEP 규칙.
- **M5 고개 숙임**: GRAZE 중 자기 포식자 탐지 반경 ×0.6.
- **M6 웅크림 은신**: 은신 배수 2.5 는 도착 HIDE 에만, 은신처 안 GRAZE 는 1.5.
- **플레이어형 위협**(threats, 사용자 결정): 세계의 절반에 하나. 낮밤과 무관하게 활동한다(밤에 자지 않는다). 움직임 모드를 몇백 스텝마다 바꾼다: 배회(×0.4), 잠행 접근(×0.3, 가장 가까운 무리 쪽), 돌진(×1.3, 최대 20스텝, 그 뒤 휴식). 닿으면 포획(근접형과 같은 거리, 쿨다운 있음). 초식에게는 포식자와 같은 관측 칸(포식자 수·거리)으로 보인다. 언리얼에서는 플레이어 폰을 같은 칸에 넣는다.
- 관측(R1 학습용으로 미리 계산해 둔다): `pred_approach`(가장 가까운 보이는 위협의 접근 속력, [0,1], 없으면 0.5), `kin_alarm`(보이는 동족 중 FLEE 비율), 현재 행동 one-hot·경과·threat_recency.

## 4. 행동별 통과 시험 (R0, `results/v3/r0/PREREG.md` 에 수치 고정 후 실행)
- 거주 112마리는 **X 를 쓰지 않는 최선 규칙**(GRAZE → FLEE 문턱을 탐색으로 찾은 규칙, SLEEP 시험에서는 밤 규칙 포함), 침입 16마리는 같은 규칙에 X 를 니치에서 쓰는 규칙. 탐색 시드 40개 × 3000스텝, 짝 t(임계 2.023).
- 통과 = 셋 모두: (1) 니치 사용 침입이 칸 다수에서 양수이고 유의하게 음수인 칸이 없다 (2) 니치 밖에서 X 를 쓰면 유의하게 음수다(지배 행동 아님) (3) 교차 — X 의 니치에서는 X 가, 대안의 니치에서는 대안이 이긴다.
- 칸: p_stalk {0.3, 0.7} × 플레이어 {있음, 없음} × 하루 {600, 1800}. FLEE 와 GRAZE 는 기본 행동이라 시험하지 않는다(FLEE 는 v2 에서 이미 확인).
- 실패한 행동은 장치를 한 번 다시 보정(최대 2회)하고, 그래도 실패하면 R1 에서 빼고 '규칙 장면' 후보로 둔다. 2M 아사 조기 중단은 R1 사전 등록에 넣는다.
