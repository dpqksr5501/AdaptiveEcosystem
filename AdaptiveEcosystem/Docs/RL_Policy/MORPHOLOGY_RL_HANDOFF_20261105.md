# 체형의 강화학습 인계

상태는 제안이다. 현재 V1 7관측/4출력과 통합 R7e 24관측/5행동·mask5의 입력, 행동, 보상, 가중치를 유지한다. 이 문서의 체형 축은 [설계](../Architecture/INHERITED_MORPHOLOGY_DESIGN_20261105.md)를 따른다.

## 서로 다른 세 경로

1. **체형 조건부 행동.** 먼저 서버가 확정한 체형을 에피소드 동안 고정한다. 학습자가 개체 본인의 현재 표현형을 보게 하는 경우 새 관측 버전과 순서·범위·정규화·결측 중립값을 정의한다. 다른 개체의 유전자, 미래 자원, 서버가 아는 비가시 정보를 정책에 주지 않는다.
2. **단기 신체 사용.** 이후 필요하면 질주나 웅크림처럼 현재 몸으로 할 수 있는 행동 요청을 별도 버전에서 평가한다. Request는 서버의 능력·지형·안전·대사 검사를 거쳐 실행되며 마스크, 거절, 실제 소비를 기록한다.
3. **출생 시 체형 선택.** 강화학습이 유전 축에 영향을 주어야 하면 개체 정책과 별도의 실험으로 다룬다. 오프라인에서 종별 범위 또는 부모 유전값 대비 제한된 출생 변이 제안을 평가한다. 서버 출생 트랜잭션이 프로필·유전 범위·비용·버전을 검증하고 승인된 결과를 고정한다. 기존 출생의 재시도는 같은 ID·시드·규칙으로 재현돼야 한다.

런타임 게임 추론은 기존 Native 경로를 유지한다. 과거 가중치와 새 입력을 섞기 전에 버전과 호환성 검사를 통과해야 한다. 학습 소스나 정책이 세션 중 직접 유전자, 충돌체, 서버 장부를 수정하는 API는 제안 범위에 없다.

## 인수 기준

- 고정 초기 개체 ID·부모·성별·나이·유전값·자원·지형·날씨로 baseline과 축 하나의 처리를 비교한다. seed와 실제 활성 모델을 함께 기록한다.
- 같은 입력에서 Python과 Native의 유전→성숙→능력 계산 및 실제 시야·이동·포획 조건을 Golden Vector와 시나리오로 대조한다. 표현에 쓰는 양자화 값으로 Native 결과를 계산하지 않는다.
- 성장 중 개체의 몸 크기와 성체 유전 체격 분포를 분리한다. 생존·섭식·에너지·번식 기여와 후손 분포를 보고하고 세대별 표본 수를 함께 둔다.
- 사냥 성과는 시야 확보, 실제 추격, 물리적으로 유효한 포획으로 분리한다. 포획 수 하나만 최대화할 때 생기는 기아·멸종·안전 영역 악용과 성향 독점을 별도 실패로 기록한다.
- 현재 진단 자료의 새 체형 상태는 `training_ready=false` 기준이다. 검증 전 값을 기존 모델 관측이나 보상으로 연결하지 않는다.
