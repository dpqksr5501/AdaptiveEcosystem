# R10 0 단계 구현 사양 — 종 카드·2.5D 세계·생성기·계약·규칙 두뇌·시험 (학습 없음)

작성 2026-11-19 · 위 설계: [RL_R10_UNIVERSAL_FAUNA_DESIGN.md](RL_R10_UNIVERSAL_FAUNA_DESIGN.md)(사용자 답 16 절) · 코드 자리 `herbivore_rl/r10/`

이 문서는 0 단계 코드가 지킬 약속이다. 숫자 값(몸·범위)은 종 카드·설정 파일이 정하고, 이 문서는 꼴과 규칙과 시험을 정한다.
R9 코드(`env_v2/r9_*.py`)는 고치지 않는다. R10 은 새 꾸러미로 짜고, R9 에서 검증된 꼴(동시 이동·결정 블록·PPO 리그·팩)을 옮겨 쓴다.

## 1. 시간과 단위

- 길이 m, 시간 s, 질량 kg, 각도 °. 종 카드·맵 카드·세계 상태 모두 SI 다. 언리얼 cm 와 R9 단위(2 m)는 경계에서만 바꾼다.
- 물리 한 걸음 `STEP_S = 2/15 s`(R9·언리얼 Native v3 와 같음), 결정은 2 걸음마다(`DECISION_S = 4/15 s ≈ 0.267 s`). 하루 = 900 걸음(R9 와 같음).
- 계약 상수(`r10/contract.py`)에 넣는다. 바꾸면 계약 판이 바뀐다.

## 3. 종 카드 (`species/<id>.json`, card_version 1)

```
{ "id": "buffalo", "name_ko": "물소", "card_version": 1,
  "medium":   { "ground": true, "wade_depth_m": 0.35, "swim": false, "swim_depth_frac": null, "needs_water": false,
                "fly": false, "cruise_height_m": null, "ceiling_m": null, "takeoff_s": null },
  "body":     { "mass_kg": 450, "radius_m": 0.65, "walk_mps": 1.0, "run_mps": 2.4, "swim_mps": null, "fly_mps": null,
                "cruise_mps": null, "dive_mps": null, "accel_mps2": ..., "turn_dps": ..., "lat_accel_mps2": ...,
                "max_slope_deg": ..., "step_m": ..., "stamina_s": ..., "stamina_recover_s": ... },
  "senses":   { "sight_m": 12, "fov_deg": 300, "smell_m": ..., "hearing_m": ..., "night_vision": 0.3 },
  "diet":     { "grass": 1.18, "forbs": 1.08, "browse": 0.79, "wet_meadow": 1.40, "roots": 0, "insects": 0,
                "aquatic": 0, "drift": 0, "meat": 0, "carrion": 0 },
  "eat":      { "rate_per_s": ..., "energy_per_unit": ... },
  "metabolism": { "drain_per_day": ..., "reserve_days": ..., "run_cost": ..., "swim_cost": ..., "fly_cost": ... },
  "combat":   { "kill_mass_ratio": 0, "reach_m": ..., "attack_cd_s": ..., "defense": 32, "counter_reach_m": ... },
  "life":     { "maturity_days": ..., "litter": ..., "gestation_days": ..., "birth_needs": { ... } },
  "randomize": { "frac": 0.15, "keys": ["mass_kg", "walk_mps", "run_mps", ...] },
  "sources":  { "body.mass_kg": "Tools/Editor/setup_jyu_fauna.py:6xx", ... } }
```

- **값 기준**: 언리얼이 실제로 실행하는 값(팀 에디터 스크립트가 맵에 쓴 프로필, 사슴·늑대는 Native v3). 값이 없는 칸은 R9 YAML → 문서 → 정함(정한 까닭을 `sources` 에 '정함: …' 으로) 순서.
- **잡는 규칙은 이름이 아니라 몸으로**: `kill_mass_ratio` 가 0 보다 크고 먹이에 `meat` 가 있으면, 질량이 `내 질량 × kill_mass_ratio` 이하인 다른 몸을 물 수 있다.
  어린 물소만 표범에게 잡히는 일은 어린 몸이 가벼워서 저절로 생긴다. 새 종이 와도 표를 고칠 필요가 없다.
  팀 언리얼의 '먹잇감 목록·선호'는 두뇌가 배울 일이라 카드에 행동으로 넣지 않는다. 기록용으로 `sources` 에만 남긴다.
- **매체가 같아야 닿는다**: 물속 몸과 땅 몸은 물지 못한다. 하늘 몸은 급강하로 땅·수면 가까이(높이 ≤ 몸 반지름 × 2) 내려왔을 때만 닿는다.
  밍크는 물속에서 물고기를, 뭍에서 쥐를 문다.
- **몸 벡터 17 칸**(감각에 들어감, 7 절 — 11-19 예비 칸 하나를 물 수 있는 몸무게 비로 씀): log 질량, log 반지름, log 걷기·뛰기 속도, 헤엄 가능·속도, 날기 가능·순항 높이, 걷기 물 깊이,
  경사 한계, 회전 한계, 시야 거리·각, 먹이 넷 묶음(풀류·뿌리곤충·물먹이·고기사체), kill_mass_ratio.
- **흔들기**: 학습 세계마다 `randomize.keys` 의 값을 곱 `U[1 − frac, 1 + frac]`로 흔든다(개체 유전 흔들기 R9 0.95~1.05 는 그 위에 따로).
  '배운 범위' 표(종·키·하한·상한)를 팩 manifest 에 적는다. 언리얼 값이 범위 밖이면 경고한다(설계 11 절).
- **이름 모를 동물 카드**: `species.random_card(rng)` 이다. 질량은 log-균등 0.1~500 kg 이고, 속도·반지름·시야는 질량에서 동물 크기 법칙
  (속도 ∝ 질량^0.17 어림)으로 정한 뒤 ±30% 흔든다. 매체는 땅 80%·물 10%·하늘 10%, 먹이는 무작위다.

## 4. 층 지형 (`r10/terrain.py`)

- 셀 `cell_m` = 1.0 m, 맵 W × H 셀(60~200). 층(모두 float32, 셀마다):
  - `ground_z` 땅 높이, `block` 0/1 (바위·나무 줄기 — 땅 몸이 못 지나감),
  - `water_bed_z`·`water_surf_z` (물 없으면 surf < bed), `current_xy` (m/s), `water_temp`,
  - `cover_sight` 0~1 (시야를 막는 정도), `cover_body` 0/1 (은신처 안 — 보호), `canopy` 0/1 (나는 몸 이륙·착지 막음),
  - 먹이 층 8 개: `grass forbs browse wet_meadow roots insects aquatic drift` 각 (양, 용량, 재생/s, 마름/s).
- 수위 주기: `surf_z(t) = base + 진폭 × 주기(오름·높음·내림·낮음 길이)` + 비에 따른 오름(언리얼 `EcoVegetationField.h:55-73` 꼴). 맵 카드에 매개변수.
- 질의(벡터): `height(x,y)`, `slope_deg(x,y,dir)`, `depth(x,y)`, `current(x,y)`, `is_blocked_for(body, from, to)`, `sight_cover(from, to)`.
- **맵 카드** = 층 배열 `npz` + `json` 머리(셀 크기·원점·수위 매개변수·출처·생성기 시드). 생성기와 언리얼 내보내기가 같은 꼴을 쓴다.

## 5. 몸 물리 (`r10/world.py`, 한 걸음)

차례는 R9 와 같게 '모두 이전 위치에서 동시에' 한다: 결정 → 이동 → 접촉(물기·반격) → 먹기 → 대사 → 번식 → 죽음·사체 → 감각.

- **땅 이동**: 행동의 방향·걸음(걷기/뛰기)이 목표 속도다. 가속·회전 한계(M1)로 자른다. 다음 자리로 가는 길을 셀 단위로 훑는다.
  - 높이 차 > `step_m` 이거나 경사 > `max_slope_deg` 이거나 `block` 이면 그 앞에서 멈춘다. R9 벽처럼 벽을 따라 미끄러진다.
  - 물 깊이 ≤ `wade_depth_m` 이면 걷되 속도 × (1 − 깊이/걷기깊이 × 0.5) 이다. 더 깊으면 `swim` 몸은 헤엄으로 바뀌고, 아니면 멈춘다.
- **헤엄**: 헤엄 몸은 물기둥 안에 높이 `z` 를 가진다. 깊이는 `(bed + 여유) ≤ z ≤ (surf − 여유)`, 여유 = 반지름 × 0.65(언리얼과 같음)이다.
  - `오르기`·`내리기`가 z 를 `swim_mps × 0.5` 로 바꾼다. 물살 × STEP_S 만큼 떠밀린다.
  - `needs_water` 몸(물고기)은 깊이 < 2 × 여유인 칸으로 못 간다. 수위가 내려 그런 칸에 남으면 숨 가쁨이 오른다. 숨 가쁨 1 이면 죽는다(몸 규칙).
- **날기**: 나는 몸은 `airborne`·`z`(땅 위 높이)를 가진다.
  - 땅에서 `오르기`를 하면 위에 `canopy` 가 없을 때 `takeoff_s` 동안 떠오른다.
  - 공중에서 오르기·내리기가 z 를 바꾼다(상한 `ceiling_m`). 앞으로 가는 속도는 z ≥ 0.6 × `cruise_height_m` 이면 `cruise_mps`, 아래면 `fly_mps` 이다.
  - z 가 0 에 닿을 때 그 칸이 물이 아니고 경사가 완만하고 `canopy` 가 없으면 내려앉는다. 아니면 z = 0.5 m 에서 맴돈다.
    **다른 착지점을 세계가 찾아 주지 않는다.**
  - `빠르게 내리기`(급강하)는 z 를 `dive_mps` 로 내리고 앞으로도 간다. 지구력이 든다.
- **지구력·대사**: 뛰기·빨리 헤엄·날기·급강하는 지구력을 쓰고, 서기·걷기는 되찾는다. 에너지 소모 = drain × (걸음·매체 배율) + 무게 배율.
  비축(R9 지방)은 R9 와 같다.
- **접촉**
  - 물기: 공격 몸(`kill_mass_ratio > 0`)이 같은 매체(3 절)이고, `reach_m` 안이고, 머리 앞 원뿔(내적 ≥ 0.5)이고, 다가가는 속도 > 0 이고,
    상대 질량 ≤ 내 질량 × ratio 이고, 상대가 은신처 밖이면 문다. 쿨다운은 `attack_cd_s` 다.
  - 반격: 상대 `defense` > 0 이고 공격자가 앞에 있으면 R9 반격 꼴(체력·쿨다운)을 따른다.
  - 같은 종은 물지 않는다(R9 와 같음, 몸 규칙).
- **먹기**: `서서 먹기`만 먹는다(걸어가지 않음). 발밑 먹이 층 가운데 `diet` 가중 × 양이 가장 큰 것을 `rate_per_s × STEP_S` 만큼 먹는다.
  고기·사체는 1 m 안 사체다. 물속 먹이는 헤엄 몸, 수면 떠내려온 것은 수면 가까이(z ≥ surf − 2 × 여유)에서만 먹는다.
- **생애**: R9 `r9_life` 의 번식 조건·성장·출생을 종 카드 `life` 값으로 일반화한다.
  - 출생 자리가 그 몸의 매체에 맞아야 낳는다(물고기는 물, 나는 몸은 땅). 산란 수온·물살은 카드 `birth_needs`.
  - R9 판정 세계의 마릿수 상한·막힘 셈은 그대로 옮긴다.

## 6. 맵 무작위 생성기 (`r10/mapgen.py`)

- `make_map(seed, preset_mix) -> MapCard`. 같은 시드면 같은 맵이다(시험).
- 층을 차례로 만든다.
  1. 크기 60~200 m.
  2. 높이: 노이즈 몇 겹 + 모양(평지·언덕·고원 절벽·골짜기)을 섞는다. 경사 0~45°.
  3. 물: 없음 / 개울(너비 1~4 m) / 강(4~15 m, 깊이 0.5~3 m, 물살 0~0.6 m/s) / 호수 / 습지.
  4. 막힘·가림: 바위·나무·수풀 밀도 0~40%, 은신처 0~8.
  5. 먹이 군락: 층마다 수·용량·재생. 물먹이는 물에만, 습지풀은 물가에.
- 동물 배치: 종마다 0~N 마리, 서식 조건(물·땅·높이)을 만족하는 칸에 둔다. 그 종이 없는 맵을 꼭 섞는다. 이름 모를 동물은 세계 0~3 마리.
- 시드 범위: 학습 50000~59999, 점검 60000~60999, **시험(처음 보는 맵) 61000~61999 잠금**.
  섬·JWJ 맵 카드는 시험에만 쓴다. 학습 코드가 시험 범위나 맵 카드 경로를 받으면 거부한다(R9 판정 시드 잠금과 같은 꼴).

## 7. 감각 S1 (`r10/contract.py`·`r10/senses.py`)

- 머리 기준(x = 머리 쪽, y = 왼쪽)이다. 거리·크기·속도는 `lg(x) = log1p(x/ref)/log1p(max/ref)` 로 0~1 에 넣고, 방향 성분은 −1~1 이다.
- 묶음과 칸 수:
  - 자기 14: 에너지·비축·지구력·체력·나이·짝지을 수 있음·출산 대기·속도·땅 위 높이(나는 몸)·물속 높이 비(헤엄 몸)·물속인가·은신처 안인가·숨 가쁨·날고 있나.
  - 몸 17: 3 절 몸 벡터 (11-19 예비 칸 하나를 b_kill = 물 수 있는 몸무게 비 / 4 로 씀).
  - 8 방향 × 6 = 48: 머리에서 왼쪽 j × 45° 방향마다
    - 내 몸으로 갈 수 있는 거리(시야 안, 막힘·경사·깊이를 내 카드로 판정)
    - 그 방향 2 m 앞 높이 차
    - 그 방향 물 깊이
    - 물살 성분(그 방향으로)
    - 시야 가림
    - 내 먹이 양(먹이 가중 합, R9 `food_dir` 꼴: x/(x + ref))
  - 발밑 6: 여기 먹이(가중 합), 여기 사체, 수면까지 높이, 바닥까지 높이, 여기 경사, 은신처 가장자리까지.
  - 다른 동물 8 × 12 = 96: 보이는(시야 거리·각·가림·밤) 가까운 순 8 마리. 칸마다
    - 있음
    - 상대 위치 x·y(거리 lg × 방향)
    - 다가오는 속도
    - 상대 속력
    - 크기 비(log)
    - 질량 비(log)
    - 매체 두 칸(물속인가·하늘인가, 둘 다 0 = 땅)
    - 높이 차
    - 같은 종인가
    - 상대 머리가 나를 향하나(내적)
  - 같은 종 4: 둘레 같은 종 수, 중심 방향 x·y, 평균 속도.
  - 환경 6: 빛, 비, 눈, 기온, 수위 오르내림, 최근 큰 소리 방향(없으면 0).
  - 예비 15: 0.
  - 합 206.
- 감각 마스크: 몸이 못 느끼는 칸은 0(예: 물고기에게 공기 중 소리, 땅 몸에게 물속 높이). 마스크 표는 계약에 넣는다.
- 계약 해시(`io_hash`)에는 이름·순서·정규화 상수·행동 이름·망 꼴이 들어간다. 몸 값·맵은 들어가지 않는다(설계 11 절).

## 8. 행동 A1 (24 칸)

0 서서 먹기 · 1–8 천천히(걷기/헤엄/날기) 8 방향 · 9–16 빠르게 8 방향 · 17 숨기 · 18 지켜보기 · 19 오르기 · 20 내리기 · 21 빠르게 내리기 · 22–23 예비.

- 행동 마스크(학습·실행 모두): 땅만 몸은 19–21 이 막힌다. 헤엄 몸은 21 이 막힌다. 날지 않는 몸은 21 이 막힌다. 예비 칸은 늘 막힌다.
- 마스크는 PPO 정책 출력에서 막힌 칸의 로짓을 −∞ 로 둔다(SB3 MaskablePPO 꼴 또는 직접 구현).

## 9. 공통 규칙 두뇌와 '작은 확인'

- `rule_brain.decide(obs_block, mask)` 는 감각만 읽고 종 이름은 모른다.
  1. 둘레에 나보다 크기 비 > 1.5 이면서 다가오는 몸이 있으면 반대쪽으로 빠르게 간다(나는 몸은 오르기).
  2. 배고프고 고기를 먹는 몸이면 질량 비가 내 kill 범위 안인 가장 가까운 몸 쪽으로 빠르게 간다.
  3. 발밑에 먹이가 있으면 먹는다.
  4. 아니면 먹이 방향 가장 큰 쪽으로 천천히 간다.
  5. 아니면 지켜본다.
- 0 바퀴 상대·잣대·이름 모를 동물에 쓴다. 보상으로 따라 하게 하지 않는다.
