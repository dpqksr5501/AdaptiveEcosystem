# 04. 부트스트랩 히스토리 및 역할 분담 (Bootstrap History & Team Roles)

> 본 문서는 프로젝트 초기 셋업 및 1·2차 부트스트랩 안정화 과정의 개발 이력과 팀 역할 분담을 기록한 문서입니다.

---

## 1. 초기 파트별 역할 분담 (Initial Team Roles)

| 역할 | 담당 영역 | 초기 목표 및 산출물 |
| :--- | :--- | :--- |
| **World / Level** | `AEcologyRegion`<br>`UEcologyWorldSubsystem` | 지리적 볼륨 설정, 날씨/낮밤 환경 파라미터(`FRegionEnvironmentState`), 테스트 맵 구축 |
| **Server / Mass** | `UEcologyServerSubsystem`<br>`MassEntity` | 서버 권한 시뮬레이션, 이벤트 집계, 자원 소모/재생, 대규모 엔티티 연산 |
| **Creature Runtime**| `ACreatureCharacter`<br>`UCreatureTraitComponent` | 확정된 프로필을 수신하여 신체 스케일(BodyScale), 이동속도, AI 성향 시각화 |
| **Ecology / Evolution**| `EvolutionValidator`<br>`DummyEvolutionDecisionProvider`| 초기 수치 변이 검증기, 상한/하한 클램프, 안전 예외 처리 |

---

## 2. 부트스트랩 단계별 진행 이력 (History)

### Phase 1 — 최초 리포지토리 부트스트랩 (Initial Bootstrap)
- UE 5.8 C++ 프로젝트 기준점 확정 및 모듈 빌드 환경 구성
- 최초 수직 슬라이스: `Forest_A` (Region) $\times$ `Wolf` (Species)
- 공통 기본 데이터 계약(`Core/EcoDataContracts.h`) 및 통합 테스트 액터(`AEcologyBootstrapTestActor`) 구축

### Phase 2 — 공통 경계 및 서버 권위 안정화 (Stabilization)
- `UEcologyServerSubsystem`의 Server / Standalone 단독 동작 보장 (`NM_Client` 차단)
- `EvolutionValidator`를 통한 비정상 수치(NaN/Inf, 오버플로우) 방어 체계 수립
- `ACreatureCharacter`가 서버 서브시스템을 직접 참조하지 않고 순수 파라미터 주입(`InitializeCreature`)으로 동작하도록 Decoupling 완료

### Phase 3 — PPO + MassEntity 동적 생태계 전환 (Current Architecture)
- 장기 세대 진화 모델을 닫힌 생태계 피드백 루프(MassEntity + Python PPO + C++ Native 추론 + MassFlock)로 전면 전환
- 세부 사항은 [Docs/PPO_MASS_ECOSYSTEM_ARCHITECTURE.md](../PPO_MASS_ECOSYSTEM_ARCHITECTURE.md) 참조
